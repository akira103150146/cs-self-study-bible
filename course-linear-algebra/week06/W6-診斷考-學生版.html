  1. Let $A$ be a $5 \times 5$ matrix whose columns are linearly independent. Which statement must be false?

    1. AThere is a $\mathbf{b}$ in $\mathbb{R}^5$ for which $A\mathbf{x} = \mathbf{b}$ has no solution.
    2. B$A$ has 5 pivot positions.
    3. C$A$ is row equivalent to $I_5$.
    4. DThe transformation $\mathbf{x} \mapsto A\mathbf{x}$ is onto $\mathbb{R}^5$.

  2. $A$ is a $4 \times 3$ matrix whose columns are linearly independent. What can you conclude about the equation $A\mathbf{x} = \mathbf{b}$?

    1. ANothing about existence of solutions; but if a solution exists it is unique.
    2. BIt has a unique solution for every $\mathbf{b}$ in $\mathbb{R}^4$.
    3. CIt has at least one solution for every $\mathbf{b}$ in $\mathbb{R}^4$.
    4. DIt has infinitely many solutions.

  3. A square matrix $A$ satisfies $\det A = 1$ and $\operatorname{cond}(A) \approx 10^4$. Using double precision (about 16 significant digits), roughly how many digits of the computed solution of $A\mathbf{x} = \mathbf{b}$ can be trusted?

    1. AAbout 12
    2. BAll 16, because $\det A = 1$ is far from 0
    3. CAbout 4
    4. DNone, because the matrix is singular

  4. Given $A = LU$, how do you solve $A\mathbf{x} = \mathbf{b}$?

    1. ASolve $L\mathbf{y} = \mathbf{b}$ first, then solve $U\mathbf{x} = \mathbf{y}$.
    2. BSolve $U\mathbf{y} = \mathbf{b}$ first, then solve $L\mathbf{x} = \mathbf{y}$.
    3. CCompute $L^{-1}U^{-1}\mathbf{b}$.
    4. DCompute $A^{-1}\mathbf{b}$, since $A^{-1} = L^{-1}U^{-1}$.

  5. While row reducing $A$ to $U$, you use the operation "row 3 minus 2 times row 1." What is the $(3,1)$ entry of $L$?

    1. A$2$
    2. B$-2$
    3. C$1/2$
    4. D$0$
