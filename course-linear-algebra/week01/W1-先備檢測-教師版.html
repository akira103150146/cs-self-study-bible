第 1 週理論課開頭,15 分鐘內收回。不計對錯、只看有沒有交,學生才會照實作答。

收回後快速看作答分布:如果多數人選了同一個錯誤選項,查下面的迷思對照,先花最多 10 分鐘補那個觀念,再往下上課。

  1. 先備

    Solve the system $2x + y = 7,\;\; x - y = 2$.

    答案$x = 3,\; y = 1$

    兩式相加消去 $y$:$3x = 9$,$x = 3$;代回第二式:$3 - y = 2$,$y = 1$。

    常見錯答代表的迷思回去看
    $x = 3,\; y = -1$代回時移項沒變號國中:移項要變號,解完代回兩式驗算
    只寫出 $x = 3$忘了把 $x$ 代回去求 $y$加減消去法的最後一步:代回
  2. 先備

    If $x = 2$ and $y = -1$, evaluate $3x - 4y$.

    答案$10$

    $3(2) - 4(-1) = 6 + 4 = 10$。

    常見錯答代表的迷思回去看
    $2$把 $-4 \times (-1)$ 算成 $-4$負負得正
    $-10$代入時整個符號弄反代入負數要加括號:$-4(-1)$
  3. 先備

    Which point lies on the line $2x + 3y = 12$?

    1. A$(3, 2)$
    2. B$(2, 3)$
    3. C$(0, 6)$
    4. D$(4, 2)$
    答案A

    代入 $(3, 2)$:$2 \cdot 3 + 3 \cdot 2 = 12$ ✓。其他三點代入分別得 $13$、$18$、$14$。

    選項代表的迷思回去看
    B把點的 $x$、$y$ 座標順序弄反點 $(x, y)$:先橫座標、再縱座標
    C求 $y$ 截距時用 $12 \div 2$,算成 6令 $x = 0$:$3y = 12$,$y = 4$
    D只看其中一項、沒有把兩項加起來驗算代入後把整個左邊算完再和右邊比
  4. 先備

    The lines $y = 2x + 1$ and $y = 2x - 3$ are:

    1. Aparallel (they never meet)
    2. Bintersecting at exactly one point
    3. Cthe same line
    4. Dperpendicular
    答案A

    斜率都是 2,方向相同;截距一個是 1、一個是 $-3$,所以是兩條不同的平行線,永遠不相交。

    選項代表的迷思回去看
    B沒注意到斜率相同斜率決定方向:斜率相同就不會相交(除非重合)
    C以為斜率相同就是同一條線,忽略了截距截距不同就是不同的線
    D把「斜率相同」和「垂直」搞混垂直是斜率相乘等於 $-1$
  5. 先備

    Simplify $2(x + 3y) - (x - y)$.

    答案$x + 7y$

    $2x + 6y - x + y = x + 7y$。注意 $-(x - y) = -x + y$。

    常見錯答代表的迷思回去看
    $x + 5y$去括號時沒有變號,把 $-(x - y)$ 寫成 $-x - y$負號要分配到括號內每一項
    $3x + 7y$同類項合併時把 $2x - x$ 算成 $3x$同類項:係數相加減
