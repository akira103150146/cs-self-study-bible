線性方程組與列化簡

Google 地圖怎麼算路線、遊戲怎麼知道子彈打中了牆、照片缺了一塊怎麼補回來?答案裡都藏著同一件事:解一大堆一次方程式。這週把手算的方法練熟(Lay 1.1–1.2),實作課再交給電腦。

下課鐘響時,學生要能做到

  • 判斷一條式子是不是線性方程式;分清楚「解」與「解集」;說出解只有三種情況與各自的直線圖像。
  • 把方程組寫成係數矩陣與增廣矩陣,用三種基本列運算化簡,每一步寫出操作記號。
  • 化到三角形式就能回答「有沒有解、解是不是唯一」。
  • 用五步驟的列化簡演算法把矩陣化成 RREF,指出 pivot 位置與 pivot 行。
  • 從 RREF 寫出一般解(自由變數當參數),並用 Theorem 2 判斷無解/唯一解/無限多解。
  • 說出「列運算不改變解集」的理由:每種列運算都能復原。

本週的證明時刻

列運算不改變解集——整個消去法的正當性都靠這一句(課本 p. 31)。關鍵想法只有一個:每種列運算都能被另一個列運算復原。課堂上只示範 replacement 的雙向論證(舊解 ⇒ 新解、新解 ⇒ 舊解),interchange 和 scaling 口頭帶過,最後點出 scaling 的「$c \neq 0$」在哪一步被用到。觀念 2 的「幾何意義」圖可以當開場:線換了,交點沒動。

教師版例題裡有完整證明;學生版只列定理、為什麼值得證、關鍵想法,並留空間讓學生跟著寫。 筆試不考「請證明」,考三種變形:哪一步違反前提、舉一個反例、 用在沒看過的情境。

份量說明

例題講義刻意給足份量:每個觀念 2–3 題老師講解、10 題左右的練習(大多是課本原題,出處標在題號旁)。教師版每題都有「教師備註」,寫明建議課堂做、當作業或可略;依班級程度挑選即可,不必全上。觀念 6 是補充,不在節奏表裡。

開場:先測再說(15 + 5 分)

一上課不要先講話,直接發先備檢測,五題、15 分鐘、當場收。題目是高職代數:解聯立、代入求值、判斷點在不在線上、兩線平行、去括號。

為什麼要測:線代沒有先修課,你需要知道這班的代數底子在哪裡。收回來看一眼就好,不用當場檢討;如果「去括號變號」錯很多,觀念 2 做列運算時要特別放慢。

接著 5 分鐘講三個場景:遊戲判斷子彈打中牆(兩條線求交點)、動畫讓曲線穿過指定的點(實作課會做)、照片補洞(觀念 6 的熱傳導模型)。丟出本週的核心問題:「方程組的解,到底有幾種可能?」讓學生猜,把答案寫在黑板角落。

觀念 1:線性方程組與解集(20 分)

觀念(5 分):線性方程式的定義,只看未知數有沒有次方、互乘、開根號。講清楚「解」和「解集」的差別(是非題 31 會考)。

講解(8 分):例 1 讓學生舉手投票四條式子是不是線性,$\sqrt{6}$ 和 $\sqrt{x_1}$ 一定會有人搞混,正好帶出判斷準則。例 3 三小題並排做,一定要畫三張圖;(b) 算到 $0 = 2$ 時停下來問:「這代表什麼?」

練習(7 分):Exercises 3–4、Practice Problem 3。Practice Problem 3 巡堂看誰只代了前兩條。

觀念 2:矩陣表示與基本列運算(30 分)

觀念(6 分):把方程組寫在左邊、增廣矩陣寫在右邊,用箭頭一個一個對應。強調「列是橫的、行是直的」「$m \times n$ 列數在前」。三種列運算各舉一個小例子。

講解(14 分):例 2(課本 Example 1)是本週第一個完整的消去,黑板左右兩欄同時寫方程式與矩陣,每一步都寫操作記號。最後一定要驗算,並帶一次「合理性檢查」那個例子。

練習(10 分):Exercises 1–2 全班寫完再往下;是非題 27–30 每題 30 秒口頭問答。

證明時刻(15 分)

先問:「我們把矩陣改來改去,憑什麼最後的解就是原題的解?」讓學生意識到這不是理所當然。秀出觀念 2 的幾何意義圖:線換了,交點沒動。

黑板分兩欄:左欄「舊解 ⇒ 新解」、右欄「新解 ⇒ 舊解」,只做 replacement。右欄做完時點出:「剛剛『減去 $c$ 倍』,就是把列運算復原。」最後問:「scaling 為什麼要規定不能乘 0?」讓學生回答「因為乘 0 就回不去了」。

觀念 3:存在性與唯一性(20 分)

觀念(4 分):抄下課本 p. 31 的「兩個基本問題」方框,整學期都會回來用。

講解(8 分):例 1 只花 2 分鐘(它就是觀念 2 例 2 的三角形式)。例 2(課本 Example 3)是重點:先換列、再消去,最後讀出 $0 = 15$。給學生看課本 p. 32 的立體圖。

練習(8 分):照做 Practice Problem 2 與 Exercises 7–8;變化挑 Exercises 23–26 其中兩題。

觀念 4:梯形、RREF 與 pivot(35 分)

觀念(8 分):用樓梯圖講列梯形的三個條件,再加 RREF 的兩個條件。強調 Theorem 1「RREF 只有一種」的意義:pivot 位置是矩陣本身的性質。

講解(17 分):例 1 快速判斷三個矩陣。例 2(課本 Example 2)做到第 7 步,強調「跳過全 0 的行」。例 3(課本 Example 3)放慢做:把步驟 1–5 的框框一個一個貼到黑板上,往前、往回用兩種顏色寫。

練習(10 分):Exercise 1 快速判斷;Exercise 3 完整化簡,給足時間;是非題口頭問。

觀念 5:從 RREF 讀出解(25 分)

觀念(5 分):把流程圖畫在黑板角落,之後都不要擦。講清楚基本變數和自由變數,以及「$x_3$ is free」的意思。

講解(12 分):例 1 寫出一般解後,讓學生隨便挑一個 $x_3$ 的值代回去驗算。例 2(課本 Example 4)示範兩個自由變數;例 3(課本 Example 5)示範「梯形就夠回答存在與唯一」。

練習(8 分):照做 Practice Problem 1、Exercises 7–8(提醒 Exercise 8 的 $x_3$ 陷阱)。挑戰題 35–38 很適合當成下課前的討論題。

🧠
學生最常翻的車
  • 以為方程組可能剛好有兩個解。
  • 把「解」和「解集」混為一談。
  • 看到 $\sqrt{6}\,x_2$ 就說不是線性方程式;或反過來,沒發現 $\sqrt{x_1}$ 不是線性。
  • 驗算只代一條方程式。
  • 算到 $0 = 2$ 以為自己算錯,回頭重算。
  • 「列」和「行」搞混;把 $m \times n$ 寫成行數在前。
  • 做 $R_3 \leftarrow R_3 + (-5)R_1$ 時把第 1 列也改掉。
  • 把「某列乘以 0」當成合法的列運算。
  • 在原矩陣上圈 pivot,而不是在化簡後的梯形上圈。
  • 往前階段遇到某一行剩下的部分全是 0 時卡住,或硬拿 0 當 pivot。
  • 把全 0 列 $[\,0 \;\; 0 \;\; 0 \mid 0\,]$ 當成無解。
  • 以為有自由變數就代表題目算錯了;一般解漏掉沒出現在方程式裡的未知數。

出門檢核(下課前,口頭)

快問快答,老師自己看誰卡住;書面的正式版本是實作課開頭的診斷考。

  1. 兩條直線的方程組,解的個數有哪幾種可能?

    0 個、1 個、無限多個。不可能剛好 2 個。

  2. 哪一種列運算要加「不為 0」的條件?為什麼?

    Scaling。乘 0 會把方程式變成 $0 = 0$,限制條件消失,而且沒辦法復原。

  3. RREF 最後一列是 $[\,0 \;\; 0 \;\; 0 \mid 7\,]$,代表什麼?

    $0 = 7$,矛盾,方程組無解(最後一行是 pivot 行)。

  4. 方程組相容,而且有一個自由變數,解有幾個?

    無限多個(Theorem 2)。
