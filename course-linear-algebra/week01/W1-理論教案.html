線性方程組與列化簡

Google 地圖怎麼算路線、遊戲怎麼知道子彈打中了牆、推薦系統怎麼猜你喜歡什麼?答案裡都藏著同一件事:解一大堆一次方程式。這週把手算的方法練熟,實作課再交給電腦。

理論 3 小時搭配實作 3 小時Lay 1.1–1.2學期地基

哪些能快轉,哪些要踩煞車

內容對學生是建議節奏
解二元一次聯立(代入、加減消去)高職學過,但熟練度不一先備檢測確認,別重教
線性方程式的判斷新名詞,概念簡單快速帶過
解的三種情況與直線圖像全新的觀點踩煞車,一定要畫圖
增廣矩陣與三種列運算全新,但就是消去法換個寫法中速,強調寫操作記號
梯形、RREF、pivot全新,本週最重要大力踩煞車,例 2 慢慢做
從 RREF 讀解、存在與唯一性定理全新中速,用流程圖固定判斷順序

下課鐘響時,學生要能做到

  • 判斷一條式子是不是線性方程式,並說出解只有三種情況、各自對應的直線圖像。
  • 把方程組寫成增廣矩陣,用三種列運算化簡,每一步寫出操作記號。
  • 把矩陣化成 RREF,指出 pivot 位置與 pivot 行。
  • 從 RREF 判斷無解/唯一解/無限多解;有解時寫出一般解(自由變數當參數)。
  • 說出「列運算不改變解集」的理由:每種列運算都能復原。

🎯
本週的證明時刻

列運算不改變解集——整個消去法的正當性都靠這一句。關鍵想法只有一個:每種列運算都能被另一個列運算復原。課堂上只示範 replacement 的雙向論證(舊解 ⇒ 新解、新解 ⇒ 舊解),interchange 和 scaling 口頭帶過,最後點出 scaling 的「$c \neq 0$」在哪一步被用到。

教師版例題裡有完整證明;學生版只列定理、為什麼值得證、關鍵想法,並留空間讓學生跟著寫。 筆試不考「請證明」,考三種變形:哪一步違反前提、舉一個反例、 用在沒看過的情境。

逐段怎麼上

開場:先測再說(15 分)

一上課不要先講話,直接發先備檢測,五題、15 分鐘、當場收。題目是高職代數:解聯立、代入求值、判斷點在不在線上、兩線平行、去括號。

為什麼要測:線代沒有先修課,你需要知道這班的代數底子在哪裡。收回來看一眼就好,不用當場檢討;如果「去括號變號」錯很多,觀念 2 做列運算時要特別放慢。

為什麼資工系要學解方程組(10 分)

不要講定義,講三個場景:遊戲判斷子彈打中牆(兩條線求交點)、動畫讓曲線穿過指定的點(實作課會做)、推薦系統(第 16 週會回來)。

然後丟出本週的核心問題:「方程組的解,到底有幾種可能?」讓學生猜,把答案寫在黑板角落,留到觀念 1 揭曉。

觀念 1:解的三種情況(30 分)

觀念(7 分):先講「什麼是線性方程式」,只看未知數有沒有次方、互乘。接著畫三張圖:相交、平行、重合。

講解(10 分):例 1 讓學生舉手投票每一小題是不是線性,(c) 的 $\sqrt5$ 一定會有人投錯,正好帶出判斷準則。例 2 兩小題並排做,(b) 算到 $0 = 2$ 時停下來問:「這代表什麼?」

練習(13 分):照做兩題、變化兩題,挑戰題選做。巡堂重點:變化題第 2 題(求 $h$)有沒有人想到「平行 = 無解」。

觀念 2:增廣矩陣與列運算(30 分)

觀念(7 分):把例 1 的方程組寫在左邊、增廣矩陣寫在右邊,用箭頭一個一個對應。三種列運算各舉一個小例子。

講解(12 分):例 2 是本週第一個完整的消去,每一步都寫操作記號,寫在矩陣右邊。最後一定要驗算——讓學生看到代回原題才能確認答案。

練習(11 分):照做兩題一定要全班都寫完再往下,這是後面所有東西的基本功。

證明時刻(15 分)

先問:「我們把矩陣改來改去,憑什麼最後的解就是原題的解?」讓學生意識到這不是理所當然。

黑板分兩欄:左欄「舊解 ⇒ 新解」、右欄「新解 ⇒ 舊解」,只做 replacement。右欄做完時點出:「剛剛『減去 $c$ 倍』,就是把列運算復原。」最後問:「scaling 為什麼要規定不能乘 0?」讓學生回答「因為乘 0 就回不去了」。

觀念 3:梯形、RREF 與 pivot(35 分)

觀念(8 分):用樓梯圖講梯形的三個條件,再加 RREF 的兩個條件。強調「RREF 只有一種」的意義:pivot 位置是矩陣本身的性質。

講解(15 分):例 1 快速判斷三個矩陣。例 2 放慢做:往前、往回兩個階段用兩種顏色寫;做到第 2 步時停下來問「第 2 行底下全是 0,怎麼辦?」——這是本週學生最容易卡住的地方。

練習(12 分):照做第 2 題和變化第 1 題是完整的化簡,給足時間。

觀念 4:從 RREF 讀出解(30 分)

觀念(7 分):把流程圖畫在黑板角落,之後都不要擦。講清楚基本變數和自由變數。

講解(10 分):例 1 寫出一般解後,讓學生隨便挑一個 $x_3$ 的值代回去驗算。例 2 三小題照流程圖判斷,每一題都大聲問那兩個問題。

練習(13 分):挑戰題(3 條方程式、5 個未知數)很適合當成下課前的討論題。

收尾(5 分)

回到開場寫在角落的猜測,對答案:0 個、1 個、無限多個。預告實作課開頭有 10 分鐘的診斷考,不計對錯、只看有沒有交,目的是讓老師知道哪裡要補。

🧠
學生最常翻的車
  • 以為方程組可能剛好有兩個解。
  • 看到 $\sqrt5\,x_2$ 就說不是線性方程式。
  • 算到 $0 = 2$ 以為自己算錯,回頭重算。
  • 做 $R_3 \leftarrow R_3 - 5R_1$ 時把第 1 列也改掉。
  • 把「某列乘以 0」當成合法的列運算。
  • 在原矩陣上圈 pivot,而不是在化簡後的梯形上圈。
  • 往前階段遇到某一行底下全是 0 時卡住,或硬拿 0 當 pivot。
  • 把全 0 列 $[\,0 \;\; 0 \;\; 0 \mid 0\,]$ 當成無解。
  • 以為有自由變數就代表題目算錯了。

出門檢核(下課前,口頭)

快問快答,老師自己看誰卡住;書面的正式版本是實作課開頭的診斷考。

  1. 兩條直線的方程組,解的個數有哪幾種可能?

    0 個、1 個、無限多個。不可能剛好 2 個。

  2. 哪一種列運算要加「不為 0」的條件?為什麼?

    Scaling。乘 0 會把方程式變成 $0 = 0$,限制條件消失,而且沒辦法復原。

  3. RREF 最後一列是 $[\,0 \;\; 0 \;\; 0 \mid 7\,]$,代表什麼?

    $0 = 7$,矛盾,方程組無解。
