向量方程與 Ax = b

同一個方程組,換成向量的語言:解方程組 = 找權重,讓幾個向量組合出目標向量。這週最重要的一句話是「Ax 就是 A 各行的線性組合」。

03

解集結構與線性獨立

解有無限多個時,解集長什麼樣子?答案是「一個特解,加上齊次方程的所有解」——一條線、一個平面,平移到別的地方。同一個齊次方程換個角度看,就是這週的新觀念:這些向量裡有沒有多餘的?

04

線性變換

把矩陣看成一台機器:丟進一個向量,吐出另一個向量。旋轉、縮放、剪切、投影都是這樣的機器,而且每一台「線性」的機器,都能寫成一個矩陣——只要看它把 e1、e2 送到哪裡。

05

矩陣乘法與反矩陣

上週每個線性變換都變成了一個矩陣。這週把兩台機器接起來——先做 B 再做 A,就是乘一個矩陣 AB;想把動作倒回去,就是反矩陣。最後用齊次座標補上「平移」,湊齊 2D 繪圖引擎會用到的全部零件。
