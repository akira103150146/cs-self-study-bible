解集結構與線性獨立

一張學生成績表有「國文、英文、數學、總分」四欄。總分那一欄有提供新資訊嗎?沒有——它可以由另外三欄算出來。這週要把「多餘」這件事講精確:線性相依。在這之前,先回答上週留下的問題:解有無限多個時,解集長什麼樣子(Lay 1.5、1.7)?

下課鐘響時,學生要能做到

  • 判斷齊次方程組有沒有非平凡解,並把解集寫成 $\operatorname{Span}\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$。
  • 用課本方框的四個步驟,把相容方程組的解寫成參數向量形式 $\mathbf{x} = \mathbf{p} + t\mathbf{v}$(或多個參數)。
  • 說出 Theorem 6 的幾何意義:$A\mathbf{x} = \mathbf{b}$ 的解集是 $A\mathbf{x} = \mathbf{0}$ 的解集平移 $\mathbf{p}$,並說明為什麼要求相容。
  • 用 $A\mathbf{x} = \mathbf{0}$ 判斷一組向量是否線性獨立,相依時寫出一條相依關係。
  • 用「零向量、向量個數、兩個看倍數」三招不用計算判斷相依,並知道每一招的限制。
  • 分清楚「生成 ℝᵐ 看每一列有沒有 pivot」與「線性獨立看每一行有沒有 pivot」。

本週的證明時刻

$A\mathbf{x} = \mathbf{b}$ 的解集 = 特解 + 齊次解(Theorem 6,課本 p. 73;證明分成 Practice Problem 3 與 Exercise 37 兩半)。關鍵想法:證明「兩個集合相等」要證兩個方向。第一步 $A(\mathbf{p} + \mathbf{v}_h) = \mathbf{b} + \mathbf{0}$;第二步對任一個解 $\mathbf{w}$,定義 $\mathbf{v}_h = \mathbf{w} - \mathbf{p}$,再驗證它是齊次解。兩步都只用上週的 Theorem 5。「相容」這個前提用在第一行:要先有一個 $\mathbf{p}$。

教師版例題裡有完整證明;學生版只列定理、為什麼值得證、關鍵想法,並留空間讓學生跟著寫。 筆試不考「請證明」,考三種變形:哪一步違反前提、舉一個反例、 用在沒看過的情境。

份量說明

開場(10 分)

在黑板上畫一張四欄的成績表,只填三列資料。問:「總分這欄可以刪掉嗎?刪了會不會少了資訊?」學生會說可以,因為算得出來。接著說:如果把每一欄看成一個向量,「總分 = 國文 + 英文 + 數學」就是一條線性相依關係。這週後半就在講怎麼有系統地找出這種關係。

前半先處理上週的遺留問題:解有無限多個時,能不能把「所有的解」寫得漂亮一點?

觀念 1:齊次方程組(20 分)

觀念(5 分):定義齊次、平凡解。先問「右邊全是 0 的方程組可能無解嗎?」,讓學生說出「全填 0 就是解」。

講解(8 分):例 1(課本 Example 1)算完後停在第 5 步,示範「把 $x_3$ 提出來」。例 2(課本 Example 2)示範兩個自由變數時依自由變數拆開,黑板上用兩種顏色標出含 $x_2$、含 $x_3$ 的項。

練習(7 分):Exercises 1–2、5;是非 Exercises 27、31 口頭問。

觀念 2:參數向量形式與 Theorem 6(30 分)

觀念(7 分):把課本的四步驟方框抄在黑板上。講清楚隱式(方程式)與顯式(參數向量形式)的差別。

講解(13 分):例 1(課本 Example 3)和觀念 1 例 1 並排寫:同一個 $A$、同一個 $\mathbf{v}$,只多了 $\mathbf{p}$。然後畫平移的圖(Figure 5)。例 2(Reasonable Answers)示範「乘三次就驗完整個一般解」。

練習(10 分):Exercises 17、19;Practice Problem 2;是非 Exercises 33、35 口頭問。

證明時刻(15 分)

先問:「如果我已經知道一個解 $\mathbf{p}$,還知道 $A\mathbf{x} = \mathbf{0}$ 的所有解,我能寫出 $A\mathbf{x} = \mathbf{b}$ 的所有解嗎?」讓學生猜 $\mathbf{p} + \mathbf{v}_h$。

黑板分兩欄:左欄「$\mathbf{p} + \mathbf{v}_h$ 是解」(3 分鐘),右欄「每個解都是 $\mathbf{p} + \mathbf{v}_h$」(7 分鐘)。右欄的關鍵是「定義 $\mathbf{v}_h = \mathbf{w} - \mathbf{p}$」——這是學生第一次看到「為了證明而造一個東西」的手法,要停下來講。最後問:「相容這個條件用在哪?」(5 分鐘)

觀念 3:線性獨立(35 分)

觀念(8 分):定義。一定先強調「平凡解永遠存在」,獨立是「只有」平凡解。畫一個兩欄對照表,整週保留:左欄「生成 ℝᵐ:看每一列有沒有 pivot」,右欄「線性獨立:看每一行有沒有 pivot」。

講解(15 分):例 1(課本 Example 1)讓學生先猜「三個向量能不能加權抵消成 $\mathbf{0}$」,再算出 $10\mathbf{v}_1 - 5\mathbf{v}_2 + 5\mathbf{v}_3 = \mathbf{0}$。例 2(課本 Example 2)強調「判斷獨立只要梯形,不用 RREF」。

練習(12 分):Exercises 1–2、5;是非 Exercise 21;Exercises 9 與 11(Exercise 10 的 (a)(b) 答案不同,適合討論)。

觀念 4:兩個向量與 Theorem 7(25 分)

觀念(6 分):一個向量、兩個向量的判斷規則;Theorem 7 與它的 Warning。

講解(10 分):例 1(課本 Example 3)看倍數。例 2(課本 Example 4)用三支筆示範:$\mathbf{w}$ 平放在 $\mathbf{u}$、$\mathbf{v}$ 的桌面上 → 相依;立起來 → 獨立。

練習(9 分):Exercises 3–4、16、19;是非 Exercises 22、23 口頭問;Exercise 41 當討論題($\mathbf{v}_1 = \mathbf{0}$ 的陷阱)。

觀念 5:一定相依的兩種情況(30 分)

觀念(7 分):Theorem 8、9,各一句話證明。強調 Warning:$p \le n$ 時 Theorem 8 什麼都沒說。

講解(13 分):例 1(課本 Example 5)先讓全班兩兩檢查倍數,大家都會說「獨立」,再亮出 Theorem 8——整週最好的反直覺時刻。例 2(課本 Example 6)走完「零向量?個數?倍數?」的檢查順序,寫在黑板角落。

練習(10 分):Exercises 7–8、15、17;是非 Exercises 24、25、28;Practice Problem 1 當整合題。

收尾(5 分)

回到開場的成績表:四個欄向量相依,因為「總分 = 三科相加」。預告實作課:用 pandas 讀一張真的資料表,用 matrix_rank 和 rref() 找出哪些欄位是多餘的。實作課開頭有 10 分鐘的診斷考,不計對錯、只看有沒有交。

🧠
學生最常翻的車
  • 以為「有平凡解」等於「有非平凡解」;或以為齊次方程組可能無解。
  • 以為非平凡解的每個分量都不能是 0。
  • 寫參數向量形式時漏掉自由變數本身那個分量,或漏掉整行是 0 的自由變數。
  • 分不清特解 $\mathbf{p}$ 與齊次解;驗算時把齊次向量乘出來期待得到 $\mathbf{b}$。
  • 忘了 Theorem 6 要求相容。
  • 以為各行獨立的條件是「$A\mathbf{x} = \mathbf{0}$ 有平凡解」。
  • 判斷獨立看列、判斷生成看行(剛好弄反)。
  • 對三個以上的向量用「兩兩檢查倍數」判斷獨立。
  • 以為相依集合裡每個向量都是其他的組合。
  • 把 Theorem 8 反過來用:「向量個數不超過分量數 ⇒ 獨立」。

出門檢核(下課前,口頭)

快問快答,老師自己看誰卡住;書面的正式版本是實作課開頭的診斷考。

  1. $A$ 是 $3 \times 5$ 矩陣,$A\mathbf{x} = \mathbf{0}$ 一定有非平凡解嗎?

    一定有。5 個未知數、最多 3 個 pivot,至少 2 個自由變數(也可以用 Theorem 8:5 個行向量在 ℝ³ 裡)。

  2. 已知 $A\mathbf{p} = \mathbf{b}$,且 $A\mathbf{x} = \mathbf{0}$ 的解是 $t\mathbf{v}$,寫出 $A\mathbf{x} = \mathbf{b}$ 的所有解。

    $\mathbf{x} = \mathbf{p} + t\mathbf{v}$,$t$ 為任意實數(Theorem 6)。

  3. $\{(1, 2, 3), (2, 4, 6)\}$ 線性獨立嗎?

    不獨立(相依)。第二個是第一個的 2 倍。

  4. ℝ³ 中三個兩兩不平行的向量,一定獨立嗎?

    不一定。三個可能在同一個平面上(例如 $\mathbf{w} = \mathbf{u} + \mathbf{v}$),那就相依。
