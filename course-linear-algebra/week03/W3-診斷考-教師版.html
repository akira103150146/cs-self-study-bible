第 3 週實作課開頭,10 分鐘內收回。不計對錯、只看有沒有交,學生才會照實作答。

收回後快速看作答分布:如果多數人選了同一個錯誤選項,查下面的迷思對照,先花最多 10 分鐘補那個觀念,再往下上課。

  1. 觀念 1

    For any matrix $A$, which statement about the homogeneous equation $A\mathbf{x} = \mathbf{0}$ is always true?

    1. AIt is consistent.
    2. BIt has a nontrivial solution.
    3. CIt has exactly one solution.
    4. DEvery nontrivial solution has all entries nonzero.
    答案A

    $\mathbf{x} = \mathbf{0}$ 永遠是解,所以齊次方程組一定相容。有沒有非平凡解、解是否唯一,要看有沒有自由變數,不是永遠成立。

    選項代表的迷思回去看
    B以為齊次方程組一定有非零解觀念 1:有自由變數才有非平凡解
    C以為齊次方程組只有 $\mathbf{0}$ 這個解觀念 1 例 1:有自由變數時有無限多解
    D以為非平凡解的每個分量都不能是 0觀念 1 是非題 Exercise 28
  2. 觀念 2

    The reduced echelon form of an augmented matrix $[\,A \;\; \mathbf{b}\,]$ is $\left[\begin{array}{rrr|r} 1 & 0 & -2 & 3 \\ 0 & 1 & 1 & -1 \\ 0 & 0 & 0 & 0 \end{array}\right]$. Which is the general solution of $A\mathbf{x} = \mathbf{b}$ in parametric vector form?

    1. A$\mathbf{x} = \begin{bmatrix} 3 \\ -1 \\ 0 \end{bmatrix} + x_3\begin{bmatrix} 2 \\ -1 \\ 1 \end{bmatrix}$
    2. B$\mathbf{x} = \begin{bmatrix} 3 \\ -1 \\ 0 \end{bmatrix} + x_3\begin{bmatrix} -2 \\ 1 \\ 1 \end{bmatrix}$
    3. C$\mathbf{x} = x_3\begin{bmatrix} 2 \\ -1 \\ 1 \end{bmatrix}$
    4. D$\mathbf{x} = \begin{bmatrix} 2 \\ -1 \\ 1 \end{bmatrix} + x_3\begin{bmatrix} 3 \\ -1 \\ 0 \end{bmatrix}$
    答案A

    $x_1 - 2x_3 = 3$ 移項得 $x_1 = 3 + 2x_3$;$x_2 + x_3 = -1$ 得 $x_2 = -1 - x_3$。常數項 $(3, -1, 0)$ 是特解 $\mathbf{p}$,$x_3$ 的係數 $(2, -1, 1)$ 是齊次解的方向。

    選項代表的迷思回去看
    B移項時忘了變號,直接抄 RREF 的係數觀念 2 例 1 的第 3 步:基本變數用自由變數表示
    C漏掉特解 $\mathbf{p}$,只寫了齊次解觀念 2:解 = 特解 + 齊次解
    D把特解和方向向量的角色弄反觀念 2 白話說:常數項才是 $\mathbf{p}$
  3. 觀念 3

    The columns of a matrix $A$ are linearly independent if and only if ...

    1. A$A\mathbf{x} = \mathbf{0}$ has only the trivial solution.
    2. B$A\mathbf{x} = \mathbf{0}$ has the trivial solution.
    3. C$A$ has a pivot position in every row.
    4. D$A\mathbf{x} = \mathbf{b}$ has a solution for every $\mathbf{b}$.
    答案A

    各行獨立 ⇔ $x_1\mathbf{a}_1 + \cdots + x_n\mathbf{a}_n = \mathbf{0}$ 只有全 0 的解 ⇔ $A\mathbf{x} = \mathbf{0}$ 只有平凡解 ⇔ 每一行都是 pivot 行。

    選項代表的迷思回去看
    B漏了「只有」——平凡解永遠存在觀念 3 是非題 Exercise 21
    C把「看列」(生成)和「看行」(獨立)搞混觀念 3 白話說的對照
    D把線性獨立和上週的「生成 ℝᵐ」(Theorem 4)搞混觀念 3 白話說的對照
  4. 觀念 4

    Which set is linearly dependent?

    1. A$\left\{\begin{bmatrix} 1 \\ 2 \end{bmatrix}, \begin{bmatrix} 2 \\ 1 \end{bmatrix}\right\}$
    2. B$\left\{\begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix}, \begin{bmatrix} -2 \\ -4 \\ -6 \end{bmatrix}\right\}$
    3. C$\left\{\begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix}\right\}$
    4. D$\left\{\begin{bmatrix} 2 \\ 4 \\ 6 \end{bmatrix}, \begin{bmatrix} 1 \\ 2 \\ 4 \end{bmatrix}\right\}$
    答案B

    兩個向量,看倍數:$(-2, -4, -6) = -2(1, 2, 3)$,是倍數,所以相依。D 的前兩個分量是 2 倍,第三個不是($4 \cdot 2 = 8 \neq 6$),不是倍數。

    選項代表的迷思回去看
    A看到分量用的是同樣的數字就以為相依觀念 4 例 1:要看是不是倍數
    C以為「向量個數比分量數少」就一定相依觀念 4:兩個向量只看倍數
    D只比了前兩個分量觀念 4 易錯點:每個分量都要對得上才是倍數
  5. 觀念 5

    A set contains 4 vectors in $\mathbb{R}^3$, and no vector in the set is a multiple of another. What can you conclude?

    1. AThe set is linearly independent, because no two vectors are multiples.
    2. BThe set is linearly independent, as long as it does not contain the zero vector.
    3. CThe set is linearly dependent.
    4. DNothing, unless we row reduce.
    答案C

    4 個向量、每個只有 3 個分量,$4 > 3$,由 Theorem 8 一定相依,不用計算。

    選項代表的迷思回去看
    A把「兩個向量看倍數」用在四個向量上觀念 5 例 1:兩兩不是倍數仍可能相依
    B以為只要沒有零向量就獨立觀念 5:Theorem 9 只說有零向量一定相依,反過來不成立
    D不知道 Theorem 8 可以直接判斷觀念 5 例 2 的檢查順序
