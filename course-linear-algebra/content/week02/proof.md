## 定理
Let $A$ be an $m \times n$ matrix. The equation $A\mathbf{x} = \mathbf{b}$ has a solution for each $\mathbf{b}$ in $\mathbb{R}^m$ if and only if $A$ has a pivot position in every row. (Theorem 4, (a) ⇔ (d))

## 為什麼值得證
「對**每一個** $\mathbf{b}$ 都有解」是一句關於無限多個方程式的話,不可能一個一個試。這個定理把它換成一件**化簡一次就能檢查**的事:數 $A$ 的 pivot。以後判斷「行向量能不能生成 ℝᵐ」都靠它。

證明本身也值得學:兩個方向用了兩種不同的論證——一個是直接推,一個是**找反例**(建構一個讓方程式無解的 $\mathbf{b}$)。

## 關鍵想法
化簡 $[\,A \;\; \mathbf{b}\,]$ 時,左半邊 $A$ 會變成它的梯形 $U$,**不管 $\mathbf{b}$ 是什麼,$U$ 都一樣**。矛盾只可能出現在 $U$ 的全 0 列:

- $U$ 沒有全 0 列 → 永遠不會出現 $0 = $ 非零數 → 一定有解。
- $U$ 有全 0 列 → 故意挑一個讓那一列右邊是 1 的 $\mathbf{b}$ → 無解。這個 $\mathbf{b}$ 要**倒推**回去找,靠的是「列運算可以復原」。

## 證明
設 $U$ 是 $A$ 的一個梯形。對任意 $\mathbf{b}$,把 $[\,A \;\; \mathbf{b}\,]$ 用**同一串**列運算化簡,會得到 $[\,U \;\; \mathbf{d}\,]$,其中 $\mathbf{d}$ 是 ℝᵐ 中的某個向量(由 $\mathbf{b}$ 決定)。

**(d) ⇒ (a)。** 假設 $A$ 的每一列都有 pivot,也就是 $U$ 的每一列都有 pivot。每一列最多一個 pivot,而且它們都在 $U$ 的行(左半邊)裡,所以最後一行(增廣的那一行)**不可能**是 pivot 行。由第 1 週的存在與唯一性定理,方程組相容。$\mathbf{b}$ 是任意的,所以 (a) 成立。

**(a) ⇒ (d)**(改證它的逆否:**(d) 不成立 ⇒ (a) 不成立**)。假設 $A$ 不是每一列都有 pivot。梯形的 pivot 由上往下排,所以沒有 pivot 的列在最下面,$U$ 的**最後一列全是 0**。

1. 取 $\mathbf{d}$ 為最後一個分量是 1 的向量,例如 $\mathbf{d} = (0, \dots, 0, 1)$。那麼 $[\,U \;\; \mathbf{d}\,]$ 的最後一列是 $[\,0 \;\; \cdots \;\; 0 \mid 1\,]$,也就是 $0 = 1$:**無解**。
2. 列運算可以復原(第 1 週的證明時刻)。把「從 $A$ 化到 $U$」的那串列運算**倒著做**,$[\,U \;\; \mathbf{d}\,]$ 會變回 $[\,A \;\; \mathbf{b}\,]$ 的形式,右邊變成某個向量 $\mathbf{b}$。
3. 列運算不改變解集,所以 $A\mathbf{x} = \mathbf{b}$ 和 $U\mathbf{x} = \mathbf{d}$ 一樣**無解**。

我們找到了一個讓 $A\mathbf{x} = \mathbf{b}$ 無解的 $\mathbf{b}$,所以 (a) 不成立。$\blacksquare$

**課堂上用例 1(課本 Example 3)當具體的例子**:$U$ 的第三列全是 0,$\mathbf{b} = (1, 0, 0)$ 就讓 $b_1 - \tfrac12 b_2 + b_3 = 1 \neq 0$,無解。考試不會要求寫出這個證明,會考「為什麼 $3 \times 2$ 矩陣的行不可能生成 ℝ³」這類直接套用的題目。
