## 學習目標
- 判斷一條式子是不是線性方程式;分清楚「解」與「解集」;說出解只有三種情況與各自的直線圖像。
- 把方程組寫成係數矩陣與增廣矩陣,用三種基本列運算化簡,每一步寫出操作記號。
- 化到三角形式就能回答「有沒有解、解是不是唯一」。
- 用五步驟的列化簡演算法把矩陣化成 RREF,指出 pivot 位置與 pivot 行。
- 從 RREF 寫出一般解(自由變數當參數),並用 Theorem 2 判斷無解/唯一解/無限多解。
- 說出「列運算不改變解集」的理由:每種列運算都能復原。

## 證明時刻
**列運算不改變解集**——整個消去法的正當性都靠這一句(課本 p. 31)。關鍵想法只有一個:每種列運算都能被另一個列運算**復原**。課堂上只示範 replacement 的雙向論證(舊解 ⇒ 新解、新解 ⇒ 舊解),interchange 和 scaling 口頭帶過,最後點出 scaling 的「$c \neq 0$」在哪一步被用到。觀念 2 的「幾何意義」圖可以當開場:線換了,交點沒動。

### 觀念 1:線性方程組與解集(20 分)
**觀念**(5 分):線性方程式的定義,只看未知數有沒有次方、互乘、開根號。講清楚「解」和「解集」的差別(是非題 31 會考)。

**講解**(8 分):例 1 讓學生舉手投票四條式子是不是線性,$\sqrt{6}$ 和 $\sqrt{x_1}$ 一定會有人搞混,正好帶出判斷準則。例 3 三小題並排做,一定要畫三張圖;(b) 算到 $0 = 2$ 時停下來問:「這代表什麼?」

**練習**(7 分):照做 1–3。Practice Problem 3 巡堂看誰只代了前兩條。

### 觀念 2:矩陣表示與基本列運算(30 分)
**觀念**(6 分):把方程組寫在左邊、增廣矩陣寫在右邊,用箭頭一個一個對應。強調「列是橫的、行是直的」「$m \times n$ 列數在前」。三種列運算各舉一個小例子。

**講解**(14 分):例 2(課本 Example 1)是本週第一個完整的消去,**黑板左右兩欄同時寫方程式與矩陣**,每一步都寫操作記號。最後一定要驗算,並帶一次「合理性檢查」那個例子。

**練習**(10 分):照做 1、2 全班寫完再往下;是非題四題每題 30 秒口頭問答。

### 證明時刻(15 分)
先問:「我們把矩陣改來改去,憑什麼最後的解就是原題的解?」讓學生意識到這不是理所當然。秀出觀念 2 的幾何意義圖:線換了,交點沒動。

黑板分兩欄:左欄「舊解 ⇒ 新解」、右欄「新解 ⇒ 舊解」,只做 replacement。右欄做完時點出:「剛剛『減去 $c$ 倍』,就是把列運算復原。」最後問:「scaling 為什麼要規定不能乘 0?」讓學生回答「因為乘 0 就回不去了」。

## 迷思清單
- 以為方程組可能剛好有兩個解。
- 把「解」和「解集」混為一談。
- 看到 $\sqrt{6}\,x_2$ 就說不是線性方程式;或反過來,沒發現 $\sqrt{x_1}$ 不是線性。
- 驗算只代一條方程式。
- 算到 $0 = 2$ 以為自己算錯,回頭重算。
- 「列」和「行」搞混;把 $m \times n$ 寫成行數在前。
- 做 $R_3 \leftarrow R_3 + (-5)R_1$ 時把第 1 列也改掉。
- 把「某列乘以 0」當成合法的列運算。
- 在原矩陣上圈 pivot,而不是在化簡後的梯形上圈。
- 往前階段遇到某一行剩下的部分全是 0 時卡住,或硬拿 0 當 pivot。
- 把全 0 列 $[\,0 \;\; 0 \;\; 0 \mid 0\,]$ 當成無解。
- 以為有自由變數就代表題目算錯了;一般解漏掉沒出現在方程式裡的未知數。

## 出門檢核
### 兩條直線的方程組,解的個數有哪幾種可能?
0 個、1 個、無限多個。不可能剛好 2 個。

### 哪一種列運算要加「不為 0」的條件?為什麼?
Scaling。乘 0 會把方程式變成 $0 = 0$,限制條件消失,而且沒辦法復原。

### RREF 最後一列是 $[\,0 \;\; 0 \;\; 0 \mid 7\,]$,代表什麼?
$0 = 7$,矛盾,方程組無解(最後一行是 pivot 行)。

### 方程組相容,而且有一個自由變數,解有幾個?
無限多個(Theorem 2)。
