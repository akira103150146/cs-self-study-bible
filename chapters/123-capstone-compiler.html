二、設計我們的語言:Mini

在動手寫程式碼之前,先把目標語言的語法釘清楚。 我們的語言叫 Mini,支援:變數指派、算術與比較運算、if/else、while 迴圈、函式定義與呼叫、以及一個內建的 print。

一段 Mini 程式看起來像這樣:

// 計算費波那契數列
func fib(n) {
    if n <= 1 {
        return n;
    }
    return fib(n - 1) + fib(n - 2);
}

x = 10;
print(fib(x));   // 輸出 55

用擴充巴科斯-諾爾範式(EBNF, Extended Backus-Naur Form)描述 Mini 的完整文法:

program    = statement* EOF
statement  = assign | if_stmt | while_stmt | func_def
           | return_stmt | print_stmt | expr_stmt
assign     = IDENT '=' expr ';'
if_stmt    = 'if' expr block ('else' block)?
while_stmt = 'while' expr block
func_def   = 'func' IDENT '(' params? ')' block
return_stmt= 'return' expr ';'
print_stmt = 'print' '(' expr ')' ';'
expr_stmt  = expr ';'
block      = '{' statement* '}'
params     = IDENT (',' IDENT)*

// 運算式(由低到高優先級)
expr       = equality
equality   = comparison (('==' | '!=') comparison)*
comparison = addition   (('<' | '>' | '<=' | '>=') addition)*
addition   = multiply   (('+' | '-') multiply)*
multiply   = unary      (('*' | '/') unary)*
unary      = ('-' | '!') unary | primary
primary    = NUMBER | STRING | IDENT ('(' args? ')')? | '(' expr ')'
args       = expr (',' expr)*
ℹ️
CFG 與可解析性

這份文法是一個上下文無關文法(CFG, Context-Free Grammar)。 計算理論(本書第 §49 章)告訴我們:CFG 生成的語言可以被下推自動機(PDA)辨識。 我們的遞迴下降解析器,本質上就是一個手寫的 PDA——呼叫堆疊扮演「下推儲存」的角色。

里程碑 1 — 詞法分析器(Lexer / Tokenizer)

詞法分析(lexical analysis)把原始碼的字元流(character stream)切成 一個個有意義的記號(token)。 例如 x = 10 + 3; 被切成: IDENT("x") ASSIGN NUM(10) PLUS NUM(3) SEMI。

從計算理論的角度看(本書 §49 章),每種 token 對應一種正規語言(regular language), 可以用有限自動機(FA, Finite Automaton)辨識。 Lexer 就是把這些 FA 組合起來,貪婪地吃字元、吐 token。

1.1 Token 類型

from enum import Enum, auto

class TT(Enum):
    # 字面量
    NUM    = auto()      # 數字  e.g. 3.14
    STR    = auto()      # 字串  e.g. "hello"
    IDENT  = auto()      # 識別子 e.g. foo_bar
    # 算術運算子
    PLUS   = auto()      # +
    MINUS  = auto()      # -
    STAR   = auto()      # *
    SLASH  = auto()      # /
    # 比較運算子
    EQ     = auto()      # ==
    NEQ    = auto()      # !=
    LT     = auto()      # <
    GT     = auto()      # >
    LEQ    = auto()      # <=
    GEQ    = auto()      # >=
    # 其他符號
    ASSIGN = auto()      # =
    BANG   = auto()      # !
    LPAREN = auto(); RPAREN = auto()   # ( )
    LBRACE = auto(); RBRACE = auto()   # { }
    SEMI   = auto(); COMMA  = auto()   # ; ,
    # 關鍵字
    IF = auto(); ELSE   = auto(); WHILE  = auto()
    FUNC = auto(); RETURN = auto(); PRINT = auto()
    EOF    = auto()

# 關鍵字對映表
KEYWORDS = {
    'if': TT.IF, 'else': TT.ELSE, 'while': TT.WHILE,
    'func': TT.FUNC, 'return': TT.RETURN, 'print': TT.PRINT,
}

class Token:
    __slots__ = ('type', 'val', 'line')
    def __init__(self, type, val, line):
        self.type, self.val, self.line = type, val, line
    def __repr__(self):
        return f"Token({self.type.name}, {self.val!r}, ln={self.line})"

1.2 Lexer 實作

class Lexer:
    def __init__(self, src: str):
        self.src  = src
        self.pos  = 0
        self.line = 1

    # ── 輔助方法 ──────────────────────────────────
    def peek(self):
        """看目前字元但不移動"""
        return self.src[self.pos] if self.pos < len(self.src) else '\0'

    def advance(self):
        """讀取並移動一格"""
        ch = self.src[self.pos]; self.pos += 1
        if ch == '\n': self.line += 1
        return ch

    def match(self, expected):
        """若下一個字元是 expected 則吃掉,回傳 True"""
        if self.peek() == expected:
            self.advance(); return True
        return False

    def skip_ws(self):
        """跳過空白與 // 單行注釋"""
        while self.pos < len(self.src):
            c = self.peek()
            if c in ' \t\r\n':
                self.advance()
            elif c == '/' and self.src[self.pos:self.pos+2] == '//':
                while self.peek() not in ('\n', '\0'):
                    self.advance()
            else:
                break

    # ── 字元群讀取 ────────────────────────────────
    def read_num(self):
        """讀取整數或浮點數,回傳 float"""
        s = self.pos
        while self.peek().isdigit(): self.advance()
        if self.peek() == '.':
            self.advance()
            while self.peek().isdigit(): self.advance()
        return float(self.src[s:self.pos])

    def read_str(self):
        """讀取 "..." 字串字面量(支援 \n \t \\ \")"""
        buf = []
        while self.peek() not in ('"', '\0'):
            ch = self.advance()
            if ch == '\\':
                esc = self.advance()
                buf.append({'n':'\n','t':'\t','\\':'\\','"':'"'}.get(esc, esc))
            else:
                buf.append(ch)
        if self.peek() == '\0':
            raise SyntaxError(f"ln{self.line}: 字串字面量未終止")
        self.advance()           # 吃掉結尾的 "
        return ''.join(buf)

    def read_ident(self):
        """讀取識別子或關鍵字"""
        s = self.pos
        while self.peek().isalnum() or self.peek() == '_':
            self.advance()
        return self.src[s:self.pos]

    # ── 主掃描迴圈 ────────────────────────────────
    def next_token(self) -> Token:
        self.skip_ws()
        if self.pos >= len(self.src):
            return Token(TT.EOF, None, self.line)
        ln, ch = self.line, self.advance()

        # 數字
        if ch.isdigit():
            self.pos -= 1
            return Token(TT.NUM, self.read_num(), ln)
        # 字串
        if ch == '"':
            return Token(TT.STR, self.read_str(), ln)
        # 識別子 / 關鍵字
        if ch.isalpha() or ch == '_':
            self.pos -= 1
            name = self.read_ident()
            return Token(KEYWORDS.get(name, TT.IDENT), name, ln)

        # 單字元運算子
        simple = {
            '+': TT.PLUS,  '-': TT.MINUS, '*': TT.STAR,  '/': TT.SLASH,
            '(': TT.LPAREN,')': TT.RPAREN,'{': TT.LBRACE,'}': TT.RBRACE,
            ';': TT.SEMI,  ',': TT.COMMA,
        }
        if ch in simple:
            return Token(simple[ch], ch, ln)

        # 雙字元運算子
        if ch == '=':
            if self.match('='): return Token(TT.EQ,  '==', ln)
            return Token(TT.ASSIGN, '=', ln)
        if ch == '!':
            if self.match('='): return Token(TT.NEQ, '!=', ln)
            return Token(TT.BANG, '!', ln)
        if ch == '<':
            if self.match('='): return Token(TT.LEQ, '<=', ln)
            return Token(TT.LT, '<', ln)
        if ch == '>':
            if self.match('='): return Token(TT.GEQ, '>=', ln)
            return Token(TT.GT, '>', ln)

        raise SyntaxError(f"ln{self.line}: 未知字元 {ch!r}")

    def tokenize(self):
        """掃描全部原始碼,回傳 token 列表"""
        toks = []
        while True:
            t = self.next_token()
            toks.append(t)
            if t.type == TT.EOF: break
        return toks

⚠️
關鍵字 vs 識別子

Lexer 必須先讀完整個識別子再查 KEYWORDS。 若提前比較字元,ifx 會被誤認為 if 加上 x——這叫「最長匹配(maximal munch)」原則。

✏️ 里程碑 1 驗收 實作

為 Mini 加入取餘運算子 %。你需要:(1) 在 TT 加入 PERCENT = auto();(2) 在 Lexer 的 simple 字典加入 '%': TT.PERCENT;(3) 在後面的 Parser 中為 TT.PERCENT 設定與 *、/ 相同的結合力;(4) 在直譯器的 eval_expr 加入 if op == '%': return lv % rv。完成後驗收:Lexer('10 % 3;').tokenize() 應看到 PERCENT token,且 Mini 能正確計算 print(10 % 3); 輸出 1.0。

看解答骨架

# (2) Lexer.next_token 的 simple 字典
'%': TT.PERCENT,

# (3) Parser 的 LBP 加入(與 * / 同級 = 40)
TT.PERCENT: 40,

# (4) Interpreter.eval_expr 的 BinOp 分支
if op == '%': return lv % rv

# 驗收

里程碑 2 — 語法分析器:遞迴下降 + Pratt Parsing

Parser 的任務是把平坦的 token 串流轉換成一棵反映語法結構的樹。 最困難的部分在於運算子優先級: 1 + 2 * 3 應該解析為 1 + (2 * 3) 而非 (1 + 2) * 3。

傳統做法是為每個優先級寫一層函式(equality → comparison → addition → multiply → unary → primary)。 這完全可行,但有個更優雅的方案: Pratt 解析(Pratt parsing / Top-Down Operator Precedence), 由 Vaughan Pratt 於 1973 年提出。

2.1 Pratt 的核心直覺:結合力

給每個二元運算子一個數字——左結合力(Left-Binding Power, LBP)。 數字越大,「吸引」兩側運算元的力量越強。 解析時,只要下一個運算子的 LBP 大於目前的臨界值,就繼續往右吃。

2.2 AST 節點定義

# ── AST 節點 ─────────────────────────────────────────────

class Num:       # 數字字面量
    def __init__(self, value): self.value = value

class Str:       # 字串字面量
    def __init__(self, value): self.value = value

class Var:       # 變數參考
    def __init__(self, name): self.name = name

class BinOp:     # 二元運算  op ∈ {'+','-','*','/','<','>','<=','>=','==','!='}
    def __init__(self, op, left, right):
        self.op, self.left, self.right = op, left, right

class Unary:     # 一元運算  op ∈ {'-','!'}
    def __init__(self, op, operand):
        self.op, self.operand = op, operand

class Assign:    # 指派語句  name = value
    def __init__(self, name, value): self.name, self.value = name, value

class Block:     # 語句序列  { stmt* }
    def __init__(self, stmts): self.stmts = stmts

class IfStmt:    # if cond then [else else_blk]
    def __init__(self, cond, then_blk, else_blk=None):
        self.cond = cond; self.then_blk = then_blk; self.else_blk = else_blk

class WhileStmt: # while cond body
    def __init__(self, cond, body): self.cond, self.body = cond, body

class FuncDef:   # func name(params) body
    def __init__(self, name, params, body):
        self.name, self.params, self.body = name, params, body

class Call:      # name(args)
    def __init__(self, name, args): self.name, self.args = name, args

class ReturnStmt:
    def __init__(self, value): self.value = value

class PrintStmt:
    def __init__(self, value): self.value = value

2.3 Pratt Parser 實作

# 各二元運算子的左結合力 (Left-Binding Power)
LBP = {
    TT.EQ:    10, TT.NEQ:   10,   # ==  !=
    TT.LT:    20, TT.GT:    20,   # <   >
    TT.LEQ:   20, TT.GEQ:   20,   # <=  >=
    TT.PLUS:  30, TT.MINUS: 30,   # +   -
    TT.STAR:  40, TT.SLASH: 40,   # *   /
}

class Parser:
    def __init__(self, tokens):
        self.tokens = tokens
        self.pos    = 0

    def cur(self): return self.tokens[self.pos]
    def eat(self):
        t = self.tokens[self.pos]
        if t.type != TT.EOF: self.pos += 1
        return t
    def expect(self, tt):
        t = self.eat()
        if t.type != tt:
            raise SyntaxError(f"ln{t.line}: 預期 {tt.name},得到 {t.type.name} ({t.val!r})")
        return t
    def check(self, tt): return self.cur().type == tt
    def match(self, tt):
        if self.check(tt): self.eat(); return True
        return False

    # ════════════════════════════════════════════════════
    # Pratt 核心
    # ════════════════════════════════════════════════════
    def expr(self, rbp=0):
        """
        解析一個運算式,rbp = 呼叫者的右結合力(right-binding power)。
        只要下一個 token 的 LBP > rbp,就繼續把它吃進來。
        """
        t    = self.eat()
        left = self.nud(t)                              # 前置語意(prefix)
        while LBP.get(self.cur().type, 0) > rbp:      # 繼續吃 LBP 更強的運算子
            t    = self.eat()
            left = self.led(left, t)                    # 中置語意(infix)
        return left

    def nud(self, t):
        """null denotation:token 出現在前置(prefix)位置時的語意"""
        if t.type == TT.NUM:   return Num(t.val)
        if t.type == TT.STR:   return Str(t.val)
        if t.type == TT.IDENT:
            if self.check(TT.LPAREN):           # 函式呼叫 f(...)
                self.eat()                      # 吃掉 '('
                args = []
                if not self.check(TT.RPAREN):
                    args.append(self.expr(0))
                    while self.match(TT.COMMA):
                        args.append(self.expr(0))
                self.expect(TT.RPAREN)
                return Call(t.val, args)
            return Var(t.val)                   # 普通變數參考
        if t.type == TT.MINUS: return Unary('-', self.expr(50))  # 前置 -
        if t.type == TT.BANG:  return Unary('!', self.expr(50))  # 前置 !
        if t.type == TT.LPAREN:                 # 括號分組 (...)
            e = self.expr(0)
            self.expect(TT.RPAREN)
            return e
        raise SyntaxError(f"ln{t.line}: 未預期的 token {t.type.name}")

    def led(self, left, t):
        """
        left denotation:token 出現在中置(infix)位置時的語意。
        傳入 LBP[t.type] 作為 rbp,確保左結合性:
        '1 - 2 - 3' → (1-2)-3,而非 1-(2-3)。
        """
        return BinOp(t.val, left, self.expr(LBP[t.type]))

    # ════════════════════════════════════════════════════
    # 語句解析
    # ════════════════════════════════════════════════════
    def statement(self):
        t = self.cur()
        if t.type == TT.IF:     return self._if()
        if t.type == TT.WHILE:  return self._while()
        if t.type == TT.FUNC:   return self._func()
        if t.type == TT.RETURN:
            self.eat()
            v = self.expr(0); self.expect(TT.SEMI)
            return ReturnStmt(v)
        if t.type == TT.PRINT:
            self.eat()
            self.expect(TT.LPAREN)
            v = self.expr(0)
            self.expect(TT.RPAREN); self.expect(TT.SEMI)
            return PrintStmt(v)
        # 運算式語句 或 指派語句
        e = self.expr(0)
        if self.match(TT.ASSIGN):        # name = value;
            if not isinstance(e, Var):
                raise SyntaxError("指派目標必須是識別子")
            val = self.expr(0); self.expect(TT.SEMI)
            return Assign(e.name, val)
        self.expect(TT.SEMI)
        return e                         # 純運算式語句

    def block(self):
        self.expect(TT.LBRACE)
        stmts = []
        while not self.check(TT.RBRACE) and not self.check(TT.EOF):
            stmts.append(self.statement())
        self.expect(TT.RBRACE)
        return Block(stmts)

    def _if(self):
        self.expect(TT.IF)
        cond = self.expr(0)
        then = self.block()
        else_ = self.block() if self.match(TT.ELSE) else None
        return IfStmt(cond, then, else_)

    def _while(self):
        self.expect(TT.WHILE)
        cond = self.expr(0); body = self.block()
        return WhileStmt(cond, body)

    def _func(self):
        self.expect(TT.FUNC)
        name = self.expect(TT.IDENT).val
        self.expect(TT.LPAREN)
        params = []
        if not self.check(TT.RPAREN):
            params.append(self.expect(TT.IDENT).val)
            while self.match(TT.COMMA):
                params.append(self.expect(TT.IDENT).val)
        self.expect(TT.RPAREN)
        return FuncDef(name, params, self.block())

    def parse(self):
        stmts = []
        while not self.check(TT.EOF):
            stmts.append(self.statement())
        return Block(stmts)
🔑
Pratt 解析的魔法

expr(rbp) 的迴圈條件 LBP[cur] > rbp 只有一行,卻同時處理了優先級與左結合性:
• 優先級:LBP(*)=40 > LBP(+)=30,所以 1+2*3 的 * 會被 right-side 的 expr(30) 吸進去,變成 1+(2*3)。
• 左結合:led 傳入 LBP[t](不是 -1),所以相同優先級的運算子不再被右吸,1-2-3 解析為 (1-2)-3。

          return Num(3)
        return BinOp('+', Num(2), Num(3))
      left = BinOp('+', Num(2), Num(3))
      cur=RPAREN, LBP=0 > 0? NO
      return BinOp('+', Num(2), Num(3))
    expect(RPAREN) → 吃掉 ')'
    return BinOp('+', Num(2), Num(3))   ← nud 的返回值
  left = BinOp('+', Num(2), Num(3))
  cur=STAR, LBP=40 > 0? YES → eat STAR
  led(left, STAR):
    expr(40)
      eat → Token(NUM, 4)
      nud(NUM) → Num(4)
      cur=SEMI/EOF, LBP=0 > 40? NO
      return Num(4)
    return BinOp('*', BinOp('+',Num(2),Num(3)), Num(4))
  left = BinOp('*', BinOp('+',Num(2),Num(3)), Num(4))
  cur=EOF, LBP=0 > 0? NO
  return BinOp('*', BinOp('+',Num(2),Num(3)), Num(4))

最終 AST:

BinOp('*')
├── BinOp('+')
│   ├── Num(2)
│   └── Num(3)
└── Num(4)

求值:先算 2+3=5,再算 5*4=20。括號確保 + 被 nud(括號的語意)整個包起來再返回,使 * 的左子節點是整個 BinOp('+',...)。

里程碑 3 — AST 與樹走訪直譯器

有了 AST,最快讓語言「跑起來」的方式是樹走訪直譯器(tree-walking interpreter): 直接遞迴走訪每個 AST 節點、求值、執行——不需要任何中間表示。 CPython 早期版本就是這樣做的(後來改成位元碼)。

3.1 作用域環境

class ReturnValue(Exception):
    """用 Exception 傳遞 return 值——這是實作 early return 的標準技巧"""
    def __init__(self, value): self.value = value

class Env:
    """
    作用域鏈(scope chain):每個 Env 是一層作用域,parent 指向外層。
    查變數時從內層一層一層往外找。
    """
    def __init__(self, parent=None):
        self.vars   = {}
        self.parent = parent

    def get(self, name):
        if name in self.vars:    return self.vars[name]
        if self.parent:          return self.parent.get(name)
        raise NameError(f"未定義變數:{name}")

    def set(self, name, val):
        """
        指派:在最近的已定義層修改;若無則在當前層定義。
        簡化版:Mini 採「定義即指派」語意。
        """
        if name in self.vars or self.parent is None:
            self.vars[name] = val
        elif self.parent:
            self.parent.set(name, val)

    def define(self, name, val):
        """強制在當前層建立新綁定(用於函式參數)"""
        self.vars[name] = val

3.2 樹走訪直譯器

class Interpreter:
    def __init__(self):
        self.globals = Env()
        self.funcs   = {}          # 函式定義表

    # ── 運算式求值 ────────────────────────────────
    def eval_expr(self, node, env):
        if isinstance(node, Num):    return node.value
        if isinstance(node, Str):    return node.value
        if isinstance(node, Var):    return env.get(node.name)

        if isinstance(node, Unary):
            v = self.eval_expr(node.operand, env)
            return -v if node.op == '-' else not v

        if isinstance(node, BinOp):
            lv = self.eval_expr(node.left,  env)
            rv = self.eval_expr(node.right, env)
            op = node.op
            if op == '+':   return lv + rv
            if op == '-':   return lv - rv
            if op == '*':   return lv * rv
            if op == '/':
                if rv == 0: raise ZeroDivisionError("Mini: 除以零")
                return lv / rv
            if op == '<':   return lv < rv
            if op == '>':   return lv > rv
            if op == '<=':  return lv <= rv
            if op == '>=':  return lv >= rv
            if op == '==':  return lv == rv
            if op == '!=':  return lv != rv

        if isinstance(node, Call):
            fn = self.funcs.get(node.name)
            if fn is None:
                raise NameError(f"未定義函式:{node.name}")
            args = [self.eval_expr(a, env) for a in node.args]
            local = Env(self.globals)              # 函式在全域作用域下執行
            for p, a in zip(fn.params, args):
                local.define(p, a)
            try:
                self.exec_block(fn.body, local)
            except ReturnValue as rv:
                return rv.value
            return None

        raise TypeError(f"未知 AST 節點:{type(node).__name__}")

    # ── 語句執行 ──────────────────────────────────
    def exec_stmt(self, stmt, env):
        if isinstance(stmt, Assign):
            env.set(stmt.name, self.eval_expr(stmt.value, env))
        elif isinstance(stmt, PrintStmt):
            print(self.eval_expr(stmt.value, env))
        elif isinstance(stmt, IfStmt):
            if self.eval_expr(stmt.cond, env):
                self.exec_block(stmt.then_blk, Env(env))
            elif stmt.else_blk:
                self.exec_block(stmt.else_blk, Env(env))
        elif isinstance(stmt, WhileStmt):
            while self.eval_expr(stmt.cond, env):
                self.exec_block(stmt.body, Env(env))
        elif isinstance(stmt, FuncDef):
            self.funcs[stmt.name] = stmt     # 把函式存入全域函式表
        elif isinstance(stmt, ReturnStmt):
            raise ReturnValue(self.eval_expr(stmt.value, env))
        else:
            self.eval_expr(stmt, env)        # 運算式語句:求值後丟棄

    def exec_block(self, block, env):
        for s in block.stmts:
            self.exec_stmt(s, env)

    def run(self, source: str):
        """一站式:原始碼 → 詞法 → 語法 → 執行"""
        tokens = Lexer(source).tokenize()
        ast    = Parser(tokens).parse()
        self.exec_block(ast, self.globals)

完整執行一段 Mini 程式:

src = """
func fib(n) {
    if n <= 1 { return n; }
    return fib(n - 1) + fib(n - 2);
}
print(fib(10));
"""
Interpreter().run(src)   # 輸出:55.0

在直譯器中為 Mini 加入邏輯運算子 and 與 or(短路求值)。步驟:(1) 在 TT 加入 AND = auto()、OR = auto();(2) 在 KEYWORDS 加入 'and': TT.AND, 'or': TT.OR;(3) 在 LBP 設定 TT.OR: 5, TT.AND: 8(優先級低於比較);(4) 在 led 函式加入短路邏輯:不能直接用 Python 的 + 之類;需要在 eval_expr 的 BinOp 分支加入特判。驗收:Interpreter().run('print(0 or 5);') 輸出 5;print(1 and 0); 輸出 0。

看解答骨架

AND = auto(); OR = auto()

# KEYWORDS
'and': TT.AND, 'or': TT.OR,

# LBP(低於比較運算子 20)
TT.OR:  5,
TT.AND: 8,

# eval_expr:在處理 BinOp 其餘運算子前,先特判 and/or 實現短路求值
if isinstance(node, BinOp) and node.op in ('and', 'or'):
    lv = self.eval_expr(node.left, env)
    if node.op == 'and':
        return lv if not lv else self.eval_expr(node.right, env)

Interpreter().run('print(1 and 0);')   # 0
Interpreter().run('print(1 and 2);')   # 2

注意 led 函式不需要改:它只存 BinOp(t.val, left, self.expr(LBP[t.type])),t.val 是 'and' 或 'or'。短路求值的關鍵是在 eval_expr 裡提前特判——右運算元只在左側無法決定結果時才求值,不可先把左右都 eval 完再判斷。

里程碑 4 — 語意分析

語法分析確認程式「形狀合法」,但不保證語意正確。例如使用未宣告的變數、 在函式外用 return——這些錯誤語法上合法,語意上不行。 語意分析(semantic analysis)在執行前靜態偵測這類問題。

Mini 的語意分析器做兩件事:(1) 作用域解析(scope resolution):確認每個 Var 都有對應的定義; (2) return 合法性檢查:確認 return 只出現在函式內。 

class SemanticError(Exception): pass

class Checker:
    """
    靜態語意檢查器:走訪 AST,回報語意錯誤。
    採「定義-使用」分析(Def-Use Analysis)。
    """
    def __init__(self):
        self.scope_stack = [set()]   # 作用域鏈(集合的堆疊)
        self.in_func     = 0         # 目前是否在函式內(計數,支援巢狀函式)

    def define(self, name): self.scope_stack[-1].add(name)
    def lookup(self, name):
        return any(name in sc for sc in self.scope_stack)

    def push_scope(self): self.scope_stack.append(set())
    def pop_scope(self):  self.scope_stack.pop()

    # ── 走訪 ──────────────────────────────────────
    def check_expr(self, node):
        if isinstance(node, (Num, Str)): return
        if isinstance(node, Var):
            if not self.lookup(node.name):
                raise SemanticError(f"未定義變數:{node.name}")
        elif isinstance(node, (BinOp, Call)):
            if isinstance(node, BinOp):
                self.check_expr(node.left); self.check_expr(node.right)
            else:   # Call
                for a in node.args: self.check_expr(a)
        elif isinstance(node, Unary):
            self.check_expr(node.operand)

    def check_stmt(self, stmt):
        if isinstance(stmt, Assign):
            self.check_expr(stmt.value)
            self.define(stmt.name)            # 指派後才算「已定義」
        elif isinstance(stmt, PrintStmt):
            self.check_expr(stmt.value)
        elif isinstance(stmt, ReturnStmt):
            if self.in_func == 0:
                raise SemanticError("return 只能在函式內使用")
            self.check_expr(stmt.value)
        elif isinstance(stmt, IfStmt):
            self.check_expr(stmt.cond)
            self.check_block(stmt.then_blk)
            if stmt.else_blk: self.check_block(stmt.else_blk)
        elif isinstance(stmt, WhileStmt):
            self.check_expr(stmt.cond)
            self.check_block(stmt.body)
        elif isinstance(stmt, FuncDef):
            self.define(stmt.name)
            self.push_scope()
            self.in_func += 1
            for p in stmt.params: self.define(p)
            self.check_block(stmt.body)
            self.in_func -= 1
            self.pop_scope()
        else:
            self.check_expr(stmt)

    def check_block(self, block):
        self.push_scope()
        for s in block.stmts: self.check_stmt(s)
        self.pop_scope()

    def check(self, ast: Block):
        for s in ast.stmts: self.check_stmt(s)

src_bad = "print(z);"   # z 從未定義

    ast = Parser(Lexer(src_bad).tokenize()).parse()
    Checker().check(ast)
except SemanticError as e:
    print(f"語意錯誤:{e}")   # 語意錯誤:未定義變數:z

型別檢查是下一步

本書 §9 章討論的型別系統(type system)可以整合在語意分析階段: 在走訪時為每個運算式推導型別,若 + 的兩側型別不相容則報錯。 Mini 目前只有動態型別,型別錯誤在執行時才爆出——靜態型別語言(如 TypeScript、Rust)在編譯時就攔截這些錯誤。

里程碑 5 — 中間表示與位元碼

樹走訪直譯器簡單,但每次執行都要重新走訪 AST——效率較低。 真實的語言(CPython、JVM、Lua、LuaJIT)會先把 AST 編譯成一種 中間表示(IR, Intermediate Representation), 再由虛擬機(VM)執行。 最常見的 IR 形式是位元碼(bytecode): 一序列緊湊的數值指令,可以快速被 VM 迴圈執行。

5.1 Mini 指令集

from enum import IntEnum

class Op(IntEnum):
    # 堆疊操作
    PUSH_CONST    = 0    # arg: constant_idx  → 把常數推入堆疊
    LOAD_VAR      = 1    # arg: name_idx      → 把變數值推入堆疊
    STORE_VAR     = 2    # arg: name_idx      → pop 並存入變數
    POP           = 3    #                    → 丟棄堆疊頂端

    # 算術
    ADD = 4; SUB = 5; MUL = 6; DIV = 7

    # 比較(結果為 True/False 推入堆疊)
    LT = 8; GT = 9; LEQ = 10; GEQ = 11; EEQ = 12; NEQ = 13

    # 一元
    NEG = 14   # 取負
    NOT = 15   # 邏輯反

    # 控制流
    JUMP          = 16   # arg: addr   → 無條件跳到 addr
    JUMP_IF_FALSE = 17   # arg: addr   → pop; 若 falsy 則跳
    CALL          = 18   # arg: name_idx, argc → 呼叫函式
    RETURN        = 19   # pop 值後返回
    PRINT         = 20   # pop 值後印出
    HALT          = 21   # 停止執行

Mini VM 是一台堆疊式虛擬機(stack-based VM)——與 JVM、WASM、CPython 的設計相同。 本書 §23 章詳細介紹了 nand2tetris Jack 編譯器如何把 Jack 語言編成相似的堆疊指令集; 這裡我們的設計來自同一個家族。

5.2 Bytecode 編譯器

OP_MAP = {
    '+': Op.ADD, '-': Op.SUB, '*': Op.MUL, '/': Op.DIV,
    '<': Op.LT,  '>': Op.GT,  '<=': Op.LEQ, '>=': Op.GEQ,
    '==': Op.EEQ, '!=': Op.NEQ,
}

class Code:
    """單一函式(或主程式)的位元碼區段"""
    def __init__(self):
        self.bytecode = []      # [(Op, *args), ...]
        self.consts   = []      # 常數池
        self.names    = []      # 名稱池(變數/函式名)
        self.params   = []      # 函式參數名(主程式為空)

    def const_idx(self, v):
        if v not in self.consts: self.consts.append(v)
        return self.consts.index(v)

    def name_idx(self, n):
        if n not in self.names: self.names.append(n)
        return self.names.index(n)

    def emit(self, *instr):
        self.bytecode.append(instr)
        return len(self.bytecode) - 1   # 回傳指令位址(用於 patch)

    def patch(self, addr, *instr):
        self.bytecode[addr] = instr

class Compiler:
    def __init__(self):
        self.funcs = {}         # 函式名 → Code

    def compile(self, ast: Block) -> Code:
        code = Code()
        for s in ast.stmts:
            self._stmt(s, code)
        code.emit(Op.HALT)
        return code

    # ── 運算式編譯 ────────────────────────────────
    def _expr(self, node, code: Code):
        if isinstance(node, Num):
            code.emit(Op.PUSH_CONST, code.const_idx(node.value))
        elif isinstance(node, Str):
            code.emit(Op.PUSH_CONST, code.const_idx(node.value))
        elif isinstance(node, Var):
            code.emit(Op.LOAD_VAR, code.name_idx(node.name))
        elif isinstance(node, Unary):
            self._expr(node.operand, code)
            code.emit(Op.NEG if node.op == '-' else Op.NOT)
        elif isinstance(node, BinOp):
            self._expr(node.left,  code)
            self._expr(node.right, code)
            code.emit(OP_MAP[node.op])
        elif isinstance(node, Call):
            for a in node.args:
                self._expr(a, code)
            code.emit(Op.CALL, code.name_idx(node.name), len(node.args))

    # ── 語句編譯 ──────────────────────────────────
    def _stmt(self, stmt, code: Code):
        if isinstance(stmt, Assign):
            self._expr(stmt.value, code)
            code.emit(Op.STORE_VAR, code.name_idx(stmt.name))
        elif isinstance(stmt, PrintStmt):
            self._expr(stmt.value, code)
            code.emit(Op.PRINT)
        elif isinstance(stmt, IfStmt):
            self._expr(stmt.cond, code)
            jif = code.emit(Op.JUMP_IF_FALSE, 0)   # 先填 0,之後 patch
            for s in stmt.then_blk.stmts: self._stmt(s, code)
            if stmt.else_blk:
                j   = code.emit(Op.JUMP, 0)
                code.patch(jif, Op.JUMP_IF_FALSE, len(code.bytecode))
                for s in stmt.else_blk.stmts: self._stmt(s, code)
                code.patch(j, Op.JUMP, len(code.bytecode))
            else:
                code.patch(jif, Op.JUMP_IF_FALSE, len(code.bytecode))
        elif isinstance(stmt, WhileStmt):
            loop = len(code.bytecode)               # 迴圈頂端位址
            self._expr(stmt.cond, code)
            jout = code.emit(Op.JUMP_IF_FALSE, 0)
            for s in stmt.body.stmts: self._stmt(s, code)
            code.emit(Op.JUMP, loop)                # 跳回頂端
            code.patch(jout, Op.JUMP_IF_FALSE, len(code.bytecode))
        elif isinstance(stmt, FuncDef):
            fc = Code(); fc.params = stmt.params
            for s in stmt.body.stmts: self._stmt(s, fc)
            fc.emit(Op.RETURN)                      # 確保一定 return
            self.funcs[stmt.name] = fc
        elif isinstance(stmt, ReturnStmt):
            self._expr(stmt.value, code)
            code.emit(Op.RETURN)
        else:
            self._expr(stmt, code)
            code.emit(Op.POP)                       # 運算式語句:結果丟棄

手動追蹤以下 Mini 程式的位元碼執行,在每條指令後寫出堆疊狀態:

x = 5;
print(x * 2 + 3);

預期位元碼序列(部分):

0: PUSH_CONST 0   (5.0)    ← consts[0] = 5.0
1: STORE_VAR  0   (x)
2: LOAD_VAR   0   (x)
3: PUSH_CONST 1   (2.0)    ← consts[1] = 2.0
4: MUL
5: PUSH_CONST 2   (3.0)    ← consts[2] = 3.0
6: ADD
7: PRINT
8: HALT

常數池依 const_idx 加入順序:5.0 → 索引 0、2.0 → 索引 1、3.0 → 索引 2。寫出 ip=2 到 ip=8 每步的堆疊快照(用 [底部, ..., 頂部] 表示)。

看解答 
前置:PUSH 5.0 → [5.0]
      STORE x   → []   (x = 5.0)

ip=2: LOAD_VAR x      → [5.0]
ip=3: PUSH_CONST 2.0  → [5.0, 2.0]
ip=4: MUL             → [10.0]       ← pop 5.0、2.0;push 10.0
ip=5: PUSH_CONST 3.0  → [10.0, 3.0]
ip=6: ADD             → [13.0]       ← pop 10.0、3.0;push 13.0
ip=7: PRINT           → []           ← pop 13.0;輸出 13.0
ip=8: HALT            → 程式結束

這個過程清楚說明了堆疊式 VM 的工作原理:每個操作數先被推入堆疊,運算子從堆疊取走操作數、把結果推回去。不需要暫存器。

里程碑 6 — 位元碼虛擬機與優化一瞥

VM 是一個大迴圈:讀取指令、依 Op 分派、操作堆疊,一直到 HALT。 這種設計叫做取指-解碼-執行迴圈(fetch-decode-execute loop), 與真實 CPU 的工作方式結構上完全相同(本書 §23 章)。 

class VM:
    def __init__(self, compiler: Compiler):
        self.compiler = compiler
        self.globals  = {}          # 全域變數

    def run_code(self, code: Code, local_vars: dict = None) -> object:
        """執行一個 Code 物件,回傳最後的 return 值(若有)"""
        stack  = []
        vars_  = dict(local_vars or {})
        ip     = 0
        bc     = code.bytecode

        def push(v): stack.append(v)
        def pop():   return stack.pop()

        while ip < len(bc):
            instr = bc[ip]; ip += 1
            op = instr[0]

            if op == Op.PUSH_CONST:
                push(code.consts[instr[1]])

            elif op == Op.LOAD_VAR:
                name = code.names[instr[1]]
                push(vars_.get(name, self.globals.get(name)))

            elif op == Op.STORE_VAR:
                name = code.names[instr[1]]
                val  = pop()
                vars_[name] = val
                if code.params == []:          # 主程式:寫回全域
                    self.globals[name] = val

            elif op == Op.POP:
                pop()

            elif op in (Op.ADD, Op.SUB, Op.MUL, Op.DIV,
                        Op.LT,  Op.GT,  Op.LEQ, Op.GEQ,
                        Op.EEQ, Op.NEQ):
                b, a = pop(), pop()
                result = {
                    Op.ADD: a+b, Op.SUB: a-b, Op.MUL: a*b, Op.DIV: a/b,
                    Op.LT:  a<b, Op.GT:  a>b, Op.LEQ: a<=b, Op.GEQ: a>=b,
                    Op.EEQ: a==b, Op.NEQ: a!=b,
                }[op]
                push(result)

            elif op == Op.NEG: push(-pop())
            elif op == Op.NOT: push(not pop())
            elif op == Op.PRINT: print(pop())

            elif op == Op.JUMP:
                ip = instr[1]

            elif op == Op.JUMP_IF_FALSE:
                if not pop(): ip = instr[1]

            elif op == Op.CALL:
                fname = code.names[instr[1]]
                argc  = instr[2]
                args  = [stack.pop() for _ in range(argc)][::-1]  # 還原順序
                fn_code = self.compiler.funcs.get(fname)
                if fn_code is None:
                    raise NameError(f"未定義函式:{fname}")
                local = dict(zip(fn_code.params, args))
                ret = self.run_code(fn_code, local)   # 遞迴執行
                push(ret if ret is not None else 0.0)

            elif op == Op.RETURN:
                return pop()

            elif op == Op.HALT:
                break

        return None

    def run(self, source: str):
        tokens = Lexer(source).tokenize()
        ast    = Parser(tokens).parse()
        code   = self.compiler.compile(ast)
        self.run_code(code)

6.1 優化一瞥:常數摺疊

常數摺疊(constant folding)是編譯器最基本的優化: 若一個 BinOp 的兩個子節點都是常數,直接在編譯期計算結果、替換成單一 Num 節點。 

def fold_constants(node):
    """在 AST 上做常數摺疊優化(遞迴後序走訪)"""
    if isinstance(node, BinOp):
        node.left  = fold_constants(node.left)
        node.right = fold_constants(node.right)
        if isinstance(node.left, Num) and isinstance(node.right, Num):
            lv, rv = node.left.value, node.right.value
            op = node.op
            if op == '+':  return Num(lv + rv)
            if op == '-':  return Num(lv - rv)
            if op == '*':  return Num(lv * rv)
            if op == '/' and rv != 0: return Num(lv / rv)
    return node

插入語意分析之後、程式碼生成之前:ast = fold_constants(ast)。 原本 2 + 3 需要 PUSH、PUSH、ADD 三條指令,優化後只需 PUSH 5——少兩條。 大型程式裡這種改善會在迴圈和函式中反覆出現。

窺孔優化(peephole optimization)則在位元碼層面做類似的事: 掃描相鄰指令序列,用更短或更快的指令替換。 例如 PUSH 1; ADD 可以被替換成單一的 INC(若 VM 支援的話)。 本書 §42 章的編譯器原理部分有更詳細的討論。

ℹ️
JVM、WASM、CPython 都走同一條路

Java 原始碼 → .class 位元碼 → JVM 執行; Python 原始碼 → .pyc 位元碼 → CPython VM 執行; C/Rust → .wasm 位元碼 → WASM VM 執行。 你今天親手造的 Mini VM 與這些生產級 VM 在結構上是同一個家族。

驗收:讓 Mini 跑起來

把所有元件組合起來,驗收每個里程碑:

def run_mini(source: str, use_vm=False):
    """
    Mini 語言執行入口。
    use_vm=False → 樹走訪直譯器
    use_vm=True  → 位元碼 VM
    """
    tokens = Lexer(source).tokenize()
    ast    = Parser(tokens).parse()
    Checker().check(ast)                # 里程碑 4:語意檢查
    if use_vm:
        c = Compiler()
        code = c.compile(ast)
        VM(c).run_code(code)
    else:
        Interpreter().run(source)

驗收程式一:階乘

func fact(n) {
    if n <= 1 { return 1; }
    return n * fact(n - 1);
}
print(fact(10));   // 預期:3628800.0

驗收程式二:迴圈計數

i = 0;
sum = 0;
while i < 100 {
    i = i + 1;
    sum = sum + i;
}

驗收程式三:費波那契(位元碼 VM)

func fib(n) {
    if n <= 1 { return n; }
    return fib(n - 1) + fib(n - 2);
}
print(fib(15));   // 預期:610.0

延伸方向

  • 閉包(closure):讓函式捕獲定義時的作用域,而非呼叫時的作用域。需要在函式物件上儲存 captured_env。
  • 垃圾回收(GC):加入標記-清除(mark-and-sweep)或參考計數(reference counting)管理動態配置的物件。
  • 原生程式碼生成:把位元碼進一步編譯成 x86/ARM 機器碼,或透過 LLVM 後端生成高效原生程式碼。
  • JIT 編譯(Just-In-Time compilation):在執行時動態把熱路徑的位元碼編譯成機器碼——這是 PyPy、V8、LuaJIT 的核心技術。
  • 字串插值與更豐富的型別:加入陣列、字典、布林字面量,讓 Mini 更接近真實使用。

你剛剛做到了一件相當厲害的事:從零開始,用不到 600 行 Python,造出了一個完整的程式語言執行環境。 讓我們點名每一個被你打通的知識結節:

  • 正規語言 / FA(§49 章):Lexer 的字元掃描邏輯本質上是一個有限自動機,每種 token 對應一個正規模式。
  • 上下文無關文法(§49 章):Mini 的 EBNF 文法是一個 CFG;Parser 實作了對應的下推自動機,呼叫堆疊就是「下推儲存」。
  • Pratt Parsing(§42 章):一個優雅的運算子優先級解析演算法,用「左結合力」這個單一數字取代了傳統的多層函式鏈。
  • AST 與樹走訪:抽象語法樹是程式的純結構表示;遞迴走訪是最直接的執行方式。
  • 語意分析:作用域鏈、Def-Use 分析、return 合法性——在執行前靜態捕捉邏輯錯誤。
  • 堆疊式 VM 位元碼(§23 章):一組緊湊的指令讓程式可以「離線編譯、稍後執行」,而且天然適合詮譯和優化。
  • 常數摺疊:最基礎的編譯期優化,把編譯器理論(§42 章)的知識轉化為實際效能提升。
