從一條光線到一張照片：渲染器的全貌

你有沒有想過，為什麼《玩具總動員》裡胡迪帽子上的陰影那麼柔和，而 1995 年的遊戲場景 陰影卻是一刀切的硬邊？答案不是算力，而是演算法。早期遊戲用「固定光源＋Phong 模型」， 跳過了光真正的行為；電影則用路徑追蹤器(path tracer)——讓光子一條一條地在場景裡彈跳， 最後才累積到感光元件上。

里程碑 1 — 向量數學與 PPM 影像

渲染器的基石是三維向量(3D vector)。位置、方向、顏色——全部用 Vec3 表達。 我們先把它實作好，再用最簡單的方式輸出第一張圖：PPM 格式。 PPM（Portable Pixmap）純文字格式，每個像素寫一行 R G B，沒有任何壓縮， 能用任何文字編輯器檢查，是離線渲染的經典測試格式。

ℹ️
為何先連 §54 線性代數？

第 54 章〈線性代數〉把向量運算建立在嚴格的數學基礎上： 點積(dot product) $\mathbf{a}\cdot\mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos\theta$ 衡量「有多對齊」； 叉積(cross product) $\mathbf{a}\times\mathbf{b}$ 產生垂直於兩向量的新向量。 這兩個操作會在求交、法線計算、散射方向，反覆出現。

Vec3 實作

# milestone1_vec3.py  （Python 學習版，速度比 C++ 慢數十倍）
import math, random, sys

class Vec3:
    """三維向量；顏色(Color)與點(Point3)都用同一個類別。"""
    __slots__ = ('x', 'y', 'z')

    def __init__(self, x=0.0, y=0.0, z=0.0):
        self.x, self.y, self.z = float(x), float(y), float(z)

    def __neg__(self):
        return Vec3(-self.x, -self.y, -self.z)

    def __add__(self, v):
        return Vec3(self.x + v.x, self.y + v.y, self.z + v.z)

    def __sub__(self, v):
        return Vec3(self.x - v.x, self.y - v.y, self.z - v.z)

    def __mul__(self, t):
        if isinstance(t, Vec3):          # 分量逐一相乘（顏色合成用）
            return Vec3(self.x*t.x, self.y*t.y, self.z*t.z)
        return Vec3(self.x*t, self.y*t, self.z*t)

    def __rmul__(self, t):
        return self.__mul__(t)

    def __truediv__(self, t):
        return self * (1.0 / t)

    def dot(self, v):
        return self.x*v.x + self.y*v.y + self.z*v.z

    def cross(self, v):
        return Vec3(
            self.y*v.z - self.z*v.y,
            self.z*v.x - self.x*v.z,
            self.x*v.y - self.y*v.x
        )

    def length_sq(self):
        return self.dot(self)

    def length(self):
        return math.sqrt(self.length_sq())

    def unit(self):
        return self / self.length()

    def near_zero(self):
        """向量長度接近零（用於散射方向退化偵測）。"""
        s = 1e-8
        return abs(self.x) < s and abs(self.y) < s and abs(self.z) < s

    @staticmethod
    def random_unit():
        """在單位球面上均勻隨機取向。"""
        while True:
            v = Vec3(random.uniform(-1,1), random.uniform(-1,1), random.uniform(-1,1))
            if v.length_sq() < 1.0:
                return v.unit()

Color = Vec3
Point3 = Vec3

相機與光線

最簡相機：原點在 $(0,0,0)$，朝 $-z$ 方向看，虛擬螢幕在 $z=-1$ 平面。 每個像素 $(i, j)$ 對應螢幕上的比例座標 $(u, v) \in [0,1]^2$，由此產生一條光線(ray)：

$$\mathbf{P}(t) = \mathbf{O} + t\mathbf{d}, \quad t \in (t_{\min}, t_{\max})$$

其中 $\mathbf{O}$ 是光線起點，$\mathbf{d}$ 是方向向量，$t$ 是參數（距離）。

class Ray:
    __slots__ = ('origin', 'direction')
    def __init__(self, origin: Vec3, direction: Vec3):
        self.origin    = origin
        self.direction = direction

    def at(self, t: float) -> Vec3:
        return self.origin + self.direction * t


def sky_color(ray: Ray) -> Color:
    """天空漸層：白色（下）→ 淺藍（上）。"""
    unit_dir = ray.direction.unit()
    t = 0.5 * (unit_dir.y + 1.0)          # y∈[-1,1] 映射到 [0,1]
    return (1.0 - t) * Color(1, 1, 1) + t * Color(0.5, 0.7, 1.0)


# === PPM 輸出 ===
def write_ppm(filename: str, width: int, height: int, pixels):
    with open(filename, 'w') as f:
        f.write(f"P3\n{width} {height}\n255\n")
        for color in pixels:
            r = int(256 * max(0.0, min(0.999, color.x)))
            g = int(256 * max(0.0, min(0.999, color.y)))
            b = int(256 * max(0.0, min(0.999, color.z)))
            f.write(f"{r} {g} {b}\n")


# === 主程式：漸層背景 ===
W, H = 200, 100
aspect = W / H

lower_left  = Point3(-2.0, -1.0, -1.0)
horizontal  = Vec3(4.0,  0.0, 0.0)
vertical    = Vec3(0.0,  2.0, 0.0)
cam_origin  = Point3(0.0, 0.0, 0.0)

pixels = []
for j in range(H - 1, -1, -1):      # 從上到下
    for i in range(W):
        u = i / (W - 1)
        v = j / (H - 1)
        d = lower_left + u * horizontal + v * vertical - cam_origin
        r = Ray(cam_origin, d)
        pixels.append(sky_color(r))

write_ppm("output_m1.ppm", W, H, pixels)
print("M1 done → output_m1.ppm")

里程碑 2 — 光線與球求交

場景裡放一顆球，光線打過去，要判斷是否命中、命中在哪裡——這是整個渲染器的核心幾何問題。 它的答案藏在一條二次方程式裡。

求交推導：二次方程式

球以圓心 $\mathbf{C}$、半徑 $r$ 定義：$|\mathbf{P} - \mathbf{C}|^2 = r^2$。 把光線 $\mathbf{P}(t) = \mathbf{O} + t\mathbf{d}$ 代入： $$|\mathbf{O} + t\mathbf{d} - \mathbf{C}|^2 = r^2$$ 令 $\mathbf{oc} = \mathbf{O} - \mathbf{C}$，展開點積： $$t^2(\mathbf{d}\cdot\mathbf{d}) + 2t(\mathbf{d}\cdot\mathbf{oc}) + (\mathbf{oc}\cdot\mathbf{oc} - r^2) = 0$$ 用「半 b」優化（令 $h = \mathbf{d}\cdot\mathbf{oc}$，省掉係數 2 的因子）：

$$a = \mathbf{d}\cdot\mathbf{d}, \quad h = \mathbf{d}\cdot\mathbf{oc}, \quad c = \mathbf{oc}\cdot\mathbf{oc} - r^2$$ $$\Delta = h^2 - ac$$ $$t = \frac{-h \pm \sqrt{\Delta}}{a}$$

  • $\Delta < 0$：無交點（光線擦過球外側）
  • $\Delta = 0$：剛好切線（一個交點）
  • $\Delta > 0$：穿入再穿出（兩個交點；取較小的正 $t$ 為最近命中）

法線與可命中物件抽象

命中點的外向法線(outward normal)：把圓心到交點的向量除以半徑。 同時我們引入 HitRecord 與 Hittable 抽象——讓場景可以由任意幾何組成， 而不是寫死「只有球」。這個設計直接對應第 50 章〈計算幾何〉 的多型(polymorphism)思維。 

from dataclasses import dataclass, field
from typing import Optional

@dataclass
class HitRecord:
    p:         Vec3    = None     # 交點座標
    normal:    Vec3    = None     # 法線（永遠指向光線來源側）
    t:         float   = 0.0     # 光線參數
    front_face: bool  = True     # 光線從正面（外側）打進來?
    material:  object = None     # 材質（Milestone 4 填入）

    def set_face_normal(self, ray: Ray, outward_normal: Vec3):
        """確保法線總是指向光線來源側（雙面材質必備）。"""
        self.front_face = ray.direction.dot(outward_normal) < 0
        self.normal = outward_normal if self.front_face else -outward_normal


class Hittable:
    def hit(self, ray: Ray, t_min: float, t_max: float) -> Optional[HitRecord]:
        raise NotImplementedError


class Sphere(Hittable):
    def __init__(self, center: Point3, radius: float, material=None):
        self.center   = center
        self.radius   = radius
        self.material = material

    def hit(self, ray: Ray, t_min: float, t_max: float) -> Optional[HitRecord]:
        oc = ray.origin - self.center          # oc = O − C
        a  = ray.direction.dot(ray.direction)  # |d|²
        h  = ray.direction.dot(oc)             # d·oc（半 b）
        c  = oc.dot(oc) - self.radius**2       # |oc|² − r²
        discriminant = h*h - a*c

        if discriminant < 0:
            return None                        # 未命中

        sqrtd = math.sqrt(discriminant)
        # 先嘗試較近的根
        root = (-h - sqrtd) / a
        if not (t_min < root < t_max):
            root = (-h + sqrtd) / a           # 再試較遠的根
            if not (t_min < root < t_max):
                return None

        rec = HitRecord()
        rec.t = root
        rec.p = ray.at(root)
        outward_normal = (rec.p - self.center) / self.radius
        rec.set_face_normal(ray, outward_normal)
        rec.material = self.material
        return rec

    def bounding_box(self) -> AABB:
        r = Vec3(self.radius, self.radius, self.radius)
        return AABB(self.center - r, self.center + r)


class HittableList(Hittable):
    def __init__(self):
        self.objects: list = []

    def add(self, obj: Hittable):
        self.objects.append(obj)

    def hit(self, ray: Ray, t_min: float, t_max: float) -> Optional[HitRecord]:
        closest = t_max
        best_rec = None
        for obj in self.objects:
            rec = obj.hit(ray, t_min, closest)
            if rec is not None:
                closest  = rec.t   # 逐步縮小搜尋上限，只保留最近命中
                best_rec = rec
        return best_rec
⚠️
浮點精度：t_min 要大於 0

命中後用同一個交點重新出發追蹤（遞迴）時，若 t_min = 0， 浮點誤差會讓球自己命中自己（影子痤瘡，shadow acne）。 實務上設 t_min = 1e-4 或 1e-3， 讓二次交點略微「離開表面」後才開始計算。

里程碑 3 — 反走樣與相機模型

現在的渲染每個像素只打一條光線，球的邊緣會有明顯的鋸齒(aliasing)。 解法很直觀：同一個像素打 N 條方向略有不同的光線，取顏色平均——這就是 超取樣反走樣(super-sampling anti-aliasing, SSAA)， 也是「每像素樣本數(samples per pixel, spp)」的由來。

Gamma 校正

人眼對暗部更敏感，螢幕亮度通常以 $\gamma \approx 2.2$ 的冪次關係呈現。 若直接把線性光照值寫入 PPM，暗部細節會壓縮。 最簡的 gamma 2 校正：儲存前對每個分量取平方根： $$C_{\text{out}} = \sqrt{C_{\text{linear}}} \equiv C_{\text{linear}}^{1/2}$$ 

def write_color_srgb(color: Color, samples: int) -> tuple:
    """將累積顏色除以樣本數，gamma-2 校正，輸出 (R,G,B) 整數。"""
    scale = 1.0 / samples
    r = math.sqrt(color.x * scale)
    g = math.sqrt(color.y * scale)
    b = math.sqrt(color.z * scale)
    return (
        int(256 * max(0.0, min(0.999, r))),
        int(256 * max(0.0, min(0.999, g))),
        int(256 * max(0.0, min(0.999, b))),
    )


class Camera:
    """
    可調焦距、景深的薄透鏡相機。
    lookfrom / lookat: 相機位置與注視點
    vup: 世界上方向
    vfov: 垂直視野角（度）
    aperture / focus_dist: 光圈（景深）
    """
    def __init__(self, lookfrom, lookat, vup,
                 vfov=90.0, aspect=16/9,
                 aperture=0.0, focus_dist=1.0):
        theta = math.radians(vfov)
        h     = math.tan(theta / 2)
        vp_h  = 2.0 * h
        vp_w  = aspect * vp_h

        w = (lookfrom - lookat).unit()    # 相機的後方
        u = vup.cross(w).unit()           # 相機的右方
        v = w.cross(u)                    # 相機的上方

        self.origin     = lookfrom
        self.horizontal = focus_dist * vp_w * u
        self.vertical   = focus_dist * vp_h * v
        self.lower_left = (lookfrom
                           - self.horizontal/2
                           - self.vertical/2
                           - focus_dist * w)
        self.lens_radius = aperture / 2
        self.u, self.v = u, v

    def get_ray(self, s: float, t: float) -> Ray:
        """取 (s,t) ∈ [0,1]² 對應像素，在光圈圓內隨機偏移模擬景深。"""
        rd = self.lens_radius * Vec3.random_in_disk()
        offset = self.u * rd.x + self.v * rd.y
        direction = (self.lower_left
                     + s * self.horizontal
                     + t * self.vertical
                     - self.origin - offset)
        return Ray(self.origin + offset, direction)


# Vec3.random_in_disk: 在 xy 平面單位圓盤內均勻採樣
@staticmethod
def _random_in_disk():
    while True:
        p = Vec3(random.uniform(-1,1), random.uniform(-1,1), 0.0)
        if p.length_sq() < 1.0:
            return p
Vec3.random_in_disk = _random_in_disk

spp 與品質的權衡

增加 spp 會讓雜訊降低，但渲染時間線性增加。 反走樣邊緣：32–64 spp 已明顯改善；全域光照：256–1024 spp 才會收斂。 每像素誤差正比於 $1/\sqrt{N}$，把誤差砍半要四倍的採樣數——這是蒙地卡羅的代價，也是 AI 降噪的動機。

里程碑 4 — 材質：漫反射、金屬與電介質

現在場景只能顯示法線顏色，沒有真實材質感。本節加入三種核心材質， 對應到第 110 章的 BRDF 分類：

  • Lambertian（漫反射）：散射到任意方向，符合 Lambert 餘弦定律
  • Metal（金屬）：鏡面反射，加模糊度參數
  • Dielectric（電介質）：透明玻璃/水，折射＋全反射＋Fresnel

Lambertian 漫反射

最簡單的漫反射：新光線方向 = 法線 + 單位球面隨機向量（近似 Lambert 餘弦分佈）。 吸收率 = $(1 - \text{albedo})$，剩餘能量繼續追蹤。 

class Material:
    def scatter(self, ray_in: Ray, rec: HitRecord):
        """返回 (attenuation: Color, scattered: Ray) 或 None（完全吸收）。"""
        raise NotImplementedError


class Lambertian(Material):
    def __init__(self, albedo: Color):
        self.albedo = albedo

    def scatter(self, ray_in: Ray, rec: HitRecord):
        scatter_dir = rec.normal + Vec3.random_unit()
        if scatter_dir.near_zero():
            scatter_dir = rec.normal   # 防止方向退化
        return self.albedo, Ray(rec.p, scatter_dir)

金屬反射

完美鏡面反射的向量公式：$\mathbf{r} = \mathbf{v} - 2(\mathbf{v}\cdot\hat{\mathbf{n}})\hat{\mathbf{n}}$， 其中 $\mathbf{v}$ 是入射方向。加上模糊(fuzz)參數讓反射方向有隨機偏移，模擬磨砂金屬。 

def reflect(v: Vec3, n: Vec3) -> Vec3:
    """鏡面反射：v − 2(v·n)n。"""
    return v - 2 * v.dot(n) * n


class Metal(Material):
    def __init__(self, albedo: Color, fuzz: float = 0.0):
        self.albedo = albedo
        self.fuzz   = min(fuzz, 1.0)    # fuzz ∈ [0,1]：0 完美鏡面，1 最模糊

    def scatter(self, ray_in: Ray, rec: HitRecord):
        reflected = reflect(ray_in.direction.unit(), rec.normal)
        scattered = Ray(rec.p, reflected + self.fuzz * Vec3.random_unit())
        if scattered.direction.dot(rec.normal) > 0:
            return self.albedo, scattered
        return None   # 散射方向進入球內側，吸收掉

電介質：Snell 定律與 Fresnel-Schlick

光從折射率 $\eta_1$ 的介質進入 $\eta_2$ 時，折射角滿足 Snell 定律(Snell's law)： $$\eta_1 \sin\theta_1 = \eta_2 \sin\theta_2$$

向量形式的折射計算（入射方向 $\hat{\mathbf{v}}$，法線 $\hat{\mathbf{n}}$，$\eta = \eta_1/\eta_2$）： $$\mathbf{r}_\perp = \eta\!\left(\hat{\mathbf{v}} + \cos\theta_1\hat{\mathbf{n}}\right), \quad \mathbf{r}_\parallel = -\sqrt{1-|\mathbf{r}_\perp|^2}\,\hat{\mathbf{n}}, \quad \mathbf{r} = \mathbf{r}_\perp + \mathbf{r}_\parallel$$ 其中 $\cos\theta_1 = -\hat{\mathbf{v}}\cdot\hat{\mathbf{n}}$。

當 $\sin\theta_2 > 1$ 時（$\sin\theta_1 > \eta_2/\eta_1$）發生全反射(total internal reflection)， 折射不存在，強制反射。邊緣角度的部分反射以 Fresnel-Schlick 近似(Fresnel-Schlick approximation)估計： $$R_0 = \left(\frac{\eta_1 - \eta_2}{\eta_1 + \eta_2}\right)^2, \qquad R(\theta) \approx R_0 + (1 - R_0)(1 - \cos\theta)^5$$ 

def refract(v: Vec3, n: Vec3, eta_ratio: float) -> Vec3:
    """Snell 定律的向量折射。v 是單位入射方向，n 是單位法線。"""
    cos_theta = min(-v.dot(n), 1.0)
    r_perp = eta_ratio * (v + cos_theta * n)               # 垂直分量
    r_parallel = -math.sqrt(abs(1.0 - r_perp.length_sq())) * n  # 平行分量
    return r_perp + r_parallel


def schlick(cos_theta: float, ref_idx: float) -> float:
    """Fresnel-Schlick 反射率近似。"""
    r0 = ((1 - ref_idx) / (1 + ref_idx)) ** 2
    return r0 + (1 - r0) * (1 - cos_theta) ** 5


class Dielectric(Material):
    """透明電介質（玻璃 ir≈1.5，水 ir≈1.33，鑽石 ir≈2.42）。"""
    def __init__(self, ir: float):
        self.ir = ir   # index of refraction

    def scatter(self, ray_in: Ray, rec: HitRecord):
        attenuation = Color(1.0, 1.0, 1.0)   # 玻璃不吸收顏色
        eta_ratio = (1.0 / self.ir) if rec.front_face else self.ir

        unit_dir  = ray_in.direction.unit()
        cos_theta = min(-unit_dir.dot(rec.normal), 1.0)
        sin_theta = math.sqrt(1.0 - cos_theta**2)

        # 全反射條件：sin θ₂ = η·sin θ₁ > 1
        cannot_refract = eta_ratio * sin_theta > 1.0
        # Fresnel-Schlick：邊緣角度仍有機率反射
        if cannot_refract or schlick(cos_theta, eta_ratio) > random.random():
            direction = reflect(unit_dir, rec.normal)
        else:
            direction = refract(unit_dir, rec.normal, eta_ratio)

        return attenuation, Ray(rec.p, direction)

里程碑 5 — 蒙地卡羅路徑追蹤

前面的材質只散射一次，每條光線的「故事」到此為止。真實的光在場景裡無限次彈跳—— 天花板的光打到桌面，桌面的光再打到牆——這就是全域光照(global illumination)。 計算它需要遞迴求解渲染方程式：

$$L_o(\mathbf{x},\omega_o) = L_e(\mathbf{x},\omega_o) + \int_{\Omega^+} f_r(\mathbf{x},\omega_i,\omega_o)\,L_i(\mathbf{x},\omega_i)\,|\cos\theta_i|\,d\omega_i$$

這個半球積分沒有解析解。解法：蒙地卡羅估計量(Monte Carlo estimator)—— 隨機取樣方向 $\omega_i \sim p(\omega_i)$，不偏估計： $$\langle L_o \rangle = \frac{1}{N}\sum_{k=1}^{N} \frac{f_r\,L_i\,|\cos\theta|}{\,p(\omega_i)\,}$$ 誤差標準差 $\propto 1/\sqrt{N}$（來自第 57 章〈機率論〉的大數定律與 CLT）。 若採樣分佈 $p$ 更集中在重要區域（重要性採樣, importance sampling）， 同樣 $N$ 可以得到更低的變異數。

遞迴光線追蹤

def ray_color(ray: Ray, world: Hittable, depth: int) -> Color:
    """
    遞迴路徑追蹤。
    depth: 最大反彈次數（超過後用俄羅斯輪盤終止或直接返回黑色）。
    """
    if depth <= 0:
        return Color(0, 0, 0)   # 達到最大深度，光線能量耗盡

    rec = world.hit(ray, 0.001, math.inf)

    if rec is not None:
        result = rec.material.scatter(ray, rec)
        if result is not None:
            attenuation, scattered = result
            # 遞迴：衰減 × 繼續追蹤散射光線
            return attenuation * ray_color(scattered, world, depth - 1)
        return Color(0, 0, 0)   # 材質完全吸收

    # 未命中任何物件 → 天空漸層（環境光）
    return sky_color(ray)


# === 渲染迴圈（含 spp） ===
def render(world, cam, W, H, spp=64, max_depth=10):
    image = []
    for j in range(H - 1, -1, -1):
        for i in range(W):
            pixel_color = Color(0, 0, 0)
            for _ in range(spp):
                s = (i + random.random()) / (W - 1)
                t = (j + random.random()) / (H - 1)
                r = cam.get_ray(s, t)
                pixel_color = pixel_color + ray_color(r, world, max_depth)
            image.append(write_color_srgb(pixel_color, spp))
    return image

俄羅斯輪盤終止

固定最大深度會讓亮材質稍微偏暗（能量仍有截斷誤差）。 俄羅斯輪盤(Russian roulette)是無偏估計的替代方案： 每次反彈以機率 $p$ 繼續、$(1-p)$ 終止，繼續時把貢獻除以 $p$ 補償—— 這樣期望值不變，但讓追蹤自然收斂。 

def ray_color_rr(ray: Ray, world: Hittable, depth: int = 50) -> Color:
    """帶俄羅斯輪盤的路徑追蹤（無偏）。"""
    if depth <= 0:
        return Color(0, 0, 0)   # 達到最大深度，返回黑色
    rec = world.hit(ray, 0.001, math.inf)
    if rec is None:
        return sky_color(ray)

    result = rec.material.scatter(ray, rec)
    if result is None:
        return Color(0, 0, 0)

    attenuation, scattered = result

    # 俄羅斯輪盤：用亮度作繼續機率
    p = max(attenuation.x, attenuation.y, attenuation.z)
    p = min(p, 0.999)   # 確保至少 0.1% 終止機率（電介質 attenuation=1 時必要）
    if random.random() > p:
        return Color(0, 0, 0)   # 機率終止

    # 繼續，補償機率（保持無偏）
    return (attenuation / p) * ray_color_rr(scattered, world, depth - 1)

里程碑 6 — BVH 包圍盒階層加速

當場景有 1000 個球，HittableList.hit 要對每條光線做 1000 次求交—— 時間複雜度 $O(n)$，場景越大越慢。 BVH（Bounding Volume Hierarchy，包圍盒階層）把物件按空間分組： 先測光線是否打中父節點的包圍盒，打中才往子樹遞迴。 結果是 $O(\log n)$ 求交，場景翻倍只多一層對數——和第 27 章〈分治法〉 的快速排序、第 29 章〈資料結構〉的二元搜尋樹完全同源。

軸對齊包圍盒(AABB)

AABB（Axis-Aligned Bounding Box）：$[x_{\min},x_{\max}]\times[y_{\min},y_{\max}]\times[z_{\min},z_{\max}]$。 光線-AABB 求交用「平板法(slab method)」：對每個軸算進入/離開時刻，取交集： $$t_{\min} = \max(t_{x_{\min}}, t_{y_{\min}}, t_{z_{\min}}), \quad t_{\max} = \min(t_{x_{\max}}, t_{y_{\max}}, t_{z_{\max}})$$ 若 $t_{\min} \leq t_{\max}$ 則命中。 

class AABB:
    def __init__(self, minimum: Vec3, maximum: Vec3):
        self.minimum = minimum
        self.maximum = maximum

    def hit(self, ray: Ray, t_min: float, t_max: float) -> bool:
        for axis in ('x', 'y', 'z'):
            d_comp = getattr(ray.direction, axis)
            o_comp = getattr(ray.origin,    axis)
            b_min  = getattr(self.minimum,  axis)
            b_max  = getattr(self.maximum,  axis)

            if abs(d_comp) < 1e-12:
                if not (b_min <= o_comp <= b_max):
                    return False
                continue

            inv_d = 1.0 / d_comp
            t0 = (b_min - o_comp) * inv_d
            t1 = (b_max - o_comp) * inv_d
            if inv_d < 0:
                t0, t1 = t1, t0
            t_min = max(t_min, t0)
            t_max = min(t_max, t1)
            if t_max <= t_min:
                return False
        return True


def surrounding_box(box0: AABB, box1: AABB) -> AABB:
    """回傳包住兩個 AABB 的最小 AABB。"""
    small = Vec3(min(box0.minimum.x, box1.minimum.x),
                 min(box0.minimum.y, box1.minimum.y),
                 min(box0.minimum.z, box1.minimum.z))
    big   = Vec3(max(box0.maximum.x, box1.maximum.x),
                 max(box0.maximum.y, box1.maximum.y),
                 max(box0.maximum.z, box1.maximum.z))
    return AABB(small, big)


class BVHNode(Hittable):
    def __init__(self, objects: list, start: int, end: int):
        axis   = random.randint(0, 2)       # 隨機選分割軸（SAH 是進階版本）
        key_fn = ['x', 'y', 'z'][axis]

        span = end - start
        if span == 1:
            self.left = self.right = objects[start]
        elif span == 2:
            if getattr(objects[start].bounding_box().minimum, key_fn) \
               <= getattr(objects[start+1].bounding_box().minimum, key_fn):
                self.left, self.right = objects[start], objects[start+1]
            else:
                self.left, self.right = objects[start+1], objects[start]
        else:
            # 按選定軸排序，遞迴分割
            sub = sorted(objects[start:end],
                         key=lambda o: getattr(o.bounding_box().minimum, key_fn))
            mid = start + span // 2
            # 重新放回 objects 列表的切片（簡化版本）
            self.left  = BVHNode(sub, 0, span // 2)
            self.right = BVHNode(sub, span // 2, span)

        box_l = self.left.bounding_box()
        box_r = self.right.bounding_box()
        self._box = surrounding_box(box_l, box_r)

    def bounding_box(self) -> AABB:
        return self._box

    def hit(self, ray: Ray, t_min: float, t_max: float):
        if not self._box.hit(ray, t_min, t_max):
            return None                   # 根本沒打中包圍盒，剪枝
        hit_l = self.left.hit(ray, t_min, t_max)
        hit_r = self.right.hit(ray, t_min,
                               hit_l.t if hit_l else t_max)
        return hit_r if hit_r else hit_l   # 回傳最近命中

里程碑 7 — 三角網格與場景擴充

球很好用，但真實模型是由三角形(triangle)拼成的網格(mesh)—— 幾乎所有 3D 建模工具都以 .obj 格式匯出。 本里程碑加入三角求交與簡易 .obj 讀取，讓你能渲染「兔子」或任何免費 3D 模型。

Möller-Trumbore 三角求交

給定三角形三頂點 $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$， 光線 $\mathbf{O} + t\mathbf{d}$。 用重心座標 $(u, v)$ 表示交點：$\mathbf{P} = (1-u-v)\mathbf{v}_0 + u\mathbf{v}_1 + v\mathbf{v}_2$， 解方程組得到 $t, u, v$——條件：$t > 0$，$u \geq 0$，$v \geq 0$，$u+v \leq 1$。 

class Triangle(Hittable):
    def __init__(self, v0: Vec3, v1: Vec3, v2: Vec3, material=None):
        self.v0 = v0
        self.v1 = v1
        self.v2 = v2
        self.material = material
        # 預算邊向量與法線
        self.e1 = v1 - v0
        self.e2 = v2 - v0
        self.normal = self.e1.cross(self.e2).unit()

    def hit(self, ray: Ray, t_min: float, t_max: float):
        # Möller-Trumbore 演算法
        h   = ray.direction.cross(self.e2)
        det = self.e1.dot(h)

        if abs(det) < 1e-8:          # 光線與三角形平行
            return None

        inv_det = 1.0 / det
        s = ray.origin - self.v0
        u = inv_det * s.dot(h)
        if not (0.0 <= u <= 1.0):
            return None

        q = s.cross(self.e1)
        v = inv_det * ray.direction.dot(q)
        if v < 0.0 or u + v > 1.0:
            return None

        t = inv_det * self.e2.dot(q)
        if not (t_min < t < t_max):
            return None

        rec = HitRecord()
        rec.t = t
        rec.p = ray.at(t)
        rec.material = self.material
        rec.set_face_normal(ray, self.normal)
        return rec

    def bounding_box(self) -> AABB:
        eps = Vec3(1e-4, 1e-4, 1e-4)
        lo = Vec3(min(self.v0.x, self.v1.x, self.v2.x),
                  min(self.v0.y, self.v1.y, self.v2.y),
                  min(self.v0.z, self.v1.z, self.v2.z))
        hi = Vec3(max(self.v0.x, self.v1.x, self.v2.x),
                  max(self.v0.y, self.v1.y, self.v2.y),
                  max(self.v0.z, self.v1.z, self.v2.z))
        return AABB(lo - eps, hi + eps)


def load_obj(filename: str, material=None) -> list:
    """極簡 .obj 讀取器：只處理頂點(v)與面(f)。"""
    vertices, triangles = [], []
    with open(filename) as f:
        for line in f:
            parts = line.split()
            if not parts:
                continue
            if parts[0] == 'v':
                vertices.append(Vec3(float(parts[1]),
                                     float(parts[2]),
                                     float(parts[3])))
            elif parts[0] == 'f':
                # 面索引從 1 開始；可能是 v/vt/vn 格式
                idxs = [int(p.split('/')[0]) - 1 for p in parts[1:]]
                for k in range(1, len(idxs) - 1):
                    triangles.append(Triangle(vertices[idxs[0]],
                                              vertices[idxs[k]],
                                              vertices[idxs[k+1]],
                                              material))
    return triangles

✏️ 練習 121.1 思考

請解釋：為何在 Sphere.hit 裡用「半 b」優化（令 $h = \mathbf{d}\cdot\mathbf{oc}$） 後，判別式從 $b^2 - 4ac$ 變成 $h^2 - ac$？兩者結果是否相同？

看解答

原始形式：$a = \mathbf{d}\cdot\mathbf{d}$，$b = 2\mathbf{d}\cdot\mathbf{oc}$，$c = \mathbf{oc}\cdot\mathbf{oc}-r^2$。

令 $h = b/2 = \mathbf{d}\cdot\mathbf{oc}$，則 $b = 2h$，判別式：

$$(2h)^2 - 4ac = 4h^2 - 4ac = 4(h^2 - ac)$$

正負號與 $4(h^2-ac)$ 相同（$4 > 0$），因此零根、正負根的判斷完全等價。 解的分母從 $2a$ 變成 $a$（除以 2），正確代入後結果相同。 優點是省去係數 $4$ 的乘除，稍微節省浮點運算。

    render(world_list, cam, 200, 100, spp=4)
    t1 = time.perf_counter()
    render(bvh, cam, 200, 100, spp=4)
    t2 = time.perf_counter()
    return t1-t0, t2-t1

for n in [100, 200, 500, 1000]:
    tl, tb = benchmark(n)
    print(f"n={n:4d}  List={tl:.2f}s  BVH={tb:.2f}s  加速={tl/tb:.1f}x")

預期：List 時間線性成長（$O(n)$），BVH 時間成長遠慢於 List（$O(\log n)$），加速比在 1000 球時達 20–50x。

✏️ 練習 121.4 思考

Fresnel-Schlick 近似的 $R_0$ 項是從完整的 Fresnel 公式推導出來的。 試由菲涅耳方程式（s/p 極化）在 $\theta = 0$（垂直入射）時， 推導 $R_0 = \left(\frac{n_1 - n_2}{n_1 + n_2}\right)^2$ 的來源。

看解答

菲涅耳反射係數（s 極化，垂直入射 $\theta_1 = \theta_2 = 0$）：

$$r_s = \frac{n_1 \cos\theta_1 - n_2 \cos\theta_2}{n_1 \cos\theta_1 + n_2 \cos\theta_2} \xrightarrow{\theta \to 0} \frac{n_1 - n_2}{n_1 + n_2}$$

同理 $r_p \to \frac{n_2 - n_1}{n_2 + n_1} = -r_s$（符號差異不影響能量計算）。

反射率（能量比例）= 振幅係數的平方：

$$R_0 = |r_s|^2 = \left(\frac{n_1 - n_2}{n_1 + n_2}\right)^2$$

Schlick 把 $\theta = 0$ 的反射率 $R_0$ 作為基準值，再用 $(1-\cos\theta)^5$ 插值到掠射角（$\theta \to 90°$，$R \to 1$），是計算效率與準確度的折衷。

✏️ 練習 121.5 挑戰

實作餘弦加權半球採樣(cosine-weighted hemisphere sampling)： 在 Lambertian 材質中，讓散射方向機率密度正比於 $\cos\theta$（而非目前的均勻採樣）。 比較相同 spp 下兩者的影像品質差異，說明為何加權採樣能降低變異數。

看解答

餘弦加權採樣的逆 CDF 方法（Malley 方法）：

  1. 在單位圓盤均勻取樣 $(r_x, r_y)$：Vec3.random_in_disk()
  2. 投影到半球：$z = \sqrt{1 - r_x^2 - r_y^2}$，得 $(r_x, r_y, z)$ 為局部座標
  3. 把局部座標轉換到以法線為軸的世界座標（需正交基 ONB）

分析：目前 n + random_unit() 的機率密度 $p(\omega) \propto \cos\theta + 1$（非精確）； 餘弦加權的 $p(\omega) = \cos\theta / \pi$ 精確對應 Lambertian BRDF $f_r = \rho/\pi$， 使得 $f_r / p = \rho$（常數），變異數降為 0——這是重要性採樣完美匹配的情況。

✏️ 練習 121.6 挑戰

用 Python 的 multiprocessing 或 NumPy 向量化加速渲染器： 每行像素(scanline)可獨立平行計算。測量加速比，並思考若要移植到 GPU （第 118 章）應如何修改資料結構。

看解答 
from multiprocessing import Pool

def render_row(args):
    j, world, cam, W, H, spp, max_depth = args
    row = []
    for i in range(W):
        c = Color(0,0,0)
        for _ in range(spp):
            s = (i + random.random()) / (W-1)
            t = (j + random.random()) / (H-1)
            c = c + ray_color(cam.get_ray(s,t), world, max_depth)
        row.append(write_color_srgb(c, spp))
    return j, row

with Pool() as pool:
    jobs = [(j, world, cam, W, H, spp, 10) for j in range(H-1,-1,-1)]
    results = pool.map(render_row, jobs)
results.sort(key=lambda x: -x[0])   # 重新按 j 排序

GPU 移植要點：把 Vec3 改為 CUDA float3，把材質多型改為 switch/enum（GPU 不支援虛擬函數在 device 上的 vtable），用 CUDA kernel 每個線程處理一個像素。參見第 118 章 CUDA 程式模型。
