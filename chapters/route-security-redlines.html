資安紅線與授權

同一個動作,有授權是專業服務,沒有授權就是犯罪。學任何攻擊技巧之前,先把這條線看清楚。

只有一條分界線:授權

流行文化把「駭客」都當成壞人。資安界的分法不同,看的是授權與意圖:

  • 白帽(white hat):拿到授權,為了找出並修補漏洞而攻擊系統。滲透測試員、漏洞賞金獵人都是白帽。
  • 黑帽(black hat):沒有授權,為了私利或破壞而入侵。違法。
  • 灰帽(gray hat):沒有授權就去試別人的系統,但說自己是好意。好意救不了你:沒有授權的存取本身通常就違法,也可能在無意間造成損害。
🔑
核心觀念

掃描一個網站的漏洞:有書面授權,是專業服務;沒有授權,可能就是犯罪。動作一模一樣,差別只在授權。

原文:第 42 章 §資安與駭客倫理:帽子的顏色。

台灣的法律怎麼說

在台灣,未經授權入侵或干擾別人的電腦,會觸犯《刑法》第三十六章「妨害電腦使用罪」。 書裡每一段紅線都提醒同一件事:就算你「只是好奇」、「只是看看」、「沒造成損害」,也可能已經犯罪。

條文白話摘要
第 358 條無故用別人的帳號密碼、破解保護措施或利用系統漏洞,入侵別人的電腦或相關設備。
第 359 條無故取得、刪除或變更別人電腦裡的電磁紀錄,造成損害。
第 360 條無故用電腦程式或其他電磁方式干擾別人的電腦或相關設備,造成損害。
第 361 條對公務機關的電腦犯前三條的罪,刑度加重。
第 362 條製作專門用來犯本章罪的電腦程式,供自己或別人犯罪,造成損害。
⚠️
這不是法律意見

上表只是幫你記住「哪些行為會出事」的白話摘要。正式條文、刑度與最新修正,請查全國法規資料庫的《中華民國刑法》第三十六章。 遇到具體情況(例如工作上的滲透測試合約),請找懂法律的人確認。

哪裡可以練,哪裡不能碰

可以放心攻擊的地方,都有一個共同點:擁有者明確同意你攻擊它。

  • 可以:你自己的電腦;你自己跑起來的本機靶機(例如 DVWA、OWASP Juice Shop、WebGoat、書裡的 vuln_server.py); 專門給人合法練習的平台(例如 picoCTF、PortSwigger Web Security Academy);書面授權的滲透測試;明訂範圍的漏洞賞金計畫。
  • 不可以:學校、同學、公司的系統;任何不屬於你的網站或機器;公共 Wi-Fi 上別人的流量。

封包分析也一樣:你只能分析你有權擷取的流量,例如你自己的機器,或實驗室授權給你的抓包檔。竊聽別人的通訊同樣違法。

⛔
紅線

只在授權環境練習。絕不碰真實的、未經授權的系統。漏洞賞金也要待在計畫寫明的範圍(scope)內:超出範圍,就從白帽變成犯罪。

原文:第 70 章 §動手之前,先記住這條紅線、 第 72 章 §開打前的鐵律:只打授權靶機。

發現漏洞之後:負責任揭露

萬一你在真實系統裡意外發現漏洞,正確的做法是負責任揭露(responsible disclosure):

  1. 不要利用它,也不要再往下試探「看能做到多深」。
  2. 不要公開,也不要在社群上炫耀。
  3. 私下通報擁有者,清楚說明問題在哪裡、怎麼重現。
  4. 給對方合理的時間修補(常見是 90 天),修好後、在對方同意下,才公開細節。

很多公司設有漏洞賞金(bug bounty)計畫,正式邀請研究者回報漏洞,並依嚴重程度發獎金。 這是把技能用在正途、又合法的路;但一樣要先讀清楚計畫的規則與範圍。

原文:第 53 章 §Bug bounty 與負責任揭露、 第 42 章 §資安與駭客倫理(負責任揭露的小提示)。

白帽的路

CTF 練出來的能力,是真實資安工作的核心:像攻擊者一樣思考、快速學會陌生技術、團隊合作、把過程寫清楚。 這些能力可以走向滲透測試、紅隊與藍隊、漏洞賞金與資安研究。每一條路的前提都一樣:先有授權,才動手。

原文:第 74 章 §白帽的道路:職涯、社群與那條線。

把這一頁串起來

  • 白帽與犯罪只差一件事:授權。「我是好意」在法律上往往救不了你。
  • 在台灣,未經授權入侵、取得或變更資料、干擾別人的電腦,都可能觸犯《刑法》妨害電腦使用罪。
  • 只在自己的機器、本機靶機、合法練習平台、書面授權的測試與明訂範圍的漏洞賞金裡動手。
  • 發現真實漏洞:不利用、不公開、私下通報、給時間修補。
