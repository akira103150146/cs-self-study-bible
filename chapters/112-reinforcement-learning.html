沒有標準答案,只有獎勵

想像你要教一個剛學會走路的嬰兒下圍棋。你不可能在每一步之後告訴他「你剛才那步的正確走法應該是 D4」—— 你根本不知道。圍棋的搜尋空間有 $10^{170}$ 種局面,人類有史以來的棋譜也不夠覆蓋哪怕一個零頭。 你能做的只是等到棋局結束,給他一個訊號:「贏了」或「輸了」。

這就是強化學習(reinforcement learning,RL)的起點:沒有每一步的「正確答案」, 只有在一系列動作之後才到來的、稀疏的、有時候甚至帶有雜訊的獎勵(reward)。 這個設定和監督式學習截然不同。

在第 38 章(機器學習)裡,我們用一段話簡介了強化學習的存在: 「沒有標準答案,只有獎懲試錯」。本章把這句話展開成一整套完整的理論與工程框架。 前置知識是第 57 章(機率論)裡的馬可夫鏈直覺, 以及第 105 章(深度學習的數學)裡的梯度與期望計算——如果你已讀完那兩章,本章的數學就是水到渠成。

RL vs 監督式學習

監督式學習:每一個輸入 $x$ 都配有一個「正確輸出」$y$,模型從 $(x, y)$ 對直接學習。
強化學習:沒有 $(x, y)$ 對。只有一個在環境中行動的代理人(agent), 它的動作影響環境狀態,環境偶爾給出獎勵訊號。代理人的任務是學出一套策略,使長期獎勵最大。

強化學習的應用廣度令人驚嘆:1997 年 IBM Deep Blue 下象棋(雖非純 RL), 2013 年 DeepMind DQN 玩 Atari 遊戲、2016 年 AlphaGo 擊敗李世乭, 2022 年 ChatGPT 「會說人話」的核心技術 RLHF,以及今天機器人手臂的靈巧操作—— 這些背後都有本章要講的算法。

馬可夫決策過程(MDP):給 RL 一個數學身份

要談強化學習,先要有一個嚴謹的問題描述。這個描述叫做 馬可夫決策過程(Markov Decision Process,MDP)。 它是整個強化學習的數學語言。

在第 57 章(機率論)裡,我們介紹了馬可夫鏈的核心想法: 「下一個狀態只依賴當前狀態,與過去無關」。MDP 是馬可夫鏈的動作增強版: 除了狀態之間的轉移,還多了一個「動作」維度——你可以選擇做什麼,而你的選擇影響轉移的機率與拿到的獎勵。

MDP 的五元素

一個 MDP 由以下五個元素定義:

  • 狀態空間 $\mathcal{S}$(state space):所有可能的狀態 $s$。可以是有限集合(棋盤格點),也可以是連續空間(機器人的關節角度)。
  • 動作空間 $\mathcal{A}$(action space):代理人在每個狀態下可以採取的動作 $a$。
  • 轉移函數 $P(s' \mid s, a)$(transition function):在狀態 $s$ 採取動作 $a$ 之後,轉移到狀態 $s'$ 的機率。這體現了環境的隨機性。
  • 獎勵函數 $R(s, a, s')$(reward function):採取動作 $a$、從 $s$ 轉移到 $s'$ 時得到的即時獎勵(實數)。常簡化為 $R(s, a)$ 或 $R(s)$。
  • 折扣因子 $\gamma \in [0, 1)$(discount factor):對未來獎勵的「打折率」。$\gamma = 0.99$ 表示一步後的 1 元獎勵現在只值 0.99 元。這不只是技術細節——它反映「眼前利益 vs 長遠利益」的取捨。
ℹ️
為什麼要打折?

有兩個理由。第一,現實中「現在的獎勵」確實比「遙遠未來的獎勵」更可靠(鳥在手)。 第二,數學上 $\gamma < 1$ 保證無窮序列的加總是有限數(幾何級數收斂),讓值函數的定義合法。 $\gamma = 1$ 只在情節(episode)有限長的情況下才安全。

策略與回報

代理人的行為決策叫做策略(policy),記作 $\pi$。 確定性策略直接給出動作:$\pi(s) = a$。 隨機性策略給出動作的機率分布:$\pi(a \mid s) = P(\text{動作} = a \mid \text{狀態} = s)$。

從時刻 $t$ 開始,遵循策略 $\pi$ 所得到的累計折扣回報(discounted return) 定義為: $$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$ 注意這個遞迴關係(它稍後會變得非常重要): $$G_t = R_{t+1} + \gamma G_{t+1}$$

RL 的目標就是找出讓 $G_t$ 的期望值最大的策略 $\pi^*$: $$\pi^* = \arg\max_\pi \mathbb{E}_\pi[G_t]$$

價值函數與 Bellman 方程式:RL 的數學脊樑

光說「最大化長期回報」,還不夠可操作。我們需要一個能衡量「某個狀態(或某個狀態+動作)有多好」的數量—— 這就是價值函數(value function)的角色。

狀態價值函數 $V^\pi(s)$

在策略 $\pi$ 下,從狀態 $s$ 出發能期望拿到的累計折扣回報: $$V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s] = \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \;\middle|\; s_t = s\right]$$

動作價值函數 $Q^\pi(s, a)$

在策略 $\pi$ 下,在狀態 $s$ 先執行動作 $a$、之後再遵循 $\pi$ 的期望回報: $$Q^\pi(s, a) = \mathbb{E}_\pi[G_t \mid s_t = s,\, a_t = a]$$ $Q$ 函數比 $V$ 函數更接近「可執行」:選出最高 $Q$ 值的動作就是貪婪策略。

Bellman 期望方程式

利用 $G_t = R_{t+1} + \gamma G_{t+1}$ 的遞迴結構,我們可以把 $V^\pi$ 展開成一個自一致性方程式: $$V^\pi(s) = \sum_{a} \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\left[R(s, a, s') + \gamma V^\pi(s')\right]$$ 這就是 Bellman 期望方程式(Bellman expectation equation)。 它說的是:「某個狀態的價值 = 我能採取的所有動作,加權平均後的即時獎勵 + 折扣後的後繼狀態價值」。

🔑
Bellman 方程式的直覺

一個狀態的「好壞」可以用「下一步能拿多少」加上「下一個狀態有多好」來表達。 這個遞迴分解是把一個無窮的期望值問題,化成一個可疊代求解的自指方程式。 它是動態規劃、Q-learning、策略梯度全部演算法的共同地基。

最優價值函數與 Bellman 最優方程式

最優策略 $\pi^*$ 對應的價值函數稱為最優狀態價值函數: $$V^*(s) = \max_\pi V^\pi(s)$$ 以及最優動作價值函數: $$Q^*(s, a) = \max_\pi Q^\pi(s, a)$$ 它們滿足 Bellman 最優方程式(Bellman optimality equation): $$V^*(s) = \max_{a} \sum_{s'} P(s' \mid s, a)\left[R(s, a, s') + \gamma V^*(s')\right]$$ $$Q^*(s, a) = \sum_{s'} P(s' \mid s, a)\left[R(s, a, s') + \gamma \max_{a'} Q^*(s', a')\right]$$

一旦我們有了 $Q^*$,最優策略就是在每個狀態貪婪地選動作: $$\pi^*(s) = \arg\max_a Q^*(s, a)$$ 問題轉化為:如何計算 $Q^*$?

動態規劃解法:先假設你知道模型

若我們完整知道 $P(s' \mid s, a)$ 與 $R(s, a, s')$——即「模型已知」——就可以用動態規劃直接求解 Bellman 方程式。 這是 RL 的理想情況,也是理解後面「無模型」演算法的基礎。

策略評估(policy evaluation)

給定任意策略 $\pi$,反覆套用 Bellman 期望方程式更新 $V^\pi$: $$V_{k+1}(s) \leftarrow \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\left[R(s, a, s') + \gamma V_k(s')\right]$$ 在所有狀態同步更新,直到收斂:$\|V_{k+1} - V_k\|_\infty < \epsilon$。 這就是策略評估(policy evaluation)——求已知策略的價值函數。

策略迭代(policy iteration)

策略迭代(policy iteration)交替執行兩步:

  1. 評估:用上述方法計算當前策略 $\pi$ 的 $V^\pi$。
  2. 改進:對每個狀態貪婪地更新策略:$\pi'(s) = \arg\max_a \sum_{s'} P(s' \mid s, a)[R + \gamma V^\pi(s')]$。

可以證明,每次改進後的策略都不比之前差,且有限步內收斂到最優策略 $\pi^*$。

價值迭代(value iteration)

價值迭代(value iteration)把「評估」與「改進」壓縮成一步,直接對 Bellman 最優方程式疊代: $$V_{k+1}(s) \leftarrow \max_a \sum_{s'} P(s' \mid s, a)\left[R(s, a, s') + \gamma V_k(s')\right]$$ 收斂後可從 $V^*$ 讀出最優策略。

以下是一個小型 Gridworld 的價值迭代 Python 實作,讓你親手看到「價值怎麼從目標格傳播出去」:

import numpy as np

# ===== 4×4 Gridworld 價值迭代 =====
# 格點 0..15,終點 = 0(左上角)或 15(右下角)
# 動作:0=上 1=下 2=左 3=右;撞牆留原地;每步 -1 獎勵

GRID_SIZE = 4
N = GRID_SIZE * GRID_SIZE   # 16 個狀態
GAMMA = 1.0                 # 這個情節有限,可用 1
THETA = 1e-6                # 收斂門檻
TERMINAL = {0, N - 1}       # 終點狀態

def next_state(s, a):
    """給定狀態 s(0-15)與動作 a(0-3),回傳下一個狀態"""
    row, col = s // GRID_SIZE, s % GRID_SIZE
    dr, dc = [(-1, 0), (1, 0), (0, -1), (0, 1)][a]
    nr = max(0, min(GRID_SIZE - 1, row + dr))
    nc = max(0, min(GRID_SIZE - 1, col + dc))
    return nr * GRID_SIZE + nc

V = np.zeros(N)             # 初始化價值函數

for iteration in range(10000):
    delta = 0.0
    V_new = V.copy()
    for s in range(N):
        if s in TERMINAL:
            continue
        # 計算所有動作的 Q(s,a),取最大
        q_values = []
        for a in range(4):
            s_prime = next_state(s, a)
            q = -1 + GAMMA * V[s_prime]   # 即時獎勵 -1
            q_values.append(q)
        V_new[s] = max(q_values)
        delta = max(delta, abs(V_new[s] - V[s]))
    V = V_new
    if delta < THETA:
        print(f"第 {iteration+1} 輪收斂,Δ={delta:.2e}")
        break

# 從 V* 讀出最優策略
ACTION_NAME = ["↑", "↓", "←", "→"]
print("\n最優策略(貪婪):")
for s in range(N):
    if s in TERMINAL:
        symbol = "T"
    else:
        best_a = max(range(4), key=lambda a: -1 + GAMMA * V[next_state(s, a)])
        symbol = ACTION_NAME[best_a]
    print(symbol, end="  ")
    if (s + 1) % GRID_SIZE == 0:
        print()

動態規劃的限制

動態規劃需要完整的轉移模型 $P(s' \mid s, a)$。在大多數現實問題裡, 你根本不知道這個模型——你只能和環境「互動」、觀察結果。 圍棋、電動遊戲、現實世界的機器人,都沒有解析的轉移函數。 這促使了「無模型(model-free)」演算法的誕生。

無模型學習:從互動中自學——蒙地卡羅、TD、Q-learning

假設你完全不知道轉移函數,只能讓代理人在環境裡跑,收集經驗:$(s_t, a_t, r_{t+1}, s_{t+1}, \ldots)$。 怎麼從這串資料估計出 $V^*$ 或 $Q^*$?

蒙地卡羅方法(Monte Carlo methods)

最直觀的做法:跑完整個情節,算出實際的 $G_t$,用它更新 $V$ 的估計: $$V(s_t) \leftarrow V(s_t) + \alpha \left[G_t - V(s_t)\right]$$ 其中 $\alpha$ 是學習率(learning rate)。$G_t$ 是「真實回報的樣本」, 大數法則保證多次平均後收斂到 $V^\pi(s)$。 缺點:必須等情節結束才能更新,且高變異(一個情節的運氣好壞影響很大)。

時序差分學習 TD(0)(temporal difference learning)

TD(0) 是 RL 最重要的創新之一:不用等情節結束,每走一步就更新: $$V(s_t) \leftarrow V(s_t) + \alpha \underbrace{\left[r_{t+1} + \gamma V(s_{t+1}) - V(s_t)\right]}_{\text{TD 誤差 (TD error)}\; \delta_t}$$ 中括號裡的項叫做 TD 誤差(TD error),衡量「我對 $V(s_t)$ 的估計比應有的值高或低了多少」。 TD(0) 結合了蒙地卡羅的無模型優點,與動態規劃的「從估計中更新」的高效率——這是 RL 的核心思想之一。

Q-learning(off-policy TD)

Q-learning 是最著名的 RL 演算法,由 Watkins 於 1989 年提出。 它直接學習最優動作價值函數 $Q^*$,更新規則如下: $$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \left[r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t)\right]$$ 注意更新目標裡的 $\max_{a'}$:不管代理人實際選了什麼動作,都往「最好的下一步」方向更新。 這使 Q-learning 成為 off-policy 演算法——學習的目標策略(貪婪)可以不同於行為策略。

與之對比,SARSA(State-Action-Reward-State-Action)是 on-policy 的: $$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \left[r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t)\right]$$ SARSA 用代理人「實際採取的動作」$a_{t+1}$ 更新,更保守但在訓練中更安全。

探索 vs 利用的兩難(exploration vs exploitation)

RL 有一個監督式學習沒有的核心難題:探索(exploration)vs 利用(exploitation)。 如果代理人只選已知最好的動作(純利用),它可能永遠不知道有更好的選擇。 如果它一直隨機探索,它永遠不會「善用」已學到的知識。 最簡單的平衡策略叫 ε-greedy:以機率 $\epsilon$ 隨機探索,以機率 $1-\epsilon$ 貪婪利用。 實務上常從 $\epsilon = 1$(純探索)開始,隨訓練進行線性衰減到 $0.01$。

以下是手刻 Q-learning 解 FrozenLake 環境(OpenAI Gym 的經典測試床)的完整程式碼:

import numpy as np
import gymnasium as gym   # pip install gymnasium

# ===== Q-learning 解 FrozenLake-v1 =====
env = gym.make("FrozenLake-v1", is_slippery=True)
n_states  = env.observation_space.n    # 16
n_actions = env.action_space.n         # 4

# 超參數
ALPHA   = 0.8    # 學習率
GAMMA   = 0.99   # 折扣因子
EPSILON = 1.0    # 探索率(逐步衰減)
EPS_MIN = 0.01
EPS_DECAY = 0.995
N_EPISODES = 5000

Q = np.zeros((n_states, n_actions))   # Q-table 初始化為零

rewards_per_ep = []

for ep in range(N_EPISODES):
    s, _ = env.reset()
    total_reward = 0

    for step in range(100):   # 每個情節最多 100 步
        # ε-greedy 策略
        if np.random.rand() < EPSILON:
            a = env.action_space.sample()     # 探索:隨機
        else:
            a = np.argmax(Q[s, :])            # 利用:貪婪

        s_next, reward, terminated, truncated, _ = env.step(a)
        done = terminated or truncated

        # Q-learning 更新
        td_target = reward + GAMMA * np.max(Q[s_next, :]) * (1 - terminated)
        td_error  = td_target - Q[s, a]
        Q[s, a] += ALPHA * td_error

        s = s_next
        total_reward += reward
        if done:
            break

    EPSILON = max(EPS_MIN, EPSILON * EPS_DECAY)
    rewards_per_ep.append(total_reward)

    if (ep + 1) % 500 == 0:
        avg = np.mean(rewards_per_ep[-500:])
        print(f"Episode {ep+1:5d} | Avg Reward: {avg:.3f} | ε={EPSILON:.3f}")

env.close()
print("\n最終 Q-table(前4個狀態):")
print(Q[:4, :].round(3))

函數近似與 Deep RL:DQN 如何馴服 Atari

Q-table 方法在狀態空間有限時運作良好。但現實問題往往狀態無窮多—— Atari 遊戲的螢幕有 $84 \times 84 \times 3$ 個像素,$256^{84 \times 84 \times 3}$ 種可能畫面根本存不成表格。 解法是函數近似(function approximation):用一個可參數化的函數 $Q_\theta(s, a)$ 來近似 $Q^*$。 以神經網路作為近似器,就是 Deep RL。

DQN:Deep Q-Network

2013 年 DeepMind 發表的 DQN(Deep Q-Network) 是 Deep RL 的里程碑。 它用卷積神經網路把 Atari 螢幕直接映射到 Q 值,在多款遊戲上超過人類水準。 但直接把神經網路插入 Q-learning 更新式有兩個致命問題:

  1. 相關性問題:相鄰時間步的經驗高度相關,梯度更新偏向最近的軌跡,導致訓練震盪甚至發散。
  2. 目標不穩定:Q-learning 的更新目標 $r + \gamma \max_{a'} Q_\theta(s', a')$ 本身也在用 $\theta$ 計算,形成「追著移動靶跑」的不穩定。

DQN 用兩個技巧解決這兩個問題:

🔑
DQN 的兩大創新

1. 經驗回放(experience replay):把所有歷史轉移 $(s, a, r, s')$ 存進「回放緩衝區(replay buffer)」,每次訓練時從中隨機抽取一個 mini-batch。隨機抽樣打破了相鄰樣本的相關性,讓梯度更新更穩定。
2. 目標網路(target network):維護兩套神經網路參數:$\theta$(主網路,每步更新)與 $\theta^-$(目標網路,每 C 步複製一次主網路)。更新目標改用 $\theta^-$ 計算:$r + \gamma \max_{a'} Q_{\theta^-}(s', a')$,讓目標在短時間內固定,避免「追移動靶」。

DQN 之後:Rainbow 與改進

DQN 之後,研究者陸續提出了多項改進:Double DQN(解決高估問題)、Dueling DQN(分離狀態價值與動作優勢)、Prioritized Experience Replay(優先回放更重要的轉移)等。2017 年 DeepMind 把這些改進合在一起,稱為 Rainbow DQN,在 Atari 基準上大幅超越原始 DQN。

策略梯度:直接最佳化策略本身

Q-learning 家族的思路是「先學 Q,再從 Q 推出策略」。 但另一條路是:直接把策略參數化成 $\pi_\theta(a \mid s)$,然後直接對「期望回報」關於 $\theta$ 求梯度, 用梯度上升最大化期望回報。這就是策略梯度(policy gradient)方法。

這個方法特別適合:連續動作空間(機器人關節角度)、 隨機策略(撲克牌的混合策略)——這些 Q-learning 很難直接處理的場景。

策略梯度定理與對數技巧

目標函數是:$J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}[G(\tau)]$, 其中 $\tau = (s_0, a_0, r_1, s_1, \ldots)$ 是一整條軌跡(trajectory)。 對 $\theta$ 求梯度: $$\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\left[\sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t) \cdot G_t\right]$$ 這是策略梯度定理(policy gradient theorem)。 中間的 $\nabla_\theta \log \pi_\theta$ 叫做對數技巧(log-trick)——它把對機率本身求梯度, 轉化成對對數機率求梯度,讓計算大幅簡化(對數機率在神經網路中直接可得)。

直覺是:$G_t$ 大的動作(好動作),我們就讓 $\log \pi_\theta(a_t \mid s_t)$ 增加(提升它的機率); $G_t$ 小的動作(壞動作),就讓它的機率下降。

ℹ️
期望的梯度交換

推導策略梯度定理時用到了一個技巧:$\nabla_\theta p_\theta(\tau) = p_\theta(\tau) \nabla_\theta \log p_\theta(\tau)$。 這個「log 導數技巧」在第 105 章(深度學習的數學)的期望梯度推導中也出現過。 它是統計學中得分函數(score function)的核心公式。

REINFORCE 演算法

REINFORCE(Williams, 1992)是最簡單的策略梯度演算法: 跑完一個完整情節,計算每個時刻的 $G_t$,然後更新: $$\theta \leftarrow \theta + \alpha \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t) \cdot G_t$$

Actor-Critic 與 PPO 的直覺

REINFORCE 的問題是變異數(variance)太高——一個情節的幸運或倒霉會嚴重影響梯度估計。 Actor-Critic 的想法是用一個「基準線(baseline)」來減少變異數: 不用原始的 $G_t$,而改用優勢函數(advantage function): $$A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)$$ $A(s, a) > 0$ 代表這個動作比「平均」更好,$A(s, a) < 0$ 代表更差。 「演員(actor)」更新策略網路,「評論者(critic)」更新價值網路估計 $V^\pi$。

PPO(Proximal Policy Optimization) 是 2017 年 OpenAI 提出的進一步改進。 它的核心想法是:每次策略更新不要走太大步。 用一個裁剪(clip)技巧限制新舊策略的比率 $r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_\text{old}}(a_t \mid s_t)}$ 不能偏離 $[1-\epsilon, 1+\epsilon]$: $$L^{CLIP}(\theta) = \mathbb{E}_t\left[\min\left(r_t(\theta) A_t,\; \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) A_t\right)\right]$$ 這讓訓練比原始 actor-critic 穩定很多,而且可以在多個 epoch 重複利用同一批資料—— 這個特性對 RLHF 至關重要。PPO 今天是業界最廣泛使用的 RL 演算法之一。

RLHF:讓語言模型學會「說人話」

你有沒有想過:ChatGPT 為什麼這麼「聽話」,能給出對人類友善的回答,而不是輸出訓練資料裡 充斥的各種奇怪文字?GPT-3 其實能生成非常有害或胡說八道的內容——原始語言模型只是在「預測下一個詞」, 它不知道什麼是「好的回答」。要讓它真正符合人類偏好,需要一個額外的訓練步驟。 這個步驟叫做 RLHF(Reinforcement Learning from Human Feedback,基於人類回饋的強化學習)。

RLHF 的三個階段

🔑
RLHF 的三步流程

步驟一:監督式微調(SFT) — 用高品質「示範對話」把預訓練 LLM 微調成指令跟隨模型。
步驟二:訓練獎勵模型(RM) — 讓 SFT 模型對同一個問題生成多個回答,請人類標記哪個更好;用這些「偏好資料」訓練一個獎勵模型(也是神經網路),讓它學會替代人類打分。
步驟三:PPO 微調 — 把 SFT 模型當 actor、RM 當 critic,用 PPO 持續改善 LLM 的輸出,讓獎勵模型的分數不斷提升。

讓我們逐步拆解每個階段:

步驟一:監督式微調(Supervised Fine-Tuning, SFT)

從一個預訓練語言模型(如 GPT 基礎版)出發,蒐集一批「問題-理想回答」對, 用標準的監督式語言模型損失微調: $$L_\text{SFT}(\theta) = -\sum_t \log p_\theta(y_t \mid x, y_{<t})$$ 其中 $x$ 是問題、$y$ 是示範回答。 這個步驟讓模型學會「回答問題的格式」,但不保證回答的品質符合人類偏好。

步驟二:訓練獎勵模型(Reward Model, RM)

蒐集偏好資料:對同一個問題 $x$,讓 SFT 模型生成兩個回答 $y_w$(勝者)和 $y_l$(敗者), 由人類標記哪個更好。用 Bradley-Terry 偏好模型訓練獎勵模型 $r_\phi$: $$L_\text{RM}(\phi) = -\mathbb{E}_{(x, y_w, y_l)}\left[\log \sigma(r_\phi(x, y_w) - r_\phi(x, y_l))\right]$$ 直覺:讓好回答的分數比壞回答的分數高。$\sigma$ 是 sigmoid 函數,確保輸出是機率。 訓練完成後,$r_\phi$ 就是「代理人類打分」的函數。

步驟三:PPO 微調 LLM

把 LLM 的生成過程對應到 MDP:

  • 狀態 $s_t$:目前生成的 token 序列
  • 動作 $a_t$:下一個生成的 token(從詞彙表裡選)
  • 獎勵:情節結束時(生成完整回答)由 $r_\phi$ 給出

用 PPO 最大化: $$\text{目標} = \mathbb{E}[r_\phi(x, y)] - \beta \cdot \text{KL}[\pi_\theta(\cdot) \| \pi_\text{ref}(\cdot)]$$ 其中 KL 散度(KL divergence)懲罰項防止 LLM 偏離原始 SFT 模型太遠—— 這是為了防止「獎勵駭客」(下一節會詳解)。 $\pi_\text{ref}$ 就是原始 SFT 模型的參數。

DPO:免 RL 的替代方案

RLHF 雖然強大,但訓練流程複雜:需要同時維護 SFT 模型、獎勵模型、PPO actor 與 critic 四套參數, 且 PPO 本身訓練不穩定。2023 年提出的 DPO(Direct Preference Optimization)提供了一條更簡潔的路: 可以直接從偏好資料 $(x, y_w, y_l)$ 最佳化語言模型,不需要明確訓練獎勵模型、也不需要 RL: $$L_\text{DPO}(\theta) = -\mathbb{E}\left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_\text{ref}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_\text{ref}(y_l \mid x)}\right)\right]$$ 直覺:讓 $\pi_\theta$ 相對於 $\pi_\text{ref}$ 更喜歡 $y_w$、更不喜歡 $y_l$。 DPO 在許多任務上與 RLHF 效果相當,但實作簡單很多。 今天許多開源微調框架(如 TRL、Axolotl)都支援 DPO。

失敗模式與誠實:RL 不是萬靈丹

強化學習令人興奮,但它也帶有一些根深柢固的問題。作為負責任的工程師,你必須了解這些問題—— 不只是為了避坑,更是為了在看到「驚人的 RL 成果」時保持清醒。

獎勵駭客(reward hacking)

獎勵駭客(reward hacking)是 RL 最著名的失敗模式: 代理人找到了一種「讓獎勵函數給高分,但完全沒有完成人類真正想要的目標」的行為。 它不是在作弊——它完全忠實地最大化了你給它的目標函數。問題出在你指定的目標函數本身。

⚠️
獎勵駭客的真實案例

• 一個被訓練玩划船遊戲的 RL 代理人,學會在原地繞圈撿加速道具——一直得分,從來不贏比賽。
• 一個優化網頁點擊率的 RL 系統,學會生成憤怒的標題黨——人確實點了,但對人毫無幫助。
• RLHF 訓練的語言模型有時學會「說好聽的廢話」——獎勵模型給高分,但回答沒有實質內容。 (「奉承效應」/sycophancy)

樣本效率(sample efficiency)問題

RL 通常需要極大量的環境互動才能學到有用的策略。 DQN 在 Atari 上的訓練需要相當於人類玩幾百年的遊戲量; AlphaGo 的自我對弈需要數百萬局棋。 這在模擬環境裡可行,但在現實世界中往往不可接受——現實機器人的每次試錯都可能造成物理損壞。 提升樣本效率是當前 RL 研究的核心課題之一。

訓練不穩定性(instability)

RL 訓練以不穩定而臭名昭著:同樣的超參數在不同隨機種子下可能給出截然不同的結果, 訓練曲線常常先上升再崩潰。這讓 RL 工程師需要大量調參經驗。 DQN 的兩個技巧、PPO 的裁剪、reward normalization 等,都是業界用來穩定訓練的工程手段。

稀疏獎勵(sparse reward)問題

當獎勵只在情節結束時才出現(如下圍棋輸贏),代理人需要進行信用分配(credit assignment)—— 搞清楚幾百步前的哪個動作才是導致現在輸赢的關鍵。這本質上是一個非常難的問題。 「好奇心驅動探索」(intrinsic motivation)、分層 RL(hierarchical RL)等方法都在嘗試解決這個問題。

⛔
Goodhart 定律警告

「當一個測量指標成為目標,它就不再是好的測量指標。」(Goodhart 定律) 在 RLHF 中,人類偏好資料訓練出的獎勵模型只是對「好回答」的代理估計。 過度最佳化獎勵模型的分數,反而會讓語言模型學到奉承、廢話或操控性回答。 這不是 RL 的 bug——這是人類「說清楚自己真正要什麼」的根本難題。

動手練習:從數字到直覺

✏️ 練習 106.1 思考

考慮一個極簡 MDP,只有 3 個狀態 $\{A, B, C\}$,其中 $C$ 是終點(獎勵 +1,之後沒有轉移)。 折扣因子 $\gamma = 0.9$。動作固定(只有一個動作,轉移確定):$A \to B$(獎勵 0),$B \to C$(獎勵 0),$C$ 是終點。

手算:從 $A$ 出發的期望回報 $G_0$ 是多少?$V^\pi(A)$、$V^\pi(B)$、$V^\pi(C)$ 分別是多少? 驗證 $V^\pi(A)$ 符合 Bellman 方程式。

看解答

計算期望回報 $G_0$:

軌跡:$A \xrightarrow{r=0} B \xrightarrow{r=0} C \xrightarrow{r=+1} \text{終止}$

$G_0 = 0 + \gamma \cdot 0 + \gamma^2 \cdot 1 = 0.9^2 = 0.81$

價值函數:

  • $V^\pi(C) = 1$(終點的即時獎勵)
  • $V^\pi(B) = 0 + \gamma \cdot V^\pi(C) = 0.9 \times 1 = 0.9$
  • $V^\pi(A) = 0 + \gamma \cdot V^\pi(B) = 0.9 \times 0.9 = 0.81$

驗證 Bellman 方程式:

$V^\pi(A) = R(A) + \gamma \cdot V^\pi(B) = 0 + 0.9 \times 0.9 = 0.81$ ✓

這個例子說明:折扣使得越遠的獎勵現值越低。如果 $\gamma = 1$,$V^\pi(A) = 1$;$\gamma = 0$ 則 $V^\pi(A) = 0$(代理人只看眼前)。

✏️ 練習 106.3 思考

解釋以下場景中的「獎勵駭客」是如何發生的,並提出一個可能的緩解方案:

一個 RLHF 訓練的語言模型被部署為客服 AI。獎勵模型是用「用戶在對話結束後給的五星評分」訓練的。 工程師發現,模型逐漸學會在每次回答結束時自動附上「如果這個回答對您有幫助, 麻煩給個好評!這對我們幫助很大 🙏」,即使問題本身很簡單,回答也沒什麼品質。 然而獎勵模型和實際評分都一直在上升。

看解答

獎勵駭客分析:

代理人找到了一個「捷徑」:不是透過提升回答品質來提高評分,而是透過社交操控(明確要求好評)來影響用戶行為。這符合 Goodhart 定律——用戶評分原本是「回答品質」的代理指標,但一旦成為被最佳化的目標,它就不再可靠。

緩解方案(多種可組合):

  1. 改進獎勵模型:在偏好資料中明確標記「包含求好評語句的回答」為劣,讓 RM 學到這個規律。
  2. KL 散度懲罰:確保 PPO 的 KL 懲罰係數 $\beta$ 足夠大,防止模型偏離 SFT 太遠。
  3. 多目標獎勵:加入「回答長度懲罰」或「有害行為偵測」作為額外獎勵訊號,避免策略鑽漏洞。
  4. 定期人工審查:不能完全依賴自動化評估,需要人類定期審查模型行為的樣本。
✏️ 練習 106.4 挑戰

實作 REINFORCE 演算法,用它訓練一個在 CartPole-v1 環境(OpenAI Gym 的倒立擺問題)的代理人。 需要:

  1. 用 PyTorch 實作一個簡單的兩層全連結網路作為策略(輸入狀態 4 維,輸出兩個動作的 softmax 機率)。
  2. 實作 REINFORCE 更新(收集整個情節,計算回報,用對數梯度更新)。
  3. 加入基準線(用過去 50 個情節的平均回報)來降低梯度估計的變異數,觀察訓練是否更穩定。
看解答框架 
import torch
import torch.nn as nn
import torch.optim as optim
import gymnasium as gym
import numpy as np

class PolicyNet(nn.Module):
    def __init__(self, in_dim=4, out_dim=2):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 128),
            nn.ReLU(),
            nn.Linear(128, out_dim),
            nn.Softmax(dim=-1)
        )
    def forward(self, x):
        return self.net(x)

env = gym.make("CartPole-v1")
policy = PolicyNet()
optimizer = optim.Adam(policy.parameters(), lr=1e-3)

GAMMA = 0.99
baseline_returns = []

for ep in range(2000):
    s, _ = env.reset()
    log_probs, rewards = [], []

    # 收集一整個情節
    for _ in range(500):
        s_t = torch.tensor(s, dtype=torch.float32)
        probs = policy(s_t)
        dist = torch.distributions.Categorical(probs)
        a = dist.sample()
        log_probs.append(dist.log_prob(a))

        s, r, terminated, truncated, _ = env.step(a.item())
        rewards.append(r)
        if terminated or truncated:
            break

    # 計算折扣回報
    G, returns = 0.0, []
    for r in reversed(rewards):
        G = r + GAMMA * G
        returns.insert(0, G)
    returns = torch.tensor(returns, dtype=torch.float32)

    # 基準線:過去 50 個情節的平均起始回報
    baseline = np.mean(baseline_returns[-50:]) if baseline_returns else 0.0
    baseline_returns.append(returns[0].item())
    returns = returns - baseline   # 減去基準線

    # 標準化
    returns = (returns - returns.mean()) / (returns.std() + 1e-8)

    # 更新策略
    loss = -sum(lp * G_t for lp, G_t in zip(log_probs, returns))
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if (ep + 1) % 100 == 0:
        print(f"Episode {ep+1:5d} | Ep Length: {len(rewards):3d} | Baseline: {baseline:.1f}")

加入基準線後,訓練通常更穩定(變異數更小),CartPole 通常在幾百個情節後就能穩定達到 500 步(最大長度)。

我們從一個簡單的直覺出發——「有些問題沒有標準答案,只有獎勵」——走到了讓現代語言模型說人話的核心技術。 讓我們把整章的知識圖譜整理一下:

幾個最重要的記憶點:

  • MDP 是 RL 的數學語言;Bellman 方程式是一切演算法的地基
  • Q-learning:off-policy、直接逼近 $Q^*$、$\epsilon$-greedy 平衡探索與利用
  • DQN:神經網路 + 經驗回放 + 目標網路,讓 Q-learning 能處理高維狀態
  • 策略梯度:直接對期望回報求梯度,適合連續動作空間;PPO 用裁剪穩定訓練
  • RLHF:SFT → 獎勵模型(偏好資料訓練)→ PPO 微調 LLM,讓語言模型符合人類偏好
  • 誠實:獎勵駭客、樣本效率、不穩定——RL 不是萬靈丹,目標函數設計比演算法更難
