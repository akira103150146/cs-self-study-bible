最佳化問題的語言:目標、約束與可行域

在進入任何演算法之前,先學會描述問題。一個最佳化問題由三個元素組成:

決策變數(decision variables)

你「可以控制」的量,記做向量 $\mathbf{x} = (x_1, x_2, \ldots, x_n)^T \in \mathbb{R}^n$。 例如:工廠每天要生產幾個 A 產品、幾個 B 產品。 機器學習裡,決策變數就是模型的全部參數 $\boldsymbol{\theta}$。

目標函數(objective function)

你想最小化或最大化的數量,寫成 $f(\mathbf{x})$:一個把決策變數映射到實數的函數。 習慣上把問題統一寫成最小化(minimization): $$\min_{\mathbf{x}} f(\mathbf{x})$$ 最大化問題 $\max f(\mathbf{x})$ 等同於 $\min -f(\mathbf{x})$,可以互換。

約束(constraints)

你必須滿足的限制。常見有兩種:

  • 不等式約束: $g_i(\mathbf{x}) \leq 0$,例如「使用資源不超過庫存」。
  • 等式約束: $h_j(\mathbf{x}) = 0$,例如「預算必須剛好用完」。

滿足所有約束的 $\mathbf{x}$ 的集合,叫可行域(feasible region / feasible set) $\mathcal{F}$。 最佳化的目標是在 $\mathcal{F}$ 內找到讓 $f$ 最小的 $\mathbf{x}^*$。

全域最小 vs 局部最小

$\mathbf{x}^*$ 是全域最小(global minimum),如果對所有 $\mathbf{x} \in \mathcal{F}$, 都有 $f(\mathbf{x}^*) \leq f(\mathbf{x})$。 $\mathbf{x}^*$ 是局部最小(local minimum),如果只在某個鄰域內它最小。 這個區分至關重要:大多數演算法只保證找到局部最小;我們需要特殊結構(例如「凸性」)才能保證局部等於全域。

ℹ️
問題分類速查

• 線性規劃(LP):$f$ 與所有約束都是線性函數。
• 二次規劃(QP):$f$ 是二次函數,約束是線性。
• 凸優化:$f$ 與可行域都是凸的(LP、QP 是特例)。
• 非線性規劃(NLP):其餘的更一般情況。
• 整數規劃(IP):決策變數有整數約束(離散,見第 31/32 章)。

線性規劃:沿著可行多面體的頂點走

線性規劃是最佳化世界的「Hello World」:目標函數和所有約束都是線性的。 雖然看似受限,但它能解決大量真實問題——運輸調度、工廠排程、廣告預算分配、電力網絡最優潮流…… 而且有多項式時間的實用演算法。

標準式(standard form)

LP 的最大化標準式為:

$$\max_{\mathbf{x}} \; \mathbf{c}^T \mathbf{x}$$ $$\text{subject to} \quad A\mathbf{x} \leq \mathbf{b}, \quad \mathbf{x} \geq \mathbf{0}$$

其中 $\mathbf{c} \in \mathbb{R}^n$ 是目標係數向量,$A \in \mathbb{R}^{m \times n}$ 是約束矩陣, $\mathbf{b} \in \mathbb{R}^m$ 是約束右側值。用引入鬆弛變數(slack variable)的方式, 不等式可以轉成等式:引入 $\mathbf{s} \geq 0$,令 $A\mathbf{x} + \mathbf{s} = \mathbf{b}$, 就得到等式標準式(equality standard form)(鬆弛變數 $\mathbf{s}$ 補的是 $A\mathbf{x}$ 與 $\mathbf{b}$ 的差)。

📝 命名說明:本書以不等式形式作為入門「標準式」;部分教材(如 Boyd & Vandenberghe)以等式形式為 standard form、不等式形式稱 inequality form,各教材慣例略有不同,閱讀文獻時請留意。

幾何直覺:可行多面體的頂點

我們先看一個二維例子,讓幾何直覺直接映入眼簾。 考慮:最大化利潤 $z = 5x_1 + 4x_2$(產品 A 和 B 的生產量), 約束為:$x_1 + x_2 \leq 5$(工人工時), $2x_1 + x_2 \leq 8$(機器小時), $x_1, x_2 \geq 0$。

可行域是一個凸多邊形,頂點為 $(0,0)$、$(4,0)$、$(3,2)$、$(0,5)$。 目標函數的等值線(isocurve,即 $5x_1+4x_2 = k$)是一族平行直線, 沿法線方向 $(5,4)$ 往外推可使 $k$ 增大。等值線最後「掃到」頂點 $(3,2)$, 算出 $z=5 \times 3 + 4 \times 2 = 23$——這就是最優解。

🔑
LP 最基本定理

若 LP 有有限最優解,最優解一定在可行多面體的某個頂點(extreme point / vertex)取到。 這個性質讓我們不必搜遍無窮多個可行點,只要遍歷(有限個)頂點就夠了。

單純形法(Simplex Method)的直覺

由 George Dantzig 於 1947 年發明的單純形法,正是把上述幾何直覺變成演算法:

  1. 從一個頂點出發(通常是原點,若原點可行的話)。
  2. 查看相鄰頂點(即沿一條邊走到隔壁頂點):選擇讓目標值改善最多的那個移動。
  3. 重複,直到所有相鄰頂點的目標值都不比當前更好——此時已到達最優。

在上圖中,單純形法從 $(0,0)$ 出發($z=0$),發現往 $(4,0)$ 移動可得 $z=20$, 再從 $(4,0)$ 往 $(3,2)$ 移動得 $z=23$,此時所有相鄰頂點都更差,停止。

單純形法在實際問題中表現極佳(雖然最壞情況是指數時間),工業求解器(如 CPLEX、Gurobi) 對它做了大量工程優化。1984 年 Karmarkar 發明了保證多項式時間的內點法(interior-point method), 但單純形法在稀疏大型 LP 上往往仍更快。

Python 求解 LP:用 scipy.optimize

from scipy.optimize import linprog

# 最大化 z = 5x1 + 4x2
# 等同最小化 -z = -5x1 - 4x2
c = [-5, -4]                    # 目標係數 (取負號因為 linprog 只做最小化)

# 不等式約束 Ax <= b
A_ub = [
    [1, 1],    # x1 + x2 <= 5
    [2, 1],    # 2x1 + x2 <= 8
]
b_ub = [5, 8]

# 變數範圍 x1, x2 >= 0
bounds = [(0, None), (0, None)]

res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
print(f"最優解: x1={res.x[0]:.2f}, x2={res.x[1]:.2f}")
print(f"最優值: z={-res.fun:.2f}")
# 輸出: 最優解: x1=3.00, x2=2.00
#        最優值: z=23.00

凸集與凸函數:「凸」為什麼是分水嶺?

在最佳化的世界裡,「凸」這個字眼是護身符——它把「地獄模式」(NP-hard、陷入局部最小) 變成「人類可解」。理解凸性,是理解整個現代最佳化理論的鑰匙。

凸集(convex set)

集合 $\mathcal{C} \subseteq \mathbb{R}^n$ 是凸集,當且僅當對任意 $\mathbf{x}, \mathbf{y} \in \mathcal{C}$ 及 $\theta \in [0,1]$, 兩點之間的線段都在集合內: $$\theta \mathbf{x} + (1-\theta)\mathbf{y} \in \mathcal{C}$$ 直觀地說:凸集「沒有凹陷」,任意兩個可行點之間的直路都是可行的。 球、超平面、半空間、多面體(LP 的可行域)都是凸集。

凸函數(convex function)

函數 $f: \mathbb{R}^n \to \mathbb{R}$ 是凸函數,當且僅當對任意 $\mathbf{x}, \mathbf{y}$ 及 $\theta \in [0,1]$,割線(chord)始終在函數圖形的上方: $$f(\theta \mathbf{x} + (1-\theta)\mathbf{y}) \leq \theta f(\mathbf{x}) + (1-\theta)f(\mathbf{y})$$ 這就是著名的 Jensen 不等式的一元版本。 若不等號嚴格成立(即 $<$,且 $\mathbf{x} \neq \mathbf{y}$,$\theta \in (0,1)$), 則 $f$ 是嚴格凸函數(strictly convex)。

如何辨識凸函數

一維情況:$f$ 是凸函數 $\iff$ $f''(x) \geq 0$（二階導數非負,函數「開口朝上」）。
多維情況:$f$ 是凸函數 $\iff$ Hessian 矩陣 $H_f(\mathbf{x})$ 在所有點都是半正定(positive semi-definite, PSD)(Hessian 矩陣與半正定的線性代數基礎見第 54 章)。

常用凸函數舉例:

  • $f(\mathbf{x}) = \mathbf{c}^T\mathbf{x}$:線性函數(同時是凸也是凹)
  • $f(x) = x^2$、$f(\mathbf{x}) = \|\mathbf{x}\|_2^2$:二次凸函數
  • $f(\mathbf{x}) = \|\mathbf{x}\|_p$($p \geq 1$):$\ell^p$ 範數
  • $f(x) = e^{ax}$:指數函數
  • $f(x) = -\log x$($x > 0$):對數的負數
  • $f(\mathbf{x}) = \log \sum_i e^{x_i}$:log-sum-exp(在 ML 的 softmax 裡天天見)

凸函數的運算保持凸性:非負線性組合、逐點最大值、仿射複合 $f(A\mathbf{x}+\mathbf{b})$ (若 $f$ 凸)都還是凸函數——這讓我們能像搭積木一樣構造複雜的凸目標函數。

🔑
凸優化的核心定理

若問題是凸優化問題(凸目標函數 + 凸可行域),則任何局部最優解都是全域最優解。 這使得梯度下降等局部搜索演算法在凸問題上保證找到全域最優。LP 是凸優化的特例。

無約束最佳化:梯度下降與牛頓法

暫時把約束放一邊,先考慮最純粹的問題:$\min_{\mathbf{x}} f(\mathbf{x})$,沒有任何限制。 這是機器學習訓練最常見的形式——損失函數對參數無約束地最小化。

梯度下降(Gradient Descent)

梯度(gradient) $\nabla f(\mathbf{x})$ 指向函數值最快上升的方向,因此 $-\nabla f(\mathbf{x})$ 是「最速下降(steepest descent)」方向。 梯度下降的更新規則極為簡單: $$\mathbf{x}_{k+1} = \mathbf{x}_k - \alpha \nabla f(\mathbf{x}_k)$$ 其中 $\alpha > 0$ 是學習率(learning rate / step size)。

學習率的選擇是最大的實務挑戰:

  • $\alpha$ 太小:每步移動距離極短,收斂慢到懷疑人生。
  • $\alpha$ 太大:每步「跨過」最小值到對面的山坡,可能發散。
  • 理論上的最優步長需要知道 Hessian 的 Lipschitz 常數,實務上常用線搜索(line search)或固定小值。

對凸函數,梯度下降的收斂速度是 $O(1/k)$(迭代次數的倒數)。下面是一個手刻範例:

import numpy as np

def f(x):
    """目標函數: f(x1,x2) = x1^2 + 4*x2^2  (橢圓形碗)"""
    return x[0]**2 + 4*x[1]**2

def grad_f(x):
    """梯度: [2*x1, 8*x2]"""
    return np.array([2*x[0], 8*x[1]])

# 梯度下降
x = np.array([3.0, 2.0])   # 初始點
alpha = 0.1                  # 學習率
for k in range(30):
    g = grad_f(x)
    x = x - alpha * g
    if k % 5 == 0:
        print(f"iter {k:2d}: x={x}, f={f(x):.6f}")

# iter  0: x=[ 2.4   0.4], f=6.400000
# iter  5: x=[ 0.786  0.001], f=0.617828
# iter 25: x=[0.008  0.000], f=0.000065

收斂條件

判斷梯度下降何時停止,最常用的準則是梯度範數夠小:$\|\nabla f(\mathbf{x}_k)\| < \varepsilon$。 對於嚴格凸函數,當梯度為零時恰好是唯一最小值點。

牛頓法(Newton's Method)

梯度下降只用了一階資訊。牛頓法進一步利用二階資訊——Hessian 矩陣 $H_f(\mathbf{x}) = \nabla^2 f(\mathbf{x})$: $$\mathbf{x}_{k+1} = \mathbf{x}_k - \left[H_f(\mathbf{x}_k)\right]^{-1} \nabla f(\mathbf{x}_k)$$ Hessian 告訴函數在各方向的「彎曲程度」,牛頓法因此能動態調整每個方向的步長。 它的收斂速度是二次(quadratic)的:接近最優點後,每次迭代誤差大約平方縮小。 而梯度下降只有線性收斂。

⚠️
牛頓法的代價

牛頓法每步需要計算並求逆 $n \times n$ Hessian 矩陣,代價是 $O(n^3)$。 對神經網路來說 $n$ 可能是幾十億——完全無法直接使用。 這是為什麼大規模 ML 只用梯度資訊,而非精確的二階方法。

ℹ️
與第 55 章的連結

第 55 章從數值分析的角度介紹了梯度法與牛頓法(用於求根)。 本章從最佳化的角度看待同一工具:梯度下降 = 把一階泰勒展開最小化; 牛頓法 = 把二階泰勒展開(二次近似)最小化。兩章互補,建議對照閱讀。

有約束最佳化:拉格朗日乘子、KKT 條件與對偶

現實中多數最佳化問題都有約束。這一節是本章最數學密集的部分, 但背後的直覺其實相當優美——值得慢慢品味。

等式約束:拉格朗日乘子

先看純等式約束問題: $$\min_{\mathbf{x}} f(\mathbf{x}) \quad \text{s.t.} \quad h_j(\mathbf{x}) = 0, \; j=1,\ldots,p$$

幾何直覺:在最優點 $\mathbf{x}^*$,目標函數的等值面必須與約束曲面相切—— 否則你還能沿著約束面移動去改善目標值。 「相切」的數學表達是:$\nabla f(\mathbf{x}^*)$ 可以用 $\nabla h_j(\mathbf{x}^*)$ 的線性組合表示: $$\nabla f(\mathbf{x}^*) + \sum_{j=1}^p \nu_j^* \nabla h_j(\mathbf{x}^*) = \mathbf{0}$$ 係數 $\nu_j^*$ 就是拉格朗日乘子(Lagrange multiplier)。 構造拉格朗日函數(Lagrangian) $L(\mathbf{x}, \boldsymbol{\nu}) = f(\mathbf{x}) + \sum_j \nu_j h_j(\mathbf{x})$, 則最優點恰好使 $\nabla_{\mathbf{x}} L = 0$ 且 $\nabla_{\boldsymbol{\nu}} L = 0$($= h_j = 0$)同時成立。

推廣到不等式約束:KKT 條件

對含不等式約束的一般問題: $$\min_{\mathbf{x}} f(\mathbf{x}) \quad \text{s.t.} \quad g_i(\mathbf{x}) \leq 0, \; i=1,\ldots,m, \quad h_j(\mathbf{x}) = 0, \; j=1,\ldots,p$$

定義廣義拉格朗日函數:

$$L(\mathbf{x}, \boldsymbol{\lambda}, \boldsymbol{\nu}) = f(\mathbf{x}) + \sum_{i=1}^m \lambda_i g_i(\mathbf{x}) + \sum_{j=1}^p \nu_j h_j(\mathbf{x})$$

在技術性假設(約束規格化條件,最常用的是 Slater 條件:存在嚴格可行點)下, 最優點 $\mathbf{x}^*$ 必須滿足以下四組 KKT 條件(Karush-Kuhn-Tucker conditions):

  1. 駐點性(Stationarity): $$\nabla_{\mathbf{x}} L(\mathbf{x}^*, \boldsymbol{\lambda}^*, \boldsymbol{\nu}^*) = \nabla f(\mathbf{x}^*) + \sum_i \lambda_i^* \nabla g_i(\mathbf{x}^*) + \sum_j \nu_j^* \nabla h_j(\mathbf{x}^*) = \mathbf{0}$$
  2. 原始可行性(Primal feasibility): $$g_i(\mathbf{x}^*) \leq 0, \quad h_j(\mathbf{x}^*) = 0$$
  3. 對偶可行性(Dual feasibility): $$\lambda_i^* \geq 0 \quad \forall i$$
  4. 互補鬆弛(Complementary slackness): $$\lambda_i^* \cdot g_i(\mathbf{x}^*) = 0 \quad \forall i$$

條件 4 有個優雅的意思:對每個不等式約束 $i$,要麼 $\lambda_i^* = 0$(這個約束「不緊繃」,不影響最優解), 要麼 $g_i(\mathbf{x}^*) = 0$(這個約束「緊繃」,在邊界上,影響最優解)——兩者不能同時為非零。

🔑
KKT 是必要條件,也可以是充分條件

KKT 條件對所有(光滑)最優化問題都是必要條件(在適當的約束規格化條件下)。 對凸優化問題,KKT 條件同時也是充分條件: 滿足 KKT 的點就是全域最優解。這使得對凸問題,只需解一個 KKT 方程組。

對偶問題(Dual Problem)與對偶理論

從 Lagrangian 可以定義拉格朗日對偶函數(Lagrange dual function): $$g(\boldsymbol{\lambda}, \boldsymbol{\nu}) = \inf_{\mathbf{x} \in \mathcal{D}} L(\mathbf{x}, \boldsymbol{\lambda}, \boldsymbol{\nu})$$ 對 $\mathbf{x}$ 取下確界,消去原始變數。$g$ 是凹函數(即使原始問題不是凸的!)。

對偶問題(dual problem)是最大化對偶函數: $$\max_{\boldsymbol{\lambda} \geq \mathbf{0}, \boldsymbol{\nu}} \; g(\boldsymbol{\lambda}, \boldsymbol{\nu})$$ 設原始問題最優值為 $p^*$,對偶問題最優值為 $d^*$。

弱對偶(Weak Duality):對任意對偶可行的 $(\boldsymbol{\lambda}, \boldsymbol{\nu})$, 有 $g(\boldsymbol{\lambda}, \boldsymbol{\nu}) \leq p^*$。等價地,$d^* \leq p^*$。 這對任何問題都成立,不需要凸性。差距 $p^* - d^*$ 稱為對偶間距(duality gap)。

強對偶(Strong Duality):當 $d^* = p^*$(對偶間距為零)時稱為強對偶。 對凸優化問題,在 Slater 條件下強對偶成立: 只要存在一個嚴格可行點(strict interior point)使得所有不等式約束嚴格成立,即 $g_i(\mathbf{x}_0) < 0$。 LP 永遠滿足 Slater 條件(如果可行的話),因此 LP 的強對偶永遠成立——這就是 LP 對偶理論的基礎。

💡
對偶的實際用途

對偶問題有時比原始問題更好解。支持向量機(SVM)的核心技巧就是把原始 QP 轉化為對偶形式, 讓核函數能以 $O(n^2)$ 而非 $O(d)$ 的複雜度出現($n$ 是樣本數,$d$ 是原始特徵維度)。 拉格朗日乘子 $\lambda_i$ 在 SVM 中正是支持向量的「重要性係數」—— 非支持向量對應的 $\lambda_i = 0$(互補鬆弛!)。

實務:凸優化求解器與大規模 ML

cvxpy:規範凸程式設計

手寫 KKT 方程組或呼叫底層 LP 求解器,對大多數工程問題而言太繁瑣。 cvxpy(Python 函式庫)採用「規範凸程式設計(Disciplined Convex Programming, DCP)」的設計哲學: 它內建一套凸性推斷引擎(基於組合規則),讓你用接近數學符號的方式寫出問題, 系統自動驗證凸性並選擇合適的後端求解器(OSQP、SCS、ECOS 等)。 

import cvxpy as cp

# 同樣的 LP:最大化 5x1 + 4x2
x = cp.Variable(2, nonneg=True)          # x1, x2 >= 0

objective   = cp.Maximize(5*x[0] + 4*x[1])
constraints = [
    x[0] + x[1] <= 5,
    2*x[0] + x[1] <= 8,
]

prob = cp.Problem(objective, constraints)
prob.solve()

print(f"最優值: {prob.value:.2f}")        # 23.00
print(f"最優解: x={x.value}")            # [3. 2.]

# 取對偶乘子(影子價格)
for c in constraints:
    print(f"對偶乘子: {c.dual_value:.4f}")

cvxpy 返回的對偶乘子(dual value)就是 KKT 中的 $\lambda^*$, 在 LP 中也叫影子價格(shadow price):它告訴你放鬆某個約束一個單位, 目標值能改善多少——一個對資源配置決策極有價值的資訊。

大規模 ML 的現實:SGD、動量與 Adam

深度學習的參數可能達幾十億,每步精確計算梯度就需要掃過整個訓練集。 這兩個限制迫使我們用隨機梯度下降(Stochastic Gradient Descent, SGD): 每步只用一個小批次(mini-batch)估計梯度,用雜訊換取計算速度。

SGD 的收斂比精確梯度下降慢,但在超大規模問題上往往是唯一可行的選擇。 工程上有幾個重要改良:

  • 動量(Momentum):加入過去梯度的指數平均,讓更新方向更平滑,加速穿越「峽谷」地形: $$\mathbf{v}_{k+1} = \beta \mathbf{v}_k + (1-\beta)\nabla f(\mathbf{x}_k), \quad \mathbf{x}_{k+1} = \mathbf{x}_k - \alpha \mathbf{v}_{k+1}$$
  • Adam(Adaptive Moment Estimation):同時維護梯度的一階矩(均值)和二階矩(方差), 給每個參數分量自適應地調整學習率。Adam 是目前深度學習訓練的預設選擇。
ℹ️
為何深度學習仍能找到好解?

神經網路的損失函數是非凸的——理論上 SGD 不保證找到全域最優。 但實踐發現,充分超參數化(overparameterized)的大型神經網路的「壞」局部最小點其實很少, 訓練過程中 SGD 幾乎都能找到泛化能力良好的解。 這背後的理論(例如隨機矩陣理論、隱式正則化)仍是活躍的研究前沿。

與離散最佳化的橋:鬆弛連回 §31 與 §32

到目前為止我們都在連續世界——決策變數可以取任意實數值。 但現實問題常常要求整數答案:工廠不能生產 2.7 個零件,航班不能排 0.5 架飛機。 這就進入了整數規劃(Integer Programming, IP)的領域, 它在最壞情況下是 NP-hard,不再有凸優化的美麗保證。

LP 鬆弛(LP Relaxation)

整數規劃的一個重要技巧是鬆弛(relaxation): 把整數約束 $x_i \in \mathbb{Z}$ 放鬆為實數 $x_i \in \mathbb{R}$, 得到一個 LP。LP 鬆弛的最優值提供原問題的上界(最大化問題), 然後可以用分支定界(Branch and Bound)逐步收緊到整數解。

有些特殊的 IP 有神奇的性質——LP 鬆弛的最優解自動是整數: 最短路、最小生成樹、最大流/最小割……這些問題背後的約束矩陣是全單模矩陣(totally unimodular), 保證 LP 頂點都是整數頂點。這就是為什麼 Dijkstra 和 Kruskal 可以直接給出整數解。

貪婪與 DP:特殊結構的離散最佳化

第 31 章的貪婪演算法成立,正是因為問題具有 貪婪選擇性質(greedy choice property)——每一步的局部最優選擇都與全域最優相容。 用最佳化的語言說,是問題結構讓 LP 鬆弛的最優解恰好落在整數頂點。 霍夫曼編碼、最小生成樹,骨子裡都是在某個組合結構的「凸包頂點」找最優。

第 32 章的動態規劃則對應最優子結構: 大問題的最優解可以由子問題的最優解組合而成。 這與連續最佳化裡 Bellman 方程式的結構相同——事實上, DP 本來就源自 Richard Bellman 的最佳化研究,「Bellman-Ford」裡的 Bellman 就是同一個人。

💡
最佳化的三個武器庫

面對一個最佳化問題,先問三個問題: ① 它是凸的嗎?若是,用 LP/QP/凸規劃求解器,保證全域最優。 ② 它有最優子結構嗎?若是,考慮 DP 或 LP 鬆弛 + 分支定界。 ③ 它有貪婪選擇性質嗎?若是,用貪婪演算法,時間最快。 三者互補,而非替代關係。

練習

✏️ 練習 103.1 思考

某工廠生產兩種產品 X 和 Y。每個 X 需要 3 小時機器時間和 1 小時人工, 利潤為 6 元;每個 Y 需要 1 小時機器時間和 2 小時人工,利潤為 4 元。 每天機器時間上限 12 小時,人工上限 8 小時,且產量不得為負。 請將此問題寫成 LP 標準式(最大化目標,含所有約束),並指出決策變數是什麼。

看解答

決策變數:$x_1$ = 每天生產 X 的數量,$x_2$ = 每天生產 Y 的數量。

LP 標準式:

$$\max_{x_1, x_2} \; 6x_1 + 4x_2$$ $$\text{subject to} \quad 3x_1 + x_2 \leq 12 \quad (\text{機器時間})$$ $$x_1 + 2x_2 \leq 8 \quad (\text{人工時間})$$ $$x_1 \geq 0, \quad x_2 \geq 0$$

用 Python/scipy 或圖解法:可行域的頂點為 $(0,0)$、$(4,0)$、$(16/5, 12/5)$、$(0,4)$。 其中 $3x_1+x_2=12$ 與 $x_1+2x_2=8$ 的交點: $5x_1 = 16 \Rightarrow x_1=16/5=3.2$,$x_2=(8-3.2)/2=2.4$, 目標值 $= 6(3.2)+4(2.4) = 19.2+9.6 = 28.8$。 $(4,0)$ 時目標值 $=24$;$(0,4)$ 時 $=16$。 最優解:$x_1=3.2$,$x_2=2.4$,最大利潤 $28.8$ 元。

✏️ 練習 103.2 思考

判斷以下函數是否為凸函數。請說明判斷依據(可用二階導數或定義)。

  1. $f(x) = 3x^2 - 2x + 5$
  2. $f(x) = -x^2 + 4x$
  3. $f(x) = |x|$
  4. $f(x,y) = x^2 + xy + y^2$
  5. $f(x) = \log(1 + e^x)$（softplus 函數,深度學習常見）
看解答

(a) $f(x) = 3x^2 - 2x + 5$:
$f''(x) = 6 > 0$,恆正。凸函數。

(b) $f(x) = -x^2 + 4x$:
$f''(x) = -2 < 0$,恆負。凹函數(concave),不是凸函數。

(c) $f(x) = |x|$:
絕對值函數在 $x=0$ 不可微,無法直接用 $f''$。改用定義: $|\theta x + (1-\theta)y| \leq |\theta x| + |(1-\theta)y| = \theta|x| + (1-\theta)|y|$ (三角不等式)。凸函數(且是 $\ell^1$ 範數,所有範數都是凸函數)。

(d) $f(x,y) = x^2 + xy + y^2$:
Hessian:$H = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$。 特徵值:$\lambda = 2 \pm 1$,即 $3$ 和 $1$,均為正。Hessian 正定,嚴格凸函數。

(e) $f(x) = \log(1+e^x)$:
$f'(x) = \frac{e^x}{1+e^x} = \sigma(x)$(sigmoid)。 $f''(x) = \sigma(x)(1-\sigma(x)) \geq 0$(因為 $\sigma \in (0,1)$)。凸函數。 事實上 softplus 是 $\max(0,x)$(ReLU)的光滑近似,兩者都是凸函數。

✏️ 練習 103.3 實作

對函數 $f(x_1, x_2) = (x_1 - 3)^2 + 2(x_2 + 1)^2$, 手刻梯度下降從初始點 $(0, 0)$ 出發,學習率 $\alpha = 0.1$,迭代 50 次。 (a) 先推導梯度解析式;(b) 寫 Python 程式執行;(c) 說明最優解應該是多少。

看解答

(a) 梯度:

$$\nabla f = \begin{pmatrix} 2(x_1 - 3) \\ 4(x_2 + 1) \end{pmatrix}$$

(b) Python 實作:

import numpy as np

def f(x):
    return (x[0]-3)**2 + 2*(x[1]+1)**2

def grad_f(x):
    return np.array([2*(x[0]-3), 4*(x[1]+1)])

x = np.array([0.0, 0.0])
alpha = 0.1

for k in range(50):
    x = x - alpha * grad_f(x)

print(f"最優解近似: x={x}")
print(f"目標值: f={f(x):.8f}")
# 最優解近似: x=[ 3.000 -1.000]
# 目標值: f=0.00000000

(c) 理論最優解:$(x_1^*, x_2^*) = (3, -1)$,此時 $f^* = 0$。 函數是嚴格凸的(Hessian $= \mathrm{diag}(2, 4) \succ 0$), 梯度在 $(3,-1)$ 處為零,即為唯一全域最小值點。

✏️ 練習 103.4 挑戰

考慮帶等式約束的問題:最小化 $f(x_1, x_2) = x_1^2 + x_2^2$, 約束為 $x_1 + 2x_2 = 5$。 (a) 寫出 Lagrangian;(b) 列出 KKT 駐點條件並求解 $x^*$ 和 $\nu^*$; (c) 說明為何此解是全域最小值。

看解答

(a) Lagrangian:

$$L(x_1, x_2, \nu) = x_1^2 + x_2^2 + \nu(x_1 + 2x_2 - 5)$$

(b) 駐點條件 $\nabla_{\mathbf{x}} L = 0$ 給出:

$$\frac{\partial L}{\partial x_1} = 2x_1 + \nu = 0 \Rightarrow x_1 = -\nu/2$$ $$\frac{\partial L}{\partial x_2} = 2x_2 + 2\nu = 0 \Rightarrow x_2 = -\nu$$

代入等式約束 $x_1 + 2x_2 = 5$:

$$-\nu/2 + 2(-\nu) = 5 \Rightarrow -5\nu/2 = 5 \Rightarrow \nu^* = -2$$ $$x_1^* = 1, \quad x_2^* = 2, \quad f^* = 1 + 4 = 5$$

(c) 全域最小的理由:目標函數 $f = x_1^2 + x_2^2$ 是嚴格凸函數, 約束集 $\{x_1+2x_2=5\}$ 是仿射集(也是凸集)。 等式約束的凸優化問題,KKT 駐點條件既是必要也是充分的, 因此 $(1, 2)$ 是在約束 $x_1+2x_2=5$ 上離原點最近的點,也是唯一全域最小值。 幾何上,它是從原點做 $x_1+2x_2=5$ 這條直線的垂線的垂足。

把這一章串起來

我們從「最佳化問題的三要素(決策變數、目標函數、約束)」出發, 沿著一條清晰的概念階梯走完了連續最佳化的主要脈絡:

  • 線性規劃(LP):目標與約束全部線性,可行域是凸多面體,最優解在頂點取到。 單純形法沿著邊移動頂點;LP 對偶提供「影子價格」與強對偶保證。
  • 凸函數與凸集:凸性是「局部最優 = 全域最優」的關鍵前提。 LP 是凸優化的特例;許多機器學習損失函數(邏輯回歸、SVM、線性回歸)也是凸的。
  • 無約束最佳化:梯度下降以 $O(1/k)$ 線性收斂;牛頓法以二次速度收斂但成本高。 大規模 ML 因維度限制只能用 SGD 及其變體(動量、Adam)。
  • 有約束最佳化:拉格朗日乘子把約束「融入」目標; KKT 四條件(駐點性、原始可行性、對偶可行性、互補鬆弛)是最優性的完整刻畫; 對偶理論提供弱對偶下界,凸問題在 Slater 條件下強對偶成立。
  • 與離散最佳化的橋:LP 鬆弛 + 分支定界是整數規劃的主力框架; 全單模矩陣保證 LP 鬆弛直接給整數解;貪婪與 DP 是特殊組合結構的高效特例。

這些工具不只是理論:每一個都在真實系統中跑著。 CVXPY 讓幾十行 Python 就能優化資源配置; Adam 的每次反向傳播都在執行凸近似; SVM 的 KKT 條件直接給出哪些樣本是「重要的支持向量」。 最佳化是演算法、統計、運籌與工程的共同語言,讀懂它,你讀論文的眼睛會突然「通了」。
