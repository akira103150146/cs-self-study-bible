核心觀念

讀程式的能力,比寫程式更早需要。這一章的目標只有一個:看到一段 C 程式,你能一行一行算出它會印出什麼。

如果你的電腦有 gcc(在 Linux 或 macOS 的終端機打 gcc --version 看看,終端機的用法見第 16 章), 本章每一段程式都可以存成 .c 檔自己跑。沒有也沒關係,先用眼睛和紙筆讀。

第一支 C 程式:骨架與編譯

Python 印一行字只要 print("Hello, C!")。C 要多寫幾行:

#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    return 0;
}

一行一行看:

  • #include <stdio.h>:載入標準輸入輸出函式庫。printf、scanf 都在裡面。很像 Python 的 import。
  • int main(void):程式從 main 開始執行。int 表示它最後回傳一個整數。
  • { }:大括號包住一個區塊。Python 用縮排分區塊,C 用大括號;C 的縮排只是給人看的。
  • ;:每一個敘述都以分號結束。
  • \n:換行。printf 不會自動換行,這和 Python 的 print 不同。
  • return 0;:回傳 0,表示程式正常結束。

C 要先編譯(compile)成執行檔才能跑。Python 是直接執行原始檔:

gcc -std=c11 -Wall hello.c -o hello   # 編譯:hello.c → 執行檔 hello
./hello                               # 執行,印出 Hello, C!
💡
小技巧

編譯時一定加 -Wall(打開大部分警告)。本章後面的好幾個陷阱,gcc -Wall 都會先警告你。

型別與宣告:先說好盒子有多大

在 Python 裡,x = 16 直接就能用,變數的型別跟著值走。C 不一樣:每個變數使用前都要宣告型別,而且型別之後不能換。 你可以把變數想成一個盒子,宣告就是先說好「這個盒子裝什麼、有多大」。 

#include <stdio.h>

int main(void) {
    int age = 16;                 // 整數
    long long big = 3000000000LL; // 很大的整數
    double pi = 3.14159;          // 小數(浮點數)
    char grade = 'A';             // 一個字元
    printf("%d %lld %.2f %c\n", age, big, pi, grade);
    return 0;
}

輸出:

16 3000000000 3.14 A
型別裝什麼常見大小常見範圍
int整數4 位元組(32 位元)約 −21 億 到 21 億(−2147483648 到 2147483647)
long long很大的整數8 位元組約 ±9.2×1018
double小數(浮點數)8 位元組有效數字約 15–16 位
char一個字元(其實是小整數)1 位元組常見是 −128 到 127

Python 的整數可以無限大。C 的 int 有上限,超過就溢位(overflow)。 兩個 5 萬相乘是 25 億,已經超過 int 的上限: 

#include <stdio.h>

int main(void) {
    int a = 50000, b = 50000;
    long long good = (long long)a * b;  // 先轉成 long long 再乘
    printf("%lld\n", good);
    // int bad = a * b;  // 兩個 int 相乘,結果超過 int 範圍:溢位
    return 0;
}

輸出:

2500000000
⚠️
常見陷阱:先算完才轉型

寫成 long long c = a * b; 沒有用。a * b 是兩個 int 相乘,在存進 c 之前就已經溢位了。 要在乘之前先轉:(long long)a * b。

有號整數溢位在 C 標準裡是未定義行為(undefined behavior):標準沒有規定結果。在常見的電腦上,2147483647 + 1 通常會變成 -2147483648;APCS 題目若問溢位,多半就是要你看出「變成負數」。 只有 unsigned(無號)整數,C 標準才保證超過上限會「繞回」從 0 開始。

(long long) 這種寫法叫強制轉型(cast):把一個值轉成括號裡的型別,很像 Python 的 int(x)、float(x)。 浮點數為什麼有誤差,見第 102 章。

printf 與 scanf:格式字串

printf 的第一個參數是格式字串。字串裡的 %d 這類記號是「空位」,後面的值依序填進去。 很像 Python 的 f-string,只是值寫在後面。 

#include <stdio.h>

int main(void) {
    int a, b;
    scanf("%d %d", &a, &b);              // 讀入兩個整數,記得加 &
    printf("和 = %d\n", a + b);
    printf("平均 = %.1f\n", (a + b) / 2.0);
    printf("[%5d][%-5d][%05d]\n", a, a, a);
    printf("100%%\n");
    return 0;
}

輸入 7 4 時,輸出:

和 = 11
平均 = 5.5
[    7][7    ][00007]
100%
格式用途例子印出
%dintprintf("%d", 42)42
%lldlong longprintf("%lld", 3000000000LL)3000000000
%f、%.2fdouble;.2 表示小數點後 2 位printf("%.2f", 3.14159)3.14
%c一個字元printf("%c", 'A')A
%s字串printf("%s", "cat")cat
%5d、%-5d、%05d寬度 5:靠右、靠左、前面補 0見上面的程式[ 7][7 ][00007]
%%印出一個 %printf("100%%")100%

scanf 反過來:照格式字串讀入資料,存進變數。注意變數前面的 &: scanf 需要知道變數「放在哪裡」,才能把值寫進去。&a 就是 a 的位址。為什麼要這樣,讀到本章的指標那一節就會懂。 

#include <stdio.h>

int main(void) {
    double h;
    long long n;
    char c;
    scanf("%lf %lld %c", &h, &n, &c);   // double 用 %lf,long long 用 %lld
    printf("%.2f %lld %c\n", h, n, c);  // 印 double 用 %f 就好
    return 0;
}

輸入 1.75 3000000000 Y 時,輸出是 1.75 3000000000 Y。

型別printf 印出scanf 讀入
int%d%d
long long%lld%lld
double%f%lf(注意多一個 l)
char%c%c(前面加空白 " %c" 可跳過空白與換行)
⚠️
常見陷阱

格式和型別要對上:long long 在 printf 和 scanf 都要用 %lld,用 %d 會得到錯的數字。 double 比較特別:printf 印出用 %f,scanf 讀入卻要用 %lf(用 %f 讀會讀錯)。scanf 忘了 &,程式可能直接當掉。

運算子:整數除法、%、++ 與 --

整數除法:C 往 0 捨去

Python 有兩種除法:/ 一定得到小數,// 是整數除法。C 只有一個 /,它看兩邊的型別決定做哪一種: 兩邊都是整數,就做整數除法;有一邊是小數,就做小數除法。 

#include <stdio.h>

int main(void) {
    printf("%d %d\n", 7 / 2, 7 % 2);
    printf("%d %d\n", -7 / 2, -7 % 2);
    double r1 = 7 / 2;          // 先算整數除法得 3,再存成 3.0
    double r2 = 7 / 2.0;        // 有一邊是小數,就做小數除法
    double r3 = (double)7 / 2;  // 先把 7 轉成 7.0
    printf("%.1f %.1f %.1f\n", r1, r2, r3);
    return 0;
}

輸出:

3 1
-3 -1
3.0 3.5 3.5

第二行要特別小心。C 的整數除法往 0 捨去:-7 / 2 是 −3.5,捨去小數得 -3。 Python 的 // 是往下取整:-7 // 2 是 -4。 % 也跟著不同:C 的 -7 % 2 是 -1(餘數和被除數同號),Python 的 -7 % 2 是 1。

🔑
核心觀念

C 裡永遠成立:(a / b) * b + a % b == a。先用往 0 捨去算出商,再用這條式子算餘數,就不會錯。

第三行是另一個常考點:double r1 = 7 / 2; 得到 3.0,不是 3.5。 右邊兩個都是整數,先做整數除法得 3,存進 double 才變成 3.0。「存進哪種盒子」不會回頭改變「怎麼算」。

++ 與 --:先用還是先加

Python 沒有 ++,只能寫 i += 1。C 的 i++ 和 ++i 都會把 i 加 1,差別在「這個式子的值」:

#include <stdio.h>

int main(void) {
    int i = 5;
    int a = i++;   // 先把 i 的值(5)給 a,再把 i 加 1
    int b = ++i;   // 先把 i 加 1(變 7),再把值給 b
    printf("%d %d %d\n", a, b, i);
    i += 3;        // i = i + 3
    i *= 2;        // i = i * 2
    printf("%d\n", i);
    return 0;
}

輸出:

5 7 7
20
  • i++(後置):式子的值是加之前的 i。所以 a 拿到 5,之後 i 變 6。
  • ++i(前置):先加 1,式子的值是加之後的 i。所以 i 變 7,b 拿到 7。
  • i += 3、i *= 2 和 Python 一樣。7 + 3 = 10,10 × 2 = 20。
⛔
不要寫的式子

同一個式子裡把同一個變數改兩次,例如 i = i++; 或 i++ + i++,在 C 是未定義行為,不同編譯器結果可能不同。這種式子沒有確定的答案,APCS 題目一般不會這樣出;你自己也不要寫。

比較與邏輯:0 是假,其他都是真

C 的比較運算子和 Python 一樣(==、!=、<、<=……)。 邏輯運算子換了寫法:Python 的 and、or、not 在 C 是 &&、||、!。 比較的結果是整數 1(真)或 0(假),而在條件裡,0 是假,任何非 0 的值都是真。 (C99 起可以 #include <stdbool.h> 使用 bool、true、false,但它們本質上還是 1 和 0;APCS 題目多半直接用整數。)

流程控制:if、switch 與三種迴圈

if 與 else

條件要放在小括號裡,區塊用大括號。elif 在 C 寫成 else if:

if (score >= 60) {
    printf("pass\n");
} else if (score >= 50) {
    printf("retry\n");
} else {
    printf("fail\n");
}

如果區塊只有一行,C 允許省略大括號。這是很多陷阱的來源,本章後面會專門講。

switch:記得 break,否則會「落下」

switch 依一個整數的值跳到對應的 case。重點是:跳進去之後,它會一直往下做,直到遇到 break 或 switch 結束。 這叫「落下」(fall-through)。 

#include <stdio.h>

int main(void) {
    int n = 2, score = 0;
    switch (n) {
        case 1: score += 1;
        case 2: score += 2;   // 從這裡進來
        case 3: score += 3;   // 沒有 break,繼續往下做
            break;            // 到這裡才跳出
        default: score += 100;
    }
    printf("%d\n", score);
    return 0;
}

輸出是 5。n 是 2,從 case 2 進去:加 2;沒有 break,落到 case 3 再加 3;遇到 break 跳出。 2 + 3 = 5。default 是「其他情況」,這次沒有走到。

for、while、do-while

C 的 for 和 Python 的 for x in range(...) 長得不一樣。它有三個部分,用分號隔開:for (起始; 條件; 每圈結束時做的事)。 for (int i = 1; i <= 10; i++) 就是 Python 的 for i in range(1, 11)。 

#include <stdio.h>

int main(void) {
    int sum = 0;
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) continue;   // 跳過 3 的倍數
        sum += i;
    }
    printf("sum = %d\n", sum);

    int n = 1230, r = 0;
    while (n > 0) {
        r = r * 10 + n % 10;   // 取出最後一位,接到 r 後面
        n /= 10;               // 去掉最後一位
    }
    printf("r = %d\n", r);

    int k = 10;
    do {
        printf("k = %d\n", k);  // 條件一開始就不成立,但還是會做一次
        k++;
    } while (k < 5);
    return 0;
}

輸出:

sum = 37
r = 321
k = 10
  • for:continue 跳過 3、6、9,所以 sum = 1 + 2 + 4 + 5 + 7 + 8 + 10 = 37。break 和 continue 的意思和 Python 一樣。
  • while:和 Python 的 while 一樣,先檢查條件再做。從 1230 依序取出 0、3、2、1,把數字反過來,得到 321(開頭的 0 不會留下)。
  • do-while:Python 沒有。它先做一次,再檢查條件。所以就算 k < 5 一開始就不成立,也會印出一次。注意結尾的 while (k < 5); 有分號。

陣列:固定大小,從 0 開始

C 的陣列(array)很像 Python 的 list,但有三個重要差別:大小固定、所有元素型別相同、超出範圍不會報錯。 索引一樣從 0 開始:長度 5 的陣列,合法索引是 0 到 4。 

#include <stdio.h>

int main(void) {
    int a[5] = {3, 1, 4, 1, 5};
    int b[5] = {0};                  // 全部設成 0
    int n = sizeof(a) / sizeof(a[0]); // 陣列長度:5
    for (int i = 0; i < n; i++) {
        b[i] = a[n - 1 - i];         // 反過來複製
    }
    for (int i = 0; i < n; i++) {
        printf("%d ", b[i]);
    }
    printf("\n");

    int m[2][3] = {{1, 2, 3}, {4, 5, 6}};
    printf("%d %d\n", m[1][2], m[0][1]);
    return 0;
}

輸出:

5 1 4 1 3 
6 2
  • int b[5] = {0};:沒列出的元素都設成 0。只寫 int b[5]; 而不初始化的話,裡面是不確定的舊資料。
  • C 的陣列沒有 len()。sizeof(a) 是整個陣列的位元組數(5 × 4 = 20),除以一個元素的位元組數就是長度。
  • 二維陣列 m[2][3] 是 2 列、每列 3 個。m[1][2] 是第 1 列(從 0 數)的第 2 個,也就是 6。
⚠️
常見陷阱:越界不會報錯

Python 讀 a[5] 會丟出 IndexError。C 讀 a[5] 不會報錯,它會讀到陣列後面那塊記憶體裡的東西;寫入 a[5] 更可能蓋掉別的變數。 迴圈寫成 i <= n 而不是 i < n,就會多走一格。這正是第 36 章緩衝區溢位的起點。

二維陣列在記憶體裡是一列接著一列排的(row-major)。m[i][j] 前面有 i × 3 + j 個元素。 APCS 常考「某個元素的位址」,用的就是這條式子;第 65 章的觀念題例題 1 有完整的算法。

字元與字串:以 '\0' 結尾的字元陣列

C 的 char 其實是一個小整數,存的是字元的編碼(ASCII)。'A' 是 65,'a' 是 97,'0' 是 48。 所以字元可以做加減:'A' + 2 就是 'C'。注意單引號 'A' 是一個字元,雙引號 "A" 是字串,兩者不同。

C 沒有 Python 那種字串型別。C 的字串是一個字元陣列,最後放一個 '\0'(值為 0 的字元)當結尾記號。 "cat" 看起來 3 個字,實際佔 4 格: 

#include <stdio.h>
#include <string.h>

int main(void) {
    char c = 'A';
    printf("%c %d %c\n", c, c, c + 2);   // 字元其實是一個小整數

    char s[] = "cat";                     // 'c' 'a' 't' '\0'
    printf("%zu %zu\n", sizeof(s), strlen(s));

    char word[] = "Hello APCS";
    int upper = 0;
    for (int i = 0; word[i] != '\0'; i++) {   // 走到 '\0' 為止
        if (word[i] >= 'A' && word[i] <= 'Z') upper++;
    }
    printf("upper = %d\n", upper);
    return 0;
}

輸出:

A 65 C
4 3
upper = 5
  • printf("%c %d %c", c, c, c + 2):同一個 'A',用 %c 印是 A,用 %d 印是 65;65 + 2 = 67,是 C。
  • strlen 在 <string.h> 裡,它從頭數到 '\0' 為止。%zu 是印 sizeof、strlen 結果用的格式。
  • 迴圈條件 word[i] != '\0' 是走訪字串的標準寫法。"Hello APCS" 有 H、A、P、C、S 五個大寫字母。
⚠️
常見陷阱

C 的字串不能用 == 比較內容(那是在比位址),要用 strcmp;也不能用 = 整串複製,要用 strcpy。 而 strcpy、gets 不檢查長度,目的陣列放不下就會越界。第 36 章會告訴你這為什麼危險。

函式與傳值:參數是複本

C 的函式要寫出回傳型別和每個參數的型別。不回傳值的函式,回傳型別寫 void。 函式要在使用前定義(或先寫一行宣告)。 

#include <stdio.h>

void swap_bad(int x, int y) {   // x、y 是複本
    int t = x;
    x = y;
    y = t;
}

void fill(int arr[], int n) {   // 陣列傳進來的是「位址」
    for (int i = 0; i < n; i++) {
        arr[i] = i * i;
    }
}

int counter(void) {
    static int c = 0;   // static:只在第一次初始化,值會留著
    c++;
    return c;
}

int main(void) {
    int a = 1, b = 2;
    swap_bad(a, b);
    printf("%d %d\n", a, b);

    int sq[4];
    fill(sq, 4);
    printf("%d %d %d %d\n", sq[0], sq[1], sq[2], sq[3]);

    counter();
    counter();
    printf("%d\n", counter());
    return 0;
}

輸出:

1 2
0 1 4 9
3
  • 傳值(pass by value):呼叫 swap_bad(a, b) 時,x、y 拿到的是 a、b 的複本。函式裡交換的是複本,main 的 a、b 沒變,還是 1 2。
  • 陣列例外:陣列當參數時,傳進去的是陣列第 0 格的位址,不是整個陣列的複本。所以 fill 改 arr[i],main 的 sq 也跟著變。
  • static 區域變數:只在第一次呼叫時初始化,函式結束後值還留著。呼叫三次,c 依序變 1、2、3,所以印出 3。
ℹ️
和 Python 對照

Python 傳進函式的 list,在函式裡改內容,外面也看得到;但在函式裡把參數重新指定成別的東西,外面看不到。C 的規則更單純:一律傳值。陣列看起來像例外,是因為「被傳的值」本身就是一個位址。

指標初探:& 與 *

每個變數都放在記憶體的某個位置,這個位置的編號叫位址(address)。 指標(pointer)就是一個「存位址的變數」。讀 APCS 和第 24、36 章,你只需要會兩個符號:

  • &x:取出 x 的位址。
  • *p:到 p 存的位址,去讀或寫那裡的值。

宣告時的 int *p 意思是「p 是一個指標,指向 int」。

#include <stdio.h>

void swap(int *x, int *y) {   // x、y 是位址
    int t = *x;
    *x = *y;
    *y = t;
}

int main(void) {
    int x = 10;
    int *p = &x;       // p 存的是 x 的位址
    *p = 20;           // 透過 p 改 x
    printf("%d %d\n", x, *p);

    int a = 1, b = 2;
    swap(&a, &b);
    printf("%d %d\n", a, b);

    int arr[3] = {10, 20, 30};
    int *q = arr;      // 陣列名稱在這裡會自動轉成第 0 格的位址
    printf("%d %d %d\n", *q, *(q + 1), q[2]);
    return 0;
}

輸出:

20 20
2 1
10 20 30
  • *p = 20; 改的是 p 指向的那格,也就是 x。所以 x 和 *p 都是 20。
  • 上一節的 swap_bad 失敗了。這一版把 a、b 的位址傳進去,函式透過 *x、*y 改到原本的變數,交換成功。 這也是 scanf("%d", &a) 要加 & 的原因:scanf 要知道 a 在哪裡,才能把讀到的值寫進去。
  • 陣列名稱 arr 在大多數式子裡會自動轉成第 0 格的位址(sizeof(arr) 是例外,它算的是整個陣列)。*(q + 1) 是「往後一格」的值,和 q[1] 完全一樣。q[2] 就是 30。

第 24 章還會用到 malloc:在程式執行時跟系統要一塊記憶體,得到它的位址。 讀懂下面這段就夠了: 

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 5;
    int *arr = malloc(n * sizeof(int));   // 要 n 個 int 的空間
    if (arr == NULL) {                    // 要不到記憶體
        return 1;
    }
    for (int i = 0; i < n; i++) {
        arr[i] = i * 10;
    }
    printf("%d %d\n", arr[0], arr[n - 1]);
    free(arr);                            // 用完要還
    return 0;
}

輸出是 0 40。malloc(n * sizeof(int)) 要的是「n 個 int 那麼多位元組」;要不到時回傳 NULL(空位址),所以要檢查; 用完要 free 還回去。Python 會自動回收記憶體,C 要你自己還。

APCS 程式識讀最愛的陷阱

程式識讀(以前的觀念題)常常不是考你「會不會」,而是考你「有沒有看漏」。下面這幾個,每一個都出現過很多次。

陷阱一:短路求值

&& 的左邊是假,右邊不會執行(整個結果已經確定是假);|| 的左邊是真,右邊也不會執行。 Python 的 and、or 也一樣。右邊如果有 ++ 或函式呼叫,就要看它到底有沒有被執行。 

#include <stdio.h>

int main(void) {
    int i = 0, cnt = 0;
    if (i != 0 && 10 / i > 1) {   // i != 0 是假,右邊不會算,不會除以 0
        cnt++;
    }
    int x = 0;
    if (x == 0 || ++x > 0) {      // 左邊已經是真,右邊的 ++x 不會做
        cnt++;
    }
    printf("%d %d\n", cnt, x);
    return 0;
}

輸出是 1 0。第一個 if 左邊 i != 0 是假,右邊的 10 / i 沒有算,所以不會除以 0,cnt 也沒加。 第二個 if 左邊 x == 0 是真,右邊的 ++x 沒有做,所以 x 還是 0,而 cnt 變成 1。

陷阱二:= 和 ==

#include <stdio.h>

int main(void) {
    int x = 3;
    if (x = 5) {             // 錯誤示範:這是「指定」,不是「比較」
        printf("x is %d\n", x);
    }
    return 0;
}

輸出是 x is 5。x = 5 是指定:把 5 存進 x,整個式子的值是 5。5 不是 0,所以條件成立,而且 x 已經被改掉了。 Python 不准在 if 裡這樣寫,C 准。gcc -Wall 會警告「suggest parentheses around assignment used as truth value」。

陷阱三:少了大括號

#include <stdio.h>

int main(void) {
    int x = 5, y = 0;
    if (x > 10)
        y = 1;
        x = 0;               // 錯誤示範:縮排騙人,這行不屬於 if
    printf("%d %d\n", x, y);
    return 0;
}

輸出是 0 0。沒有大括號時,if 只管緊接的那一個敘述(y = 1;)。 x = 0; 縮排得像在 if 裡,其實每次都會執行。C 不看縮排。gcc -Wall 會警告「misleading indentation」。

同一類的陷阱是「else 跟誰」:

#include <stdio.h>

int main(void) {
    int a = 1, b = 0;
    if (a == 0)
        if (b == 0)
            printf("A\n");
    else                     // 這個 else 跟的是最近的 if (b == 0)
        printf("B\n");
    printf("done\n");
    return 0;
}

輸出只有 done。else 永遠跟最近的、還沒配對的 if,也就是 if (b == 0),不管縮排怎麼排。 外層 a == 0 是假,裡面整段都不執行,A 和 B 都不會印。

陷阱四:switch 少了 break

前面講過:從符合的 case 進去後,一路往下做到 break 為止。看到 switch,先找每個 case 有沒有 break。

陷阱五:整數溢位與整數除法

兩個 int 相乘可能超過 21 億;double avg = (a + b) / 2; 會先做整數除法。 看到 /,先問自己:兩邊都是整數嗎?

陷阱六:多一個分號、多一格

for (i = 0; i < 5; i++);   // 這個分號就是迴圈的全部內容(空敘述)
{
    printf("%d\n", i);      // 迴圈結束後只執行一次,印出 5
}

for (...) 或 if (...) 後面多一個分號,迴圈或條件就只管那個「空敘述」,後面的大括號變成普通區塊。 gcc -Wall 的縮排誤導警告(-Wmisleading-indentation)只在下一行的排法看起來像迴圈本體時才會出現: 上面這種排法,用 gcc 13 測試會警告;如果分號後面直接接一行沒有大括號、也沒有縮排的 printf,就不會警告。不要依賴警告。 還有 i <= n 和 i < n 的差別:長度 n 的陣列,最後一格是 n - 1。

💡
考場上的檢查順序

拿到一段 C 程式,先掃一遍:每個 / 是整數除法嗎?每個 if、for 有大括號嗎、後面有沒有多分號?switch 有 break 嗎? &&、|| 右邊有 ++ 嗎?迴圈邊界是 < 還是 <=?掃完再開始手追。

手追程式:用追蹤表一行一行算

程式識讀最常見的問法是「這段程式印出什麼」。最可靠的方法是畫一張追蹤表(trace table): 每一列記下「執行到哪一步、變數變成多少、印出什麼」。不要心算跳步,一格一格填。

範例一:巢狀迴圈

#include <stdio.h>

int main(void) {
    int s = 0;
    for (int i = 1; i <= 3; i++) {
        for (int j = i; j <= 3; j++) {
            s += i * j;
        }
    }
    printf("%d\n", s);
    return 0;
}

內層的 j 從 i 開始,所以每一輪外層,內層跑的次數都少一次。只記「s += i * j 執行時」的狀態:

步驟iji * js(執行後)輸出
11111
21223
31336
422410
523616
633925
74(結束)——2525

內層一共執行 3 + 2 + 1 = 6 次。最後 i 變成 4,條件 i <= 3 不成立,迴圈結束,印出 25。

範例二:遞迴

#include <stdio.h>

int f(int n) {
    if (n <= 1) return 1;
    return f(n - 1) + 2 * f(n - 2);
}

int main(void) {
    printf("%d\n", f(4));
    return 0;
}

遞迴題先從最小的情況往上算,把結果記成一張表,就不必展開一整棵呼叫樹:

呼叫走哪一條計算回傳
f(0)n <= 1—1
f(1)n <= 1—1
f(2)遞迴f(1) + 2 * f(0) = 1 + 2 × 13
f(3)遞迴f(2) + 2 * f(1) = 3 + 2 × 15
f(4)遞迴f(3) + 2 * f(2) = 5 + 2 × 311

印出 11。如果題目問的是「f 一共被呼叫幾次」,這張表就不夠了,要畫呼叫樹:每個 f(n)(n ≥ 2)會再呼叫兩次。 遞迴追蹤更多的題型,見第 65 章的例題 5 到 7,以及第 3 章。

範例三:指標、陣列與函式

#include <stdio.h>

void update(int *p, int v) {
    *p = *p + v;
    v = 0;
}

int main(void) {
    int a[3] = {1, 2, 3};
    int k = 10;
    for (int i = 0; i < 3; i++) {
        update(&a[i], k);
        k = k - 3;
    }
    printf("%d %d %d %d\n", a[0], a[1], a[2], k);
    return 0;
}

update 有兩個參數:p 是位址(改 *p 會改到 main 的陣列),v 是複本(改 v 不影響 main 的 k)。

步驟i呼叫a(呼叫後)k(這一圈結束)輸出
10update(&a[0], 10):a[0] = 1 + 10{11, 2, 3}7
21update(&a[1], 7):a[1] = 2 + 7{11, 9, 3}4
32update(&a[2], 4):a[2] = 3 + 4{11, 9, 7}1
43(結束)—{11, 9, 7}111 9 7 1

函式裡的 v = 0; 只改了複本,所以 k 照著 10 → 7 → 4 → 1 變化。

    return 0;
}

輸入 10 時印出 30(2 + 4 + 6 + 8 + 10)。對照重點:range(2, n + 1, 2) 變成 for (int i = 2; i <= n; i += 2); input() 變成 scanf("%d", &n),記得 &。如果 n 可能很大(例如 106),總和會超過 int,total 要改成 long long、用 %lld 印出。

把這一章串起來

  • 骨架:#include、int main(void)、大括號分區塊、分號結束敘述;C 要先編譯再執行。
  • 型別:變數要先宣告型別。int 有上限,超過會溢位;要大數用 long long,在運算之前轉型。
  • 輸入輸出:printf 用格式字串填空;scanf 要傳變數的位址 &x。
  • 運算:兩個整數相除是整數除法,往 0 捨去;% 和被除數同號。i++ 先用後加,++i 先加後用。
  • 流程:switch 會落下到 break;do-while 至少做一次;沒有大括號的 if 只管一個敘述;else 跟最近的 if。
  • 陣列與字串:大小固定、從 0 開始、越界不報錯;字串是以 '\0' 結尾的字元陣列。
  • 函式與指標:參數一律傳值;陣列傳的是位址;& 取位址,* 透過位址讀寫。
  • 手追:先掃陷阱,再畫追蹤表,一格一格填,不要跳步。
