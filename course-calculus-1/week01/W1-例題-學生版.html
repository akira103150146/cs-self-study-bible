Formal Definition of a Limit｜極限的正式定義

A challenge-and-response game: you name the tolerance, I find the window
🧭
引導推導

跟著老師一步步想,自己把道理推出來:

  1. 定義裡是誰先出手?$\varepsilon$ 和 $\delta$ 哪一個是「對手的挑戰」、哪一個是「你的回應」?
  2. $|f(x)-L|<\varepsilon$ 在圖上是什麼?($y$ 軸的一條 )
  3. $0<|x-a|<\delta$ 在圖上是什麼?為什麼左邊要寫 $0<$?
  4. 如果某個 $\delta$ 可行,比它更小的 $\delta$ 還可行嗎?為什麼這讓「存在一個」就夠了?
一起做 · 示範
示範進階

State precisely, in $\varepsilon$-$\delta$ language, what $\displaystyle\lim_{x\to 2}(3x-1)=5$ asserts.

一起想:把 $a$、$L$、$f(x)$ 各是什麼先標出來,再照定義填進去。

作答區
換你練習
  1. Write the $\varepsilon$-$\delta$ statement for $\displaystyle\lim_{x\to 1}(2x+3)=5$.
  2. Explain in one sentence why the definition uses $0<|x-a|$ rather than $|x-a|$.
  3. Does the definition require $f(a)$ to be defined? Justify your answer.
