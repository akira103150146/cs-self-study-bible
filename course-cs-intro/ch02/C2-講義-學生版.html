C2.1 Numbers and Positional Notation｜數字與位值記數

The value of a digit depends on its position · 基礎
① 觀念
💡
Concept

A number is a unit of an abstract mathematical system. We use natural numbers (0, 1, 2, …), integers (…, −2, −1, 0, 1, 2, …), and rational numbers (an integer or the quotient of two integers, such as $-1/3$ or $5/2$).

In positional notation, the value of a digit depends on its position. The base (or radix) $b$ tells how many digits the system has: base $b$ uses the digits $0, 1, \dots, b-1$. A number with digits $d_{n-1} \dots d_1 d_0$ in base $b$ means

$$d_{n-1} b^{n-1} + \cdots + d_1 b^1 + d_0 b^0.$$

For bases larger than 10 we borrow letters: A = 10, B = 11, …, F = 15 in hexadecimal, and up to Z = 35 in base 36. We write the base as a subscript when it is not obvious: $943_{10}$, $1011_2$, $\text{FF}_{16}$.

名詞對照
English中文說明
natural number自然數0、1、2、…(本課從 0 開始)
integer整數包含負數與 0
rational number有理數可以寫成兩個整數相除的數
positional notation位值記數法數字的值由它所在的位置決定
base / radix基底每一位可用的數字個數,也是位與位之間的倍數
digit數字、位數0 到 b−1 其中之一
hexadecimal十六進位基底 16,用 0–9 與 A–F
白話說

$943$ 的 9 之所以代表九百,是因為它在「百位」。換個基底,每一位的權重就從 $10^i$ 換成 $b^i$,道理完全一樣。

最容易犯的錯是忘記「基底 b 只能用 0 到 b−1」:二進位沒有 2,八進位沒有 8、9。看到 $1021_2$ 就要馬上說「這不是合法的二進位數」。

後面會用到
  • 計算機組織:記憶體位址、機器指令幾乎都用十六進位寫(例如 0x7ffd…)。
  • 資料結構與演算法:雜湊、Base64、進位轉換都是位值記數的應用。
  • 本課第 3 章:所有資料的表示都建立在「位元 + 位值」上。
② 老師講解
例 1

Write $943_{10}$ and $2013_{8}$ in expanded positional form, and compute the decimal value of $2013_8$.

  1. 找出每一位的權重:最右邊是第 0 位,權重 $b^0 = 1$,往左依序是 $b^1, b^2, \dots$。
  2. $943_{10} = 9 \times 10^2 + 4 \times 10^1 + 3 \times 10^0 = 900 + 40 + 3$。
  3. $2013_8 = 2 \times 8^3 + 0 \times 8^2 + 1 \times 8^1 + 3 \times 8^0$。
  4. 計算:$2 \times 512 + 0 + 8 + 3 = 1024 + 11 = 1035$,所以 $2013_8 = 1035_{10}$。
例 2

Which of the following are valid numerals in the given base? (a) $1021_2$, (b) $778_8$, (c) $\text{1AF}_{16}$, (d) $\text{G1}_{16}$.

  1. 規則:基底 b 只能出現 0 到 b−1。
  2. (a) 二進位只有 0、1,出現 2 → 不合法。
  3. (b) 八進位只有 0–7,出現 8 → 不合法。
  4. (c) 十六進位 0–9、A–F(15)都合法 → 合法,值為 $1 \times 256 + 10 \times 16 + 15 = 431$。
  5. (d) G 代表 16,超過 15 → 不合法。

C2.2 Converting from Base b to Decimal｜從 b 進位轉成十進位

Expand by powers — or use Horner's rule · 基礎
① 觀念
💡
Concept

To convert a numeral from base $b$ to decimal, multiply each digit by its positional weight and add:

$$d_{n-1} \dots d_1 d_0\ (\text{base } b) = \sum_{i=0}^{n-1} d_i\, b^i.$$

Horner's rule computes the same value from left to right with only one multiplication per digit:

$$v \leftarrow 0; \quad \text{for each digit } d \text{ from left to right:}\ v \leftarrow v \cdot b + d.$$

Digits to the right of the radix point have negative powers: $0.d_{-1} d_{-2} \dots = d_{-1} b^{-1} + d_{-2} b^{-2} + \cdots$. For example $0.101_2 = 1/2 + 0/4 + 1/8 = 0.625$.

名詞對照
English中文說明
positional weight位值權重第 i 位的權重 $b^i$
Horner's ruleHorner 法由左到右「乘 b 再加下一位」的求值法
radix point小數點(基底點)分隔整數與小數部分的點
overflow溢位結果超出可表示的範圍
白話說

展開法很直觀,但要先算好每個 $b^i$。Horner 法更像「一邊讀一邊算」:讀到下一位,就把目前的值乘上 b(整體往左移一位)再加上新的一位。電腦讀字串轉數字(例如 C 的 strtol)就是這樣做的,Lab 任務 2 你要自己實作它。

後面會用到
  • 程式設計:把使用者輸入的字串變成數字,就是 Horner 法。
  • 演算法:Horner 法也是多項式求值的標準方法,乘法次數從 $O(n^2)$ 降到 $O(n)$。
  • 資訊安全:忘了檢查溢位的字串轉整數,是真實世界漏洞的常見來源。
② 老師講解
例 1

Convert $101101_2$ to decimal twice: by expansion and by Horner's rule.

  1. 展開法:$1 \cdot 32 + 0 \cdot 16 + 1 \cdot 8 + 1 \cdot 4 + 0 \cdot 2 + 1 \cdot 1 = 32 + 8 + 4 + 1 = 45$。
  2. Horner 法,由左到右,$v$ 從 0 開始:
  3. 讀 1:$v = 0 \cdot 2 + 1 = 1$;讀 0:$v = 2$;讀 1:$v = 5$;讀 1:$v = 11$;讀 0:$v = 22$;讀 1:$v = 45$。
  4. 兩種方法都得到 45。Horner 法不需要事先知道有幾位,適合一邊讀字串一邊算。
例 2

Convert $\text{B2F}_{16}$ and $0.11_2$ to decimal.

  1. $\text{B2F}_{16}$:B = 11、2、F = 15。
  2. Horner:$v = 11$;$v = 11 \cdot 16 + 2 = 178$;$v = 178 \cdot 16 + 15 = 2863$。
  3. $0.11_2 = 1 \cdot 2^{-1} + 1 \cdot 2^{-2} = 0.5 + 0.25 = 0.75$。
  4. 檢查合理性:$\text{B2F}_{16}$ 有三位,應介於 $16^2 = 256$ 與 $16^3 = 4096$ 之間,2863 合理。

C2.3 Converting from Decimal to Base b｜從十進位轉成 b 進位

Divide for the integer part, multiply for the fraction · 進階
① 觀念
💡
Concept

Integer part — repeated division. Divide the number by $b$; the remainder is the rightmost digit. Divide the quotient by $b$ again; the remainder is the next digit to the left. Continue until the quotient is 0. Read the remainders from the last to the first.

Fractional part — repeated multiplication. Multiply the fraction by $b$; the integer part of the result is the first digit after the radix point. Keep the fractional part and repeat. Stop when the fraction becomes 0 or when you have enough digits.

Some fractions that are finite in decimal are infinite repeating in binary. For example

$$0.1_{10} = 0.0\overline{0011}_2 = 0.000110011001100\ldots_2$$

so $0.1$ cannot be stored exactly in a binary computer.

名詞對照
English中文說明
quotient商除法的結果
remainder餘數除不盡剩下的部分,$0 \le r < b$
repeated division連除法一直除以 b、收集餘數
repeated multiplication連乘法小數一直乘以 b、收集整數部分
repeating fraction循環小數小數部分無限重複
白話說

整數部分:每除一次 b,就把「最右邊那一位」剝下來(就是餘數)。因為先剝下來的是最低位,所以最後要倒過來讀。

小數部分:每乘一次 b,就把「小數點後第一位」推到整數部分,把它拿走,剩下的繼續。這次是順著讀。

十進位的 0.1 在二進位是無限循環小數——這就是為什麼程式裡 0.1 + 0.2 不會剛好等於 0.3(第 3 章詳談)。

後面會用到
  • 計算機組織:浮點數表示(IEEE 754)的第一步就是把十進位小數轉成二進位。
  • 數值方法:捨入誤差的來源。
  • 程式設計:printf("%x")、bin() 背後就是連除法;Lab 任務 3 你要自己寫。
② 老師講解
例 1

Convert $179_{10}$ to binary and to hexadecimal.

  1. 二進位,連除 2:179 ÷ 2 = 89 餘 1;89 ÷ 2 = 44 餘 1;44 ÷ 2 = 22 餘 0;22 ÷ 2 = 11 餘 0;11 ÷ 2 = 5 餘 1;5 ÷ 2 = 2 餘 1;2 ÷ 2 = 1 餘 0;1 ÷ 2 = 0 餘 1。
  2. 倒著讀餘數:$10110011_2$。
  3. 十六進位,連除 16:179 ÷ 16 = 11 餘 3;11 ÷ 16 = 0 餘 11(B)。倒著讀:$\text{B3}_{16}$。
  4. 驗算:$\text{B3}_{16} = 11 \cdot 16 + 3 = 179$ ✓;$10110011_2 = 128 + 32 + 16 + 2 + 1 = 179$ ✓。
例 2

Convert $0.1_{10}$ to binary, showing the first 8 digits, and explain the pattern.

  1. $0.1 \times 2 = 0.2$ → 取 0,剩 0.2。
  2. $0.2 \times 2 = 0.4$ → 0;$0.4 \times 2 = 0.8$ → 0;$0.8 \times 2 = 1.6$ → 1,剩 0.6。
  3. $0.6 \times 2 = 1.2$ → 1,剩 0.2——回到第 1 步之後的狀態,開始循環。
  4. 接著:0.2 → 0、0.4 → 0、0.8 → 1。前 8 位:$0.00011001_2$。
  5. 餘下的小數在 0.2 → 0.4 → 0.8 → 0.6 之間永遠打轉,所以是無限循環小數 $0.0\overline{0011}_2$。

C2.4 Arithmetic in Other Bases｜各進位的四則運算

Same long-hand methods — carry and borrow b instead of 10 · 進階
① 觀念
💡
Concept

The pencil-and-paper methods you learned for decimal work in any base; only the number at which you carry or borrow changes.

  • Addition: add column by column from the right. If a column sum $s \ge b$, write $s - b$ and carry 1 to the next column.
  • Subtraction: subtract column by column from the right. If the top digit is smaller, borrow one from the next column: the current column gains $b$.
  • Multiplication: multiply by each digit of the multiplier, shift, and add the partial products — all in base $b$.

In binary the tables are tiny: $0+0=0$, $0+1=1$, $1+1=10_2$ (write 0, carry 1), and $1+1+1=11_2$ (write 1, carry 1). Binary multiplication is just "shift and add".

名詞對照
English中文說明
carry進位一欄的和 ≥ b 時,往左一欄加 1
borrow借位被減數不夠減時,向左一欄借 1(相當於本欄加 b)
partial product部分積直式乘法中每一列的乘積
shift移位往左移一位 = 乘以 b
白話說

十進位的直式加法,是「滿 10 進 1」;八進位就是「滿 8 進 1」,二進位就是「滿 2 進 1」。減法借位時,借來的不是 10,而是 b。

二進位乘法特別簡單:乘數的某一位是 1 就把被乘數左移到那一位抄下來,是 0 就跳過,最後全部加起來。CPU 的乘法器就是這樣做的。

後面會用到
  • 數位邏輯:加法器電路(第 4 章)就是把二進位直式加法做成硬體。
  • 計算機組織:乘法器用「移位與相加」;減法用二補數加法(第 3 章)實現。
  • 資料結構:大數運算(延伸專案)就是在陣列上做直式運算。
② 老師講解
例 1

Compute $1011_2 + 111_2$ and $\text{8A}_{16} + \text{F9}_{16}$.

  1. 二進位,由右往左:1+1 = 10 → 寫 0 進 1;1+1+1 = 11 → 寫 1 進 1;0+1+1 = 10 → 寫 0 進 1;1+0+1 = 10 → 寫 0 進 1;最後寫下進位 1。結果 $10010_2$。
  2. 驗算:$11 + 7 = 18 = 10010_2$ ✓。
  3. 十六進位:A + 9 = 10 + 9 = 19 ≥ 16 → 寫 19 − 16 = 3,進 1;8 + F + 1 = 8 + 15 + 1 = 24 → 寫 8,進 1;寫下進位 1。結果 $\text{183}_{16}$。
  4. 驗算:$138 + 249 = 387 = 1 \cdot 256 + 8 \cdot 16 + 3$ ✓。
例 2

Compute $1000_2 - 11_2$ and $101_2 \times 11_2$.

  1. 減法:最右欄 0 − 1 不夠,向左借;但左邊都是 0,要一路借到最高位的 1。借完後各位變成 $0\,1\,1\,(10)_2$。
  2. 逐欄相減:$10_2 - 1 = 1$;$1 - 1 = 0$;$1 - 0 = 1$;$0$。結果 $101_2$。驗算:$8 - 3 = 5$ ✓。
  3. 乘法:$101 \times 11$:乘數最右位 1 → 抄 $101$;下一位 1 → 左移一位抄 $1010$。
  4. 相加:$101 + 1010 = 1111_2 = 15$。驗算:$5 \times 3 = 15$ ✓。

C2.5 Power-of-2 Number Systems｜2 的冪次進位

Octal groups 3 bits, hexadecimal groups 4 — no arithmetic needed · 基礎
① 觀念
💡
Concept

When the base is a power of 2, $b = 2^k$, each digit corresponds to exactly $k$ bits. So conversion between binary and base $2^k$ needs no division — just grouping:

  • Binary → octal ($8 = 2^3$): group bits in threes starting from the right (from the radix point), pad the leftmost group with zeros, and replace each group by one octal digit.
  • Binary → hexadecimal ($16 = 2^4$): group in fours.
  • Octal or hexadecimal → binary: replace each digit by its 3-bit or 4-bit pattern.
  • Octal ↔ hexadecimal: go through binary.

For fractions, group from the radix point to the right, padding the rightmost group with zeros.

名詞對照
English中文說明
octal八進位基底 8,每位對應 3 個位元
hexadecimal十六進位基底 16,每位對應 4 個位元
nibble半位元組4 個位元,剛好一位十六進位
grouping分組每 k 個位元換成一位 $2^k$ 進位數字
padding補零位元數不是 k 的倍數時在前(或後)面補 0
白話說

十六進位之所以在電腦界這麼常見,是因為它是二進位的縮寫:一位十六進位剛好是 4 個位元,一個位元組(8 位元)剛好寫成兩位十六進位。11010110 很難一眼看清,寫成 D6 就清楚多了。

轉換只要記住 0–F 的 4 位元樣子,不必做任何除法。唯一要小心的是從哪一邊開始分組:一定從小數點(整數的最右邊)往外分。

後面會用到
  • 計算機組織:記憶體位址、機器碼、顏色(#FF8800)都用十六進位。
  • 作業系統:Unix 檔案權限用八進位(chmod 755),因為每 3 個位元是一組 rwx。
  • 資訊安全與網路:Base64(6 位元一組)、IPv6(16 位元一組)都是同一個分組的想法;延伸專案 2 會實作 Base64。
② 老師講解
例 1

Convert $10101011_2$ to octal and hexadecimal.

  1. 八進位,3 位一組,從右邊開始:$10\ 101\ 011$;最左組只有 2 位,補成 $010$。
  2. 各組換成數字:$010 = 2$、$101 = 5$、$011 = 3$ → $253_8$。
  3. 十六進位,4 位一組:$1010\ 1011$ → A、B → $\text{AB}_{16}$。
  4. 驗算:$\text{AB}_{16} = 171$;$253_8 = 2 \cdot 64 + 5 \cdot 8 + 3 = 171$ ✓。
例 2

Convert $\text{3F7}_{16}$ to octal, and $1011.1_2$ to hexadecimal.

  1. 十六進位 → 二進位:3 = $0011$、F = $1111$、7 = $0111$ → $0011\,1111\,0111$。
  2. 重新 3 位一組:$001\ 111\ 110\ 111$ → 1、7、6、7 → $1767_8$。
  3. 含小數:$1011.1_2$,整數部分從小數點往左分:$1011$ → B;小數部分從小數點往右分,不足 4 位在右邊補零:$1000$ → 8。
  4. 結果 $\text{B.8}_{16}$。驗算:$11 + 8/16 = 11.5$,而 $1011.1_2 = 11.5$ ✓。

C2.6 Binary Values and Computers｜二進位與電腦

Bits, bytes, words — and what n bits can represent · 基礎
① 觀念
💡
Concept

Computers use binary because their basic components have two stable states (for example, a voltage is high or low). A binary digit is called a bit.

  • A byte is 8 bits. A nibble is 4 bits.
  • A word is the group of bits a particular CPU handles as a unit; its size (for example 32 or 64 bits) is the word length.

With $n$ bits we can represent $2^n$ different patterns. Interpreted as an unsigned integer, they range from $0$ to $2^n - 1$. Conversely, to give a distinct pattern to each of $k$ things we need at least $\lceil \log_2 k \rceil$ bits, and to write a number $N > 0$ in binary we need $\lfloor \log_2 N \rfloor + 1$ bits.

白話說

一個位元只能說「是/否」;兩個位元可以說 4 種話(00、01、10、11);每多一個位元,能說的話就加倍。所以 8 位元 = 256 種,32 位元約 43 億種,64 位元約 $1.8 \times 10^{19}$ 種。

反過來問「要表示 k 種東西要幾個位元?」就是問「2 的幾次方才 ≥ k」。表示 26 個英文字母要 5 位元($2^5 = 32 \ge 26$,但 $2^4 = 16$ 不夠)。

後面會用到
  • 計算機組織:暫存器寬度、位址匯流排寬度決定了可定址的記憶體大小(32 位元位址最多 4 GiB)。
  • 資料結構:用幾個位元存狀態(bit set、bitmask)。
  • 本課第 3 章:負數、浮點數、字元、顏色都建立在「n 位元有 $2^n$ 種」上。
現代補充

容量單位有兩套:SI 前綴(KB = 1000、MB = $10^6$、GB = $10^9$)與 IEC 二進位前綴(KiB = 1024、MiB = $2^{20}$、GiB = $2^{30}$)。硬碟廠商用 GB,作業系統常用 GiB,所以「1 TB」的硬碟在電腦上顯示約「931 GiB」——不是被偷了容量。

② 老師講解
例 1

How many different values can a 16-bit unsigned integer hold, and what is its largest value? How many bits are needed to give each of 1000 students a distinct ID?

  1. 16 位元 → $2^{16} = 65{,}536$ 種值。
  2. 無號整數從 0 開始,所以最大值是 $2^{16} - 1 = 65{,}535$。
  3. 1000 個學生:找最小的 $n$ 使 $2^n \ge 1000$。$2^9 = 512$ 不夠,$2^{10} = 1024$ 夠。
  4. 需要 10 位元。等價地,$\lceil \log_2 1000 \rceil = \lceil 9.97 \rceil = 10$。
例 2

A disk is sold as 1 TB. How many GiB does the operating system report?

  1. 1 TB(SI)$= 10^{12}$ 位元組。
  2. 1 GiB $= 2^{30} = 1{,}073{,}741{,}824$ 位元組。
  3. $10^{12} / 2^{30} \approx 931.32$。
  4. 所以作業系統顯示約 931 GiB。兩個數字都對,只是單位不同。
