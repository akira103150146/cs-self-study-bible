計算機概論

18 章,每章四件:觀念講義 → 筆試題庫 → 核心 Lab → 延伸專案。系統主線用 C 從位元蓋到一台會跑程式的電腦,應用主線用 Python 走過資料庫、AI、網路與資安。

18 章 · 每章四件系統主線 C應用主線 PythonDocker 統一環境

這門課給資工系大學部,假設同學已經會寫程式。課本 Dale & Lewis《Computer Science Illuminated》用「洋蔥」比喻電腦系統:從最裡層的資訊表示,一層層往外到硬體、程式、作業系統、應用與網路。本課沿用它的章節順序,但講解與題目全部自編,練習也比課本紮實得多。

每章四件:

  1. 觀念講義:只挑重要、必考的觀念,每個觀念走「觀念 → 老師講解 → 換你練習」三步,並註明後面哪門必修會再用到。
  2. 筆試題庫:計算與追蹤題、觀念選擇題、簡答題。學生版可以直接練習,教師版附詳解。
  3. 核心 Lab:用程式把這章的每個觀念都做一遍,附自動測試。下載起始碼、make test 通過就完成。
  4. 延伸專案:往深處與現代應用延伸,可以累積成期末專題。

兩條主線: 第 1–11、18 章是系統主線,用 C 從位元一路蓋到一台會跑程式的電腦;第 12–17 章是應用主線,用 Python。

環境: 所有 Lab 都在同一個 Docker 映像檔裡編譯、測試(course-cs-intro/env/Dockerfile),避免「在我的電腦可以跑」。

章節彼此獨立,老師可以自行挑選、排序;每章起始碼已附上前幾章需要的參考解。
