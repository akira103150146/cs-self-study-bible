1.計算 4 分對應第 1 章 · C1.3 · 題庫 Q13

Using the course's definition of hardware generations (1: 1951–1958, 2: 1959–1964, 3: 1965–1970, 4: 1971 on; boundary years belong to the new generation), which generation does a machine from 1962 belong to? Answer with a single number.

答案

2

1962 介於 1959 與 1964 之間,屬於第 2 代(電晶體)。

2.計算 5 分對應第 1 章 · C1.4 · 題庫 Q24

A class lists these milestones: A-0 system (1952), COBOL (1959), UNIX (1969), VisiCalc (1979), World Wide Web (1991), Docker (2013). Using the course's software generations, write the generation numbers in the same order, separated by commas without spaces.

答案

1,2,3,4,5,5

依起始年 1951、1959、1965、1971、1990 逐一判斷,邊界年份屬於新世代(COBOL 1959 → 第 2 代)。

3.計算 4 分對應第 2 章 · C2.1 · 題庫 Q3

What is the largest two-digit numeral in base 36, and what is its decimal value? Give only the decimal value.

答案

1295

最大的兩位數是 ZZ:$35 \cdot 36 + 35 = 1295 = 36^2 - 1$。

4.計算 6 分對應第 2 章 · C2.2 · 題庫 Q16

Using Horner's rule on $\text{BEEF}_{16}$, list the intermediate values of $v$ after each digit, separated by commas without spaces.

答案

11,190,3054,48879

$v = 11$;$11 \cdot 16 + 14 = 190$;$190 \cdot 16 + 14 = 3054$;$3054 \cdot 16 + 15 = 48879$。

5.計算 3 分對應第 2 章 · C2.3 · 題庫 Q23

Convert $365_{10}$ to octal.

答案

555

365 → 45 r5 → 5 r5 → 0 r5 → $555_8$。

6.計算 4 分對應第 2 章 · C2.4 · 題庫 Q36

Compute $11000_2 - 101_2$ in binary.

答案

10011

24 − 5 = 19 = $10011_2$;最右邊兩欄需要連續借位。

7.計算 4 分對應第 2 章 · C2.5 · 題庫 Q48

Convert $57_8$ to binary (no leading zeros).

答案

101111

5 = 101、7 = 111 → $101111$。

8.計算 5 分對應第 2 章 · C2.6 · 題庫 Q61

A disk is sold as 2 TB ($2 \times 10^{12}$ bytes). How many GiB will the operating system report? Round to two decimal places.

答案

1862.65

$2 \times 10^{12} / 2^{30} \approx 1862.645$ → 1862.65 GiB。

9.計算 4 分對應第 3 章 · C3.1 · 題庫 Q3

A 0–5 V signal is digitized with 3 bits (8 evenly spaced levels, level 0 = 0 V, level 7 = 5 V), rounding to the nearest level. Which level represents 1.9 V?

答案

3

步長 $5/7 \approx 0.714$ V;$1.9 / 0.714 \approx 2.66$ → 四捨五入第 3 級。

10.計算 4 分對應第 3 章 · C3.2 · 題庫 Q12

What decimal value does the 8-bit two's complement pattern 11100111 represent?

答案

-25

反轉加一:00011000 + 1 = 00011001 = 25 → −25。或 $-128 + 64 + 32 + 4 + 2 + 1 = -25$。

11.計算 3 分對應第 3 章 · C3.3 · 題庫 Q22

In 8-bit two's complement, $120 + 10$ overflows. What value is actually stored (in decimal)?

答案

-126

$130 - 256 = -126$。

12.計算 4 分對應第 3 章 · C3.4 · 題庫 Q39

What is the value of the exponent field (as a decimal number) when $3.75$ is stored in single precision?

答案

128

$3.75 = 11.11_2 = 1.111_2 \times 2^1$ → $E = 1 + 127 = 128$。

13.選擇 3 分對應第 1 章 · C1.1 · 題庫 Q4

Which statement about layers is correct?

  1. A. A layer may use any other layer directly, in any order.
  2. B. Each layer uses the services of the layer below and provides services to the layer above.
  3. C. Layers describe the time order in which a program runs: first hardware, then software.
  4. D. Once a layer is designed, the layers below it can never be changed.
答案 B

分層的核心是「只和相鄰層打交道」:用下層的服務、提供服務給上層。正因為上層只依賴介面,下層才能被替換。

選項代表的迷思回看
A以為分層沒有規則回看 C1.1:跨層依賴會讓系統難以修改
C把分層當成時間順序回看 C1.1:分層是看系統的角度,一個動作同時牽涉很多層
D以為分層讓系統僵化回看 C1.2:分層正是讓下層可以替換的設計
14.選擇 4 分對應第 1 章 · C1.2 · 題庫 Q10

Which is the best example of a leaky abstraction?

  1. A. A function that returns the sum of a list
  2. B. Floating-point numbers that look like real numbers, but 0.1 + 0.2 == 0.3 is false
  3. C. A stack with push and pop
  4. D. A variable named total
答案 B

浮點數想呈現「實數」的抽象,但底層有限位元的二進位表示讓捨入誤差透了出來。第 3 章會詳細解釋。

選項代表的迷思回看
A以為任何函式都會洩漏回看 C1.2:加總函式的行為完全符合它的介面
C以為資料結構一定洩漏回看 C1.2:stack 的介面與行為一致
D把命名和抽象混為一談回看 C1.2:變數名稱不是抽象層

18.選擇 3 分對應第 2 章 · C2.1 · 題庫 Q9

Which statement about bases is true?

  1. A. Base 16 needs 15 distinct digit symbols.
  2. B. In base $b$, the digit symbols range from 1 to $b$.
  3. C. In base $b$, the digit symbols range from 0 to $b - 1$.
  4. D. The base of a number system must be a power of 2.
答案 C

基底 b 恰好有 b 個數字:0、1、…、b−1。

選項代表的迷思回看

19.選擇 3 分對應第 2 章 · C2.2 · 題庫 Q19

Why is Horner's rule preferred for converting a long numeral to an integer?

  1. A. It gives a different, more accurate answer.
  2. B. It needs only one multiplication per digit and can process digits as they are read from left to right.
  3. C. It works only in binary.
  4. D. It avoids the need to check for overflow.
答案 B

Horner 法與展開法結果相同,但只要 n 次乘法,而且不需要事先知道位數。

選項代表的迷思回看
A以為兩種方法結果不同回看 C2.2 的原理:是同一個多項式
C以為只適用二進位回看 C2.2:任何基底都適用
D以為 Horner 法不會溢位回看 C2.2 的原理:仍要先檢查

23.簡答 6 分對應第 1 章 · C1.1 · 題庫 Q5

You click "Send" on a chat app and your friend in another city sees the message. Describe what at least four different layers contribute to this action.

答案

參考:Application(聊天 App 介面與送出按鈕)、Programming(App 的程式邏輯:打包訊息、處理回應)、Operating systems(提供網路 socket、管理記憶體與行程)、Information(文字以 UTF-8 編碼成位元組)、Hardware(CPU 執行、網路卡送出電訊號)、Communications(TCP/IP 把封包送到伺服器與朋友的手機)。

  • 有提到通訊層在跨城市傳送中的角色(1 分)
  • 層與功能對應正確,沒有把 OS 說成硬體等錯誤(1 分)
24.簡答 8 分對應第 1 章 · C1.2 · 題庫 Q12

In Lab task 3, a hidden test runs the same client code on disks with block sizes 16, 64, and 512. Explain what property of your KVStore this checks, and describe a buggy implementation that would pass the public tests but fail this hidden test.

答案

它檢查 KVStore 的介面有沒有洩漏(或依賴)區塊大小:同一段使用者程式在不同的底層「硬體」上都應該正確運作。有 bug 的實作例:把 64 寫死在程式裡(例如每次切 64 位元組),在預設 64 的 disk 上通過公開測試,但 block_size = 16 時 write_block 會因長度不符而丟錯,或 512 時浪費空間、讀回錯的資料。

這題把「抽象讓實作可替換」落到具體測試上,也提醒學生:公開測試通過不代表正確。

評分要點
  • 說出「檢查是否依賴區塊大小/底層細節」(3 分)
  • 描述一個合理的 bug(3 分)
  • 說明該 bug 在哪個大小下會怎麼壞(2 分)
25.簡答 6 分對應第 1 章 · C1.3 · 題庫 Q22

For each hardware generation, name its key technology and explain one practical consequence for users of that era (size, reliability, cost, or accessibility).

答案

參考:第 1 代真空管——機器佔滿房間、耗電大、真空管常燒壞;第 2 代電晶體——更小更可靠,商業公司開始買得起;第 3 代積體電路——更便宜,出現終端機與分時系統,很多人可以同時使用;第 4 代 VLSI 微處理器——個人電腦出現,一般人可以擁有電腦。

重點是把「技術」和「對使用者的影響」連起來。

評分要點
  • 四代的技術都正確(2 分)
  • 每代一個合理的影響(每代 1 分)
