1.計算 5 分對應第 1 章 · C1.3 · 題庫 Q14

Using $N(t) = 2300 \cdot 2^{(t - 1971)/2}$, predict the number of transistors on a chip in 1991.

答案

2355200

  1. 經過 1991 − 1971 = 20 年,加倍 10 次。
  2. $2300 \times 2^{10} = 2300 \times 1024 = 2{,}355{,}200$。

3.計算 4 分對應第 2 章 · C2.1 · 題庫 Q4

The largest three-digit octal numeral is $777_8$. What is its decimal value?

答案

511

$7 \cdot 64 + 7 \cdot 8 + 7 = 511 = 8^3 - 1$。

4.計算 4 分對應第 2 章 · C2.2 · 題庫 Q15

Convert $0.1011_2$ to decimal.

答案

0.6875

$1/2 + 0 + 1/8 + 1/16 = 0.5 + 0.125 + 0.0625 = 0.6875$。

5.計算 5 分對應第 2 章 · C2.3 · 題庫 Q26

Convert $0.8125_{10}$ to binary (it terminates).

答案

0.1101

0.8125 × 2 = 1.625 → 1;0.625 × 2 = 1.25 → 1;0.25 × 2 = 0.5 → 0;0.5 × 2 = 1.0 → 1,剩 0 停止。

6.計算 5 分對應第 2 章 · C2.4 · 題庫 Q40

Compute $17_8 \times 5_8$ in octal.

答案

113

7 × 5 = 35 = 4·8 + 3 → 寫 3 進 4;1 × 5 + 4 = 9 = 8 + 1 → 寫 1 進 1;寫 1。結果 $113_8$(15 × 5 = 75)。

7.計算 4 分對應第 2 章 · C2.5 · 題庫 Q50

Convert $1234_8$ to hexadecimal (lowercase).

答案

29c

$001\,010\,011\,100$ → 4 位一組 $0010\,1001\,1100$ → 2、9、C。

8.計算 4 分對應第 2 章 · C2.6 · 題庫 Q58

How many bits does it take to write $300_{10}$ in binary?

答案

9

$\lfloor \log_2 300 \rfloor + 1 = 8 + 1 = 9$;$300 = 100101100_2$。

9.計算 5 分對應第 3 章 · C3.1 · 題庫 Q4

With 12 bits, a 0–5 V range is split into $2^{12}$ evenly spaced levels (level 0 = 0 V, top level = 5 V). What is the step between adjacent levels, in millivolts, rounded to two decimal places?

答案

1.22

$2^{12} = 4096$ 級,相鄰級差 $5 / 4095 \approx 0.0012210$ V ≈ 1.22 mV。

10.計算 5 分對應第 3 章 · C3.2 · 題庫 Q16

In 8-bit two's complement, compute $-50 + 20$ by adding the bit patterns. Give the resulting 8-bit pattern.

答案

11100010

$-50$ = 11001110,$20$ = 00010100,相加 11100010 = −30。

11.計算 4 分對應第 3 章 · C3.3 · 題庫 Q24

In 8-bit two's complement, $-120 + (-10)$ overflows. What value is stored?

答案

126

$-130 + 256 = 126$。兩負得正。

Which of the following is data rather than hardware or software?

  1. A. The Linux kernel
  2. B. A solid-state drive
  3. C. A CSV file of exam scores
  4. D. The Python interpreter
答案 C

成績檔是被程式讀寫、處理的資訊,屬於資料。Linux 核心與 Python 直譯器是軟體,SSD 是硬體。

選項代表的迷思回看

D以為直譯器只是「一個檔案」所以是資料回看 C1.1:它被執行時扮演軟體的角色
13.選擇 3 分對應第 1 章 · C1.2 · 題庫 Q9

Program P uses a library only through its documented functions. The library's authors completely rewrite the internals but keep the same functions and behavior. What happens to P?

  1. A. P must be rewritten because the internals changed.
  2. B. P keeps working without changes (though its speed may differ).
  3. C. P stops compiling because function names changed.
  4. D. P works only if it was written in the same language as the library.
答案 B

P 只依賴介面;介面與行為不變,實作可以自由替換。效能可能不同,這是抽象唯一可能「透出來」的地方。

選項代表的迷思回看
A以為使用者依賴實作回看 C1.2:只透過介面使用就不受實作影響
C沒注意到題目說介面不變回看 C1.2:名稱與參數屬於介面
D把抽象和語言綁在一起回看 C1.2:介面可以跨語言,關鍵是約定不變

18.選擇 4 分對應第 2 章 · C2.2 · 題庫 Q20

A 64-bit parser computes v = v * base + d and then checks whether v got smaller. Why is this check unreliable?

  1. A. Unsigned overflow in C wraps around, so after v * base wraps the result can still look larger than before.
  2. B. The check is too slow.
  3. C. Overflow cannot happen with unsigned integers.
  4. D. The check works only in base 10.
答案 A

乘法溢位繞回後的值不一定比原本小(例如乘以 16 繞回後仍可能變大)。正確做法是事先檢查 $v > (\text{MAX} - d)/\text{base}$。

選項代表的迷思回看
B把正確性問題當成效能問題回看 C2.2 的原理
C以為無號整數不會溢位回看 C2.2:它會繞回(模 $2^{64}$)
D以為基底會影響檢查的正確性回看 C2.2:問題在於繞回
19.選擇 4 分對應第 2 章 · C2.3 · 題庫 Q31

In Python, 0.1 + 0.2 == 0.3 is False. What is the root cause?

  1. A. Python has a bug in its addition.
  2. B. 0.1, 0.2 and 0.3 are infinite repeating fractions in binary, so each is stored as a nearby approximation.
  3. C. Python stores floats in decimal.
  4. D. The comparison operator rounds the numbers.
答案 B

這三個數的分母都含 5,在二進位是無限循環小數,只能存近似值;近似值相加與另一個近似值不一定相等。

選項代表的迷思回看
A以為是語言的 bug回看 C2.3:所有用二進位浮點數的語言都一樣
C以為浮點數以十進位儲存回看 C2.3(第 3 章 C3.4 詳談)
D以為比較會捨入回看 C2.3:== 比較的是精確的位元

簡答題

23.簡答 6 分對應第 1 章 · C1.1 · 題庫 Q6

A compiled program is stored on disk as bytes. Explain why the same bytes can be called software in one situation and data in another. Give one real tool for each situation.

答案

「軟體」或「資料」是角色,不是固有屬性。被 CPU 載入執行時,它是軟體(例:在 shell 執行 ./sum);被另一個程式讀進來分析或轉換時,它是資料(例:objdump -d sum 反組譯它、防毒軟體掃描它)。

這題考的是分層觀點的彈性:同一串位元組,在不同層、不同情境扮演不同角色。

評分要點
  • 說明「角色」的概念(2 分)
  • 當作軟體的例子正確(2 分)
  • 當作資料的例子正確(2 分)
24.簡答 6 分對應第 1 章 · C1.2 · 題庫 Q11

Choose one abstraction you use every day as a programmer (for example a file, a function, or a list). State its interface and two implementation details it hides.

答案

參考:檔案。介面:open、read、write、close,把檔案看成一串可讀寫的位元組。隱藏的細節:資料存在磁碟的哪些區塊、區塊是否連續、是否已被快取在記憶體、檔案系統種類。

  • 兩個被隱藏的細節正確(各 2 分)
25.簡答 6 分對應第 1 章 · C1.3 · 題庫 Q21

Explain why exponential growth makes long-term predictions with Moore's law fragile. Use numbers: compare the growth over 40 years with a doubling period of 2 years versus 2.5 years.

答案

40 年、週期 2 年:$2^{20} \approx 1{,}048{,}576$ 倍;週期 2.5 年:$2^{16} = 65{,}536$ 倍。週期只差 0.5 年,結果差了 16 倍。指數模型對參數極度敏感,所以長期外推很不可靠。

這題練習把「指數成長」的直覺量化。

評分要點
  • 兩個數字都算對(各 2 分)
  • 說明「對參數敏感、所以不可靠」(2 分)
