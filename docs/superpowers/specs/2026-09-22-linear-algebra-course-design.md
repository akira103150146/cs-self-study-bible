### 1.2 這本書的寫法（影響教法）

- 把 $A\mathbf{x}$ 看成 $A$ 各行的線性組合，定義與證明都從 column 出發。
- 線性變換貫穿全書，第 1 章就用它給矩陣乘法一個幾何圖像。
- 核心觀念先在 $\mathbb{R}^n$ 具體出現，之後再推廣。
- 可逆矩陣定理隨章節長大：2.3 → 2.9 → 3.2 → 5.2 → 7.4。
- 固定配件：Practice Problems、300+ 題是非題、寫作題、標 **T** 的電腦題、26 處 Numerical Notes、1–5 章的 Reasonable Answers。

### 5.1 Capstone（W17）：用 NumPy 做 PCA

用 `np.linalg.svd`（或對共變異數矩陣用 `eigh`）對 `sklearn` 內建的 `load_digits`（不用下載）做 PCA：

1. 降到 2D 畫散佈圖，看不同數字是否分群
2. 把前幾個主成分畫回 8×8 影像，**解讀**每個主成分在看什麼
3. 用 explained variance 決定 k，做 rank-k 重建並比較不同 k 的效果

重點放在**解讀結果**，不是實作演算法。串起 W15（共變異數）與 W16（SVD）。

**保底版**：只做第 1、3 步。

## 7. 實作課（Python）

**已確認**：每週一個 Lab；同週理論課之後才上；**實作課開頭先做診斷考**（見 6.4）；用 NumPy / SymPy / SciPy / Matplotlib，資料表情境用 pandas 讀入；Lab 必須用到當週理論的核心結果（沿用骨架的咬合規則）。

### 7.1 原則：不手刻，但要動腦

**學生不手刻演算法。** 實務上都用 NumPy（底層是 LAPACK），比手寫快、數值上也更穩；數理弱的學生手刻時，力氣多半花在除錯索引，不在觀念。

但直覺不會因為呼叫函式就長出來，所以每個 Lab 都要有**逼學生動腦的步驟**，尤其要讓學生讀懂這些常見陷阱：

- 奇異或病態矩陣時 `solve` 報錯，或給出不可信的答案
- 該是 0 的地方印出 `1.2e-16`
- `eig` 回傳複數；特徵向量的正負號與課本相反
- `svd` 回傳 Vᵀ 而不是 V

**例外**：少數「看到機制」本身就是重點的地方（小 pivot 的浮點誤差、餘因子展開的 $n!$），由**老師提供短的示範函式**，學生只讀、只呼叫，不自己寫。

### 7.2 每個 Lab 四步

1. **先預測**：執行前先寫下預期結果（例如「這個矩陣有幾個 pivot？」），用理論課練過的同一題
2. **用函式庫算**：NumPy / SymPy 跑一次，和預測對照
3. **解讀**：讀懂輸出，包括上面的陷阱（呼應書上的 Reasonable Answers）
4. **應用**：用在一個資工情境（圖學、訊號、資料表……）

Lab 的 TODO 以「預測」與「解讀」為主（填空、選擇、一句話說明），不是寫演算法。實作判準沿用骨架：跑得出來、TODO 完成、附一段中文說明。
