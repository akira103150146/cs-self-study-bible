Lab 1｜梯度下降 gradient descent

電腦不解 $f'(x)=0$,而是沿下坡走:$x \leftarrow x - \text{lr}\cdot f'(x)$。gradient_descent(df, x0, lr, steps) 回傳整條軌跡。先在碗形 $f(x)=x^2$ 上看它滾到谷底:

def gradient_descent(df, x0, lr, steps):
    """沿 -df 方向走下山,回傳每一步的 x(軌跡)。df 是導函數 f'。"""
    xs = [float(x0)]
    x = float(x0)
    for _ in range(steps):
        x = x - lr * df(x)      # 往下坡走一步
        xs.append(x)
    return xs

# 碗形 f(x)=x^2, f'(x)=2x
f  = lambda x: x**2
df = lambda x: 2*x
path = gradient_descent(df, x0=5.0, lr=0.1, steps=30)
print("從 x0=5 出發,最後停在 x =", round(path[-1], 6))

xx = np.linspace(-5.5, 5.5, 400)
plt.plot(xx, f(xx), label='f(x) = x^2')
px = np.array(path)
plt.plot(px, f(px), 'o-', color='C3', ms=4, label='descent path')
plt.title('Gradient descent on a convex bowl -> global min')
plt.legend(); plt.show()
預期輸出從 x0=5 出發,最後停在 x = 0.00619 <- 逐步逼近 x=0

會看到:紅點從 $x=5$ 沿拋物線一路滑到底部 $x=0$。

換一個多谷函數 $f(x)=3x^4-16x^3+18x^2$——淺谷($x=0$)與深谷($x=3$)。起點不同,會掉進不同的谷:

g  = lambda x: 3*x**4 - 16*x**3 + 18*x**2
dg = lambda x: 12*x**3 - 48*x**2 + 36*x      # g'(x)

pathA = gradient_descent(dg, x0=0.5, lr=0.01, steps=40)   # 起點靠近淺谷
pathB = gradient_descent(dg, x0=2.0, lr=0.01, steps=40)   # 起點靠近深谷
print("從 x0=0.5 ->", round(pathA[-1], 4), " (局部最小)")
print("從 x0=2.0 ->", round(pathB[-1], 4), " (全域最小)")

xx = np.linspace(-0.7, 4.2, 500)
plt.plot(xx, g(xx), 'k', label='f(x)=3x^4-16x^3+18x^2')
for p, c, lab in [(pathA, 'C0', 'start 0.5 -> local min'),
                  (pathB, 'C3', 'start 2.0 -> global min')]:
    p = np.array(p); plt.plot(p, g(p), 'o-', color=c, ms=3, label=lab)
plt.title('Same rule, different start -> may get stuck in a local minimum')
plt.legend(fontsize=8); plt.ylim(-30, 40); plt.show()
預期輸出從 x0=0.5 -> 0.0 (局部最小,f=0) 從 x0=2.0 -> 3.0 (全域最小,f=-27)

會看到:藍色軌跡從 $0.5$ 掉進淺谷(局部最小),紅色從 $2.0$ 掉進深谷(全域最小)。這正是梯度下降的罩門:只看腳邊下坡,可能卡在局部最小。

Lab 2｜用梯度下降做線性回歸

給雜訊資料,找直線 $y=wx+b$ 讓均方誤差 MSE $=\frac1N\sum(wx_i+b-y_i)^2$ 最小。對 $w,b$ 求偏導,套同一套梯度下降把 loss 壓低——這就是機器學習訓練的雛形。

# 造一組雜訊資料:真線是 y = 2x + 1
rng = np.random.default_rng(0)
N = 60
xdat = np.linspace(0, 5, N)
ydat = 2.0*xdat + 1.0 + rng.normal(0, 1.2, N)

def mse(w, b):
    return np.mean((w*xdat + b - ydat)**2)

# 對 MSE 梯度下降:d/dw = 2*mean(err*x), d/db = 2*mean(err)
w, b, lr = 0.0, 0.0, 0.02
loss_hist = []
for _ in range(400):
    err = (w*xdat + b) - ydat
    w -= lr * 2*np.mean(err*xdat)
    b -= lr * 2*np.mean(err)
    loss_hist.append(mse(w, b))

print("w =", round(w,3), " b =", round(b,3), " MSE =", round(loss_hist[-1],3))

fig, ax = plt.subplots(1, 2, figsize=(11, 4))
ax[0].plot(loss_hist); ax[0].set_title('MSE loss vs iteration')
ax[1].scatter(xdat, ydat, s=14, label='noisy data')
ax[1].plot(xdat, w*xdat + b, 'C3', label='GD fit')
ax[1].set_title('Line fitted by gradient descent'); ax[1].legend()
plt.tight_layout(); plt.show()
預期輸出w = 2.132 b = 0.762 MSE = 1.123 (真值 w=2, b=1)

會看到:左圖 MSE 快速下降後趨平;右圖擬合直線穿過雜訊點雲,斜率截距逼近真值 $(2,1)$。

Lab 3｜SymPy 自動曲線描繪

理論課的描繪流程(求 $f'$、$f''$、解臨界點與反曲點)可完全自動化。auto_sketch 用 SymPy 算導數、解方程,再把臨界點(●)與反曲點(■)標到圖上:

x = sp.symbols('x')

def auto_sketch(expr, xmin=-1.5, xmax=3.5):
    f1 = sp.diff(expr, x)
    f2 = sp.diff(expr, x, 2)
    crit = [c for c in sp.solve(f1, x) if c.is_real]
    # inflection: f''=0 and f''' != 0(確保 f'' 真的變號)
    infl = [c for c in sp.solve(f2, x) if c.is_real and sp.diff(expr, x, 3).subs(x, c) != 0]
    print("f'  =", sp.factor(f1), "  critical:", crit)
    print("f'' =", sp.factor(f2), "  inflection:", infl)
    fpy = sp.lambdify(x, expr, "numpy")
    xs = np.linspace(xmin, xmax, 500)
    plt.plot(xs, fpy(xs), 'k', label='f(x)')
    for c in crit:
        plt.plot(float(c), float(expr.subs(x, c)), 'o', color='C3', ms=9)
    for c in infl:
        plt.plot(float(c), float(expr.subs(x, c)), 's', color='C0', ms=9)
    plt.title('Automatic curve sketching (SymPy)'); plt.legend(); plt.show()
    return crit, infl

auto_sketch(x**3 - 3*x**2 + 2, -1.5, 3.5)
預期輸出f' = 3*x*(x - 2) critical: [0, 2] f'' = 6*(x - 1) inflection: [1]

會看到:三次曲線上,紅圓點標出局部極大 $(0,2)$、極小 $(2,-2)$,藍方點標出反曲點 $(1,0)$。
