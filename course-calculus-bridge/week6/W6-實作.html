一條骨架貫穿三個模型

forward(把輸入代進一連串函數 = 合成)→ loss(一個要最小化的純量)→ backward(用鏈鎖法則逐層求偏導 = backprop)→ update(沿負梯度下降一步)。這整條 pipeline,就是微積分。

環境設定

先跑這格,把套件載進來,並定義數值穩定的 sigmoid。

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['figure.figsize'] = (6.5, 4)
plt.rcParams['axes.grid'] = True

def sigmoid(z):
    # 數值穩定的 sigmoid:把 z 夾住避免 exp 溢位
    return 1.0 / (1.0 + np.exp(-np.clip(z, -500, 500)))

Part 1｜Linear Regression by Gradient Descent

給一堆帶雜訊的點,找一條直線 $\hat y=wx+b$ 擬合。骨架第一次登場:forward 是 $wx+b$、loss 是均方誤差 MSE、backward 是對 $w,b$ 偏微分、update 是沿負梯度走。先自生玩具資料(真直線 $y=2x-1$ 加雜訊):

# 自生 toy dataset:真直線 y = 2x - 1 + 雜訊
rng = np.random.default_rng(0)
N = 100
X = np.linspace(-3, 3, N)
true_w, true_b = 2.0, -1.0
y = true_w * X + true_b + rng.normal(0, 0.8, N)

接著手刻梯度下降迴圈,從 $w=b=0$ 開始一步步下坡:

# 手刻梯度下降:forward -> loss -> backward -> update
w, b = 0.0, 0.0          # 從零開始
lr = 0.03                # learning rate (步長)
losses = []
for step in range(600):
    y_hat = w * X + b                 # forward:線性函數
    err = y_hat - y
    loss = np.mean(err**2)            # loss:MSE
    losses.append(loss)
    dw = 2 * np.mean(err * X)         # backward:偏導(冪次 + 鏈鎖法則)
    db = 2 * np.mean(err)
    w -= lr * dw                      # update:沿負梯度走一步
    b -= lr * db

print(f"learned:  w = {w:.4f}  (true 2.0),   b = {b:.4f}  (true -1.0)")
print(f"final MSE loss = {losses[-1]:.4f}")
預期輸出learned: w = 2.0194 (true 2.0), b = -0.9351 (true -1.0) final MSE loss = 0.5913

學到的 $w\approx2$、$b\approx-1$,和真參數幾乎一樣;最終 MSE 大約就是雜訊的變異數。把擬合線與 loss 曲線畫出來,會看到 loss 單調下滑、直線穿過資料中心。

Part 2｜Logistic Regression(2D 二元分類)

資料變成兩類($0$/$1$)。把線性輸出 $z=w\cdot x+b$ 經過 sigmoid 壓成機率,用 cross-entropy 當 loss。神奇的是鏈鎖法則化簡後,梯度就是乾淨的 $p-y$。先自生兩坨高斯點:

# 自生 toy dataset:兩坨高斯點(線性可分)
rng = np.random.default_rng(1)
n = 150
X0 = rng.normal(0, 0.8, (n, 2)) + np.array([-1.6, -1.6])   # class 0
X1 = rng.normal(0, 0.8, (n, 2)) + np.array([ 1.6,  1.6])   # class 1
Xl = np.vstack([X0, X1])
yl = np.concatenate([np.zeros(n), np.ones(n)])

手刻訓練:sigmoid + cross-entropy + 梯度下降:

# 手刻邏輯回歸:sigmoid + cross-entropy + 梯度下降
w = np.zeros(2); b = 0.0
lr = 0.1
ce = []
for step in range(3000):
    z = Xl @ w + b                   # forward:線性
    p = sigmoid(z)                   # forward:sigmoid -> 機率
    loss = -np.mean(yl*np.log(p+1e-9) + (1-yl)*np.log(1-p+1e-9))   # cross-entropy
    ce.append(loss)
    grad_w = Xl.T @ (p - yl) / len(yl)   # backward:鏈鎖化簡後 dL/dz = p - y
    grad_b = np.mean(p - yl)
    w -= lr * grad_w; b -= lr * grad_b   # update:gradient descent

pred = (sigmoid(Xl @ w + b) > 0.5).astype(float)
acc = np.mean(pred == yl)
print(f"final cross-entropy = {ce[-1]:.4f},   accuracy = {acc:.4f}")
預期輸出final cross-entropy = 0.0063, accuracy = 0.9967

準確率約 $99.7\%$。把 decision boundary(sigmoid $=0.5$ 的等高線)畫出來:

# 畫出 decision boundary(sigmoid = 0.5 的那條線)
xx, yy = np.meshgrid(np.linspace(-4, 4, 300), np.linspace(-4, 4, 300))
grid = np.c_[xx.ravel(), yy.ravel()]
zz = sigmoid(grid @ w + b).reshape(xx.shape)
plt.contourf(xx, yy, zz, levels=20, cmap='bwr', alpha=0.6)
plt.contour(xx, yy, zz, levels=[0.5], colors='k', linewidths=2)
plt.scatter(Xl[:, 0], Xl[:, 1], c=yl, cmap='bwr', edgecolors='k', s=14)
plt.title('Part 2: logistic-regression decision boundary')
plt.xlabel('x1'); plt.ylabel('x2'); plt.show()

會看到:一條直線把兩坨點乾淨切開——但注意,它只會畫直線。

Part 3｜2 層神經網路 + Backpropagation

同心圓資料(內圈一類、外圈一類)沒有任何直線切得開。解法:中間加一個隱藏層(input 2 → hidden $H$ 個 tanh → output 1 個 sigmoid),讓模型能彎折。forward 是一連串函數合成;要更新參數就一層層往回套鏈鎖法則,這正是 backpropagation。先自生同心圓:

# 自生 toy dataset:同心圓(非線性可分)——內圈 label 0、外圈 label 1
rng = np.random.default_rng(2)
m = 400
angle = rng.uniform(0, 2*np.pi, m)
radius = np.concatenate([rng.uniform(0.0, 1.0, m//2),      # 內圈
                         rng.uniform(1.8, 2.8, m//2)])     # 外圈
Xn = np.stack([radius*np.cos(angle), radius*np.sin(angle)], axis=1)
Xn += rng.normal(0, 0.06, Xn.shape)
yn = np.concatenate([np.zeros(m//2), np.ones(m//2)]).reshape(-1, 1)

初始化參數(小隨機權重打破對稱):

# 初始化參數(小隨機權重打破對稱)
H = 16                                  # 隱藏層神經元數
rng = np.random.default_rng(2)
W1 = rng.normal(0, 1, (2, H)) * 0.8; b1 = np.zeros(H)
W2 = rng.normal(0, 1, (H, 1)) * 0.8; b2 = np.zeros(1)

手刻訓練迴圈——forward 合成、backward 鏈鎖、update 梯度下降,一格看完整條 pipeline:

# 手刻訓練迴圈:forward(合成)-> loss -> backward(鏈鎖/backprop)-> update(GD)
lr = 0.2
nn_loss = []
for epoch in range(4000):
    # ---- forward:一連串函數合成 ----
    Z1 = Xn @ W1 + b1
    A1 = np.tanh(Z1)                    # 隱藏層 activation
    Z2 = A1 @ W2 + b2
    P  = sigmoid(Z2)                    # 輸出機率
    loss = -np.mean(yn*np.log(P+1e-9) + (1-yn)*np.log(1-P+1e-9))
    nn_loss.append(loss)
    # ---- backward:鏈鎖法則一層層往回(backpropagation)----
    dZ2 = (P - yn) / len(yn)            # dL/dZ2
    dW2 = A1.T @ dZ2
    db2 = dZ2.sum(0)
    dA1 = dZ2 @ W2.T
    dZ1 = dA1 * (1 - A1**2)            # 乘上 tanh 的導數 1 - tanh^2
    dW1 = Xn.T @ dZ1
    db1 = dZ1.sum(0)
    # ---- update:gradient descent ----
    W1 -= lr*dW1; b1 -= lr*db1; W2 -= lr*dW2; b2 -= lr*db2

def nn_forward(A):
    return sigmoid(np.tanh(A @ W1 + b1) @ W2 + b2)

acc = np.mean((nn_forward(Xn) > 0.5).astype(float) == yn)
print(f"final cross-entropy = {nn_loss[-1]:.4f},   accuracy = {acc:.4f}")
預期輸出final cross-entropy = 0.0053, accuracy = 1.0000

會看到:準確率衝到 $100\%$;畫出來的 decision boundary 是一條彎曲的封閉曲線,恰好把內圈圈起來——這是單靠邏輯回歸永遠做不到的。那個 dZ1 = dA1 * (1 - A1**2),就是 tanh 的導數,也就是鏈鎖法則被寫成一行程式。

收尾 · 你剛手刻了深度學習引擎的核心

停下來看看你做了什麼。三個模型、從線性到非線性,骨架完全一樣:

步驟微積分是什麼三個模型共通
forward函數合成把輸入一層層代進函數
loss一個要最小化的純量函數MSE / cross-entropy
backward鏈鎖法則從 loss 往回逐層求偏導 = backprop
update沿負梯度下降$\theta\leftarrow\theta-\eta\nabla_\theta L$
🎉
你剛手刻了深度學習引擎的核心

那個 2 層網路的反向傳播,骨子裡就是第 2 週學的鏈鎖法則——只是被排成矩陣、大規模自動化了。把 $H$ 加大、層數疊深,換個名字它就叫 deep learning。PyTorch / TensorFlow 幫你自動算的 .backward(),跟你手寫的 dZ1 = dA1 * (1 - A1**2) 是同一件事。微積分不是考完就丟的東西,它就是讓機器「學習」的那台引擎。整個暑期的極限、導數、鏈鎖法則、最佳化,在這一頁全部合體了。
