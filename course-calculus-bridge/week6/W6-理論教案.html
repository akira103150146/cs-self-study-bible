第 6 週 · 監考教案

期中模擬考 + Capstone

最後一週不教新東西,而是把前五週「驗收」+「合體」。上半場是一份綜合 W1–W5 的英文模擬期中考(監考 + 逐題檢討);下半場是 Capstone——用自己手刻的梯度下降與鏈鎖法則,把一個模型從線性回歸養到 2 層神經網路。這份教案給你監考流程、配分規劃、失分點總表與 demo 節奏。

上半場 · 模擬考 3 小時 下半場 · Capstone 3 小時 綜合 W1–W5 期中總驗收

這週和前五週哪裡不一樣

前五週是「教案 + 例題 + 實作」;第六週改成「模擬考卷 + Capstone」。視覺與操作沿用第 1 週,但你手上的教具換了:一份要監考、要批改、要檢討的考卷(分考卷版與詳解版),外加一份會「學習」的 Capstone notebook。這份監考教案的任務,是讓你把這兩件事跑得順。

🎯
一句話定調

模擬考不是要考倒學生,是要在真正的期中之前,把每個人卡住的地方逼出來——考完的檢討,比考卷本身更值錢。

給分原則:看步驟,不只看答案

台灣大一期中幾乎都是部分給分。方法對、只是最後代錯一個數字,給大部分分數;方法錯則整段扣。只寫最終答案、沒有過程,即使對也只給一半。這個原則要在發卷時就跟學生講清楚——他們會因此願意把過程寫出來。

監考時的三個提醒

⚠️
最容易在考場出事的地方
  • Problem 3(b) 允許小數:線性近似、估計題可以給小數;其他題盡量給精確值($\frac54$、$\frac{2\sqrt2-1}{3}$ 這種)。發卷時提醒。
  • Problem 4(b)(iv) 要畫圖:準備白紙或方格紙;提醒他們圖要標出極值點、反曲點、與座標軸交點。
  • 時間分配:提醒學生 Problem 4、5 最花時間,別卡在 Problem 1 的小計算上。剩 20 分鐘報時,讓還沒寫最佳化的人趕快跳過去。

下半場:考後檢討重點

時間有限,別逐題平均用力。Problem 1、2 快帶(多半是熟練度問題,對答案即可);把 45 分鐘的檢討火力壓在最會失分、觀念最容易錯的後四題:

  • Problem 3 · L'Hôpital 的前提:一定要示範「先確認是 $\frac00$ 或 $\frac{\infty}{\infty}$ 才可以用」。很多人看到極限就狂微分。順帶講相關變率「先對 $t$ 微分、最後才代數值」。
  • Problem 4 · 一階/二階判別的符號表:帶學生畫 $f'$、$f''$ 的正負號表,強調「增減看 $f'$、凹凸看 $f''$、極值要有符號變化」。曲線描繪是把這些資訊拼成一張圖。
  • Problem 5 · 最佳化的完整格式:設變數 → 寫限制式 → 目標函數 → 求導找臨界點 → 驗二階 → 回答原問題。最常見失分:只解出 $w=100$ 卻沒回答「最大面積 $20000\ \text{m}^2$」。
  • Problem 6 · FTC 與換元的細節:不定積分的 $+C$、定積分換元要換上下限、以及 FTC 第一部分「上限是 $x^2$ 時要乘鏈鎖 $2x$」。這三個是送分也是送命的地方。
🔑
檢討的黃金句型

每題檢討完,問一句:「這題是哪一週的東西?當時卡在哪?」把失分點對回週次,學生才知道回去補哪一塊,而不是籠統地覺得「微積分好難」。

W1–W5 常見失分點總表

這張表整理五週下來、學生最常翻車的地方。檢討時直接對照:看到某題全班都錯,翻到對應那一列,通常就是這些老毛病。

週次主題最常見的失分點
第 1 週Limits & Continuity $x\to-\infty$ 時 $\sqrt{x^2}=|x|=-x$ 忘補負號 · 代入 $\frac00$ 就直接說「不存在」· 預設「極限值 = 函數值」· 分段函數端點歸哪一段搞錯 · 用 IVT 忘了先寫「$f$ 連續」、或以為 IVT 能給出根的值
第 2 週Derivatives & Rules 用定義時漏寫 $\lim_{h\to0}$ · 商法則分子順序寫反(應是 $u'v-uv'$)· 鏈鎖法則漏乘內層導數 · 隱函數微分忘記 $y$ 是 $x$ 的函數(對 $y^3$ 微分漏了 $y'$)· $x^{\sin x}$ 當成冪函數硬套 $nx^{n-1}$
第 3 週Related Rates / Linear Approx / L'Hôpital L'Hôpital 用在非不定型上(只有 $\frac00$、$\frac{\infty}{\infty}$ 可用)· 沒先確認型態就微分 · 線性近似基準點 $a$ 選得不好算 · 相關變率把變數當常數、或太早代入數值導致微分錯
第 4 週Extrema / MVT / Curve Sketching / Optimization 一階判別沒檢查符號變化就下極值結論 · 忘記檢查端點 · 凹凸與反曲點看錯 $f''$ 符號 · MVT 沒驗「連續 + 可微」前提 · 最佳化沒寫定義域、沒驗二階、沒回答原本問的量
第 5 週Integration & FTC 不定積分忘記 $+C$ · 定積分換元忘記換上下限 · $u$-substitution 的 $du$ 係數漏掉 · FTC 第一部分上限是函數時忘乘鏈鎖 · 積分與微分符號搞混

Capstone demo 進行方式(下半場 3 小時)

考完試,學生正需要一個「原來這些都有用」的收尾。Capstone 就是那個收尾:純 numpy、從零手刻三個會學習的模型,親眼看見前五週的東西合體成深度學習的引擎。這一節用帶跑 demo 的方式進行,不是丟 notebook 讓他們自己讀。

💻
開場前先確認

投影 Capstone 頁,讓每個學生把 W6-lab.ipynb 上傳到 Colab、先跑「環境設定」那格確定 numpy 正常。程式全用純 numpy、不裝任何 ML 套件——這正是重點:引擎的核心就是微積分,我們親手刻。

時間段落要點出的微積分
00:00–00:15導入:回顧全學期骨架forward = 合成 · loss · backward = 鏈鎖 · update = 梯度下降
00:15–00:45Part 1 · Linear Regression梯度下降擬合直線,畫 loss 曲線下滑
00:45–01:30Part 2 · Logistic Regressionsigmoid + cross-entropy,梯度化簡成 $p-y$,畫 decision boundary
01:30–01:45休息—
01:45–02:45Part 3 · 2-layer NN + Backprop同心圓非線性可分;backprop = 鏈鎖法則自動化
02:45–03:00收尾:「你剛手刻了深度學習引擎」把 backprop 對回第 2 週的鏈鎖法則

三個 Part 各要敲的釘子

  1. Part 1（Linear Regression）:讓學生盯著 loss 曲線單調下滑,並確認學到的 $w\approx2$、$b\approx-1$ 就是造資料的真參數。這裡第一次完整走 forward → loss → backward → update 四步。
  2. Part 2（Logistic Regression）:重點是 sigmoid 把線性輸出壓成機率、cross-entropy 當 loss,而鏈鎖法則化簡後梯度竟然乾淨成 $p-y$。畫出 decision boundary,強調「它只會畫直線」——替 Part 3 鋪梗。
  3. Part 3（2-layer NN）:先給同心圓資料,讓學生體會「沒有直線切得開」。加一個隱藏層後,那行 dZ1 = dA1 * (1 - A1**2) 就是 tanh 的導數、就是鏈鎖法則寫成程式。訓練完 boundary 變成彎曲的封閉曲線,準確率衝到 $100\%$。
🎉
收尾金句(務必講)

「你剛剛手刻了深度學習引擎的核心。那個 2 層網路的反向傳播,骨子裡就是第 2 週學的鏈鎖法則——只是被排成矩陣、大規模自動化了。PyTorch 的 .backward(),跟你手寫的那一行是同一件事。微積分不是考完就丟的東西,它就是讓機器學習的那台引擎。」

下課前的一句話

把兩件事收在一起:模擬考讓你知道哪裡還要補,Capstone 讓你看見這些補起來之後能拿去做什麼。真正的期中就照這份卷的節奏走;而那台你親手刻出來的學習引擎,會一路陪你到大二的機器學習課。
