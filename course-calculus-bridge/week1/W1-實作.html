Lab 1｜數值探極限

sin(x)/x 在 x=0 是 0/0(沒定義),但把 x 從兩邊逼近 0,值會朝 1 收斂。先看招牌例子:

# lim(x->0) sin(x)/x = ?
print("  x         sin(x)/x")
for x in [1, 0.5, 0.1, 0.01, 0.001, 0.0001]:
    print(f"{x:<9} {math.sin(x)/x:.8f}")
預期輸出 x sin(x)/x 1 0.84147098 0.5 0.95885108 0.1 0.99833417 0.01 0.99998333 0.001 0.99999983 0.0001 1.00000000 <- 越來越靠近 1

再包成通用工具,探索別的極限:

def numeric_limit(f, a, side="both", n=6):
    """從 a 的左/右用越來越近的點觀察 f 的走向。"""
    hs = [10**-k for k in range(1, n + 1)]
    if side in ("right", "both"):
        print(f"從右邊逼近 x={a}:")
        for h in hs:
            print(f"  x={a+h:<12.6g}  f(x)={f(a+h):.8f}")
    if side in ("left", "both"):
        print(f"從左邊逼近 x={a}:")
        for h in hs:
            print(f"  x={a-h:<12.6g}  f(x)={f(a-h):.8f}")

# 示範:lim(x->3) (x^2-9)/(x-3) 應該是 6
numeric_limit(lambda x: (x**2 - 9)/(x - 3), 3)

Lab 2｜夾擠定理視覺化

-x^2 ≤ x^2 sin(1/x) ≤ x^2,兩側都 → 0,中間被夾著也 → 0。畫出來一眼就懂為什麼「夾得住」。

# 夾擠:-x^2 <= x^2 sin(1/x) <= x^2
x = np.linspace(-0.5, 0.5, 3000); x = x[x != 0]
plt.plot(x,  x**2, '--', label='y = x^2 (upper)')
plt.plot(x, -x**2, '--', label='y = -x^2 (lower)')
plt.plot(x, x**2*np.sin(1/x), lw=1, label='y = x^2 sin(1/x)')
plt.title('Squeeze: x^2 sin(1/x) -> 0 as x -> 0')
plt.legend(); plt.show()

會看到:兩條虛線拋物線像喇叭口收束到原點,中間那條劇烈震盪的曲線被牢牢夾在裡面,一起被逼向 0。

Lab 3｜單邊極限與不連續

|x|/x:右邊恆為 +1、左邊恆為 -1。左右極限不相等 → 雙邊極限不存在(跳躍不連續)。

# 單邊極限與跳躍不連續:f(x) = |x|/x
f = lambda x: np.abs(x)/x
xl = np.linspace(-2, -1e-3, 500); xr = np.linspace(1e-3, 2, 500)
plt.plot(xl, f(xl), label='x<0 -> -1')
plt.plot(xr, f(xr), label='x>0 -> +1')
plt.title('Jump discontinuity: left=-1, right=+1 -> limit DNE')
plt.legend(); plt.ylim(-2, 2); plt.show()

print("左極限 ~", f(-1e-9), "  右極限 ~", f(1e-9))
預期輸出左極限 ~ -1.0 右極限 ~ 1.0

Lab 4｜二分逼近 × 中間值定理

例題只證「(1,2) 內有根」;這裡用二分法把那個根真的算出來。IVT 保證存在,二分法負責逼近——數學與程式接力。

# 二分逼近 x 中間值定理(IVT)
# f 連續、f(a)、f(b) 異號 => (a,b) 內有根(IVT 保證存在)
def bisect(f, a, b, tol=1e-10):
    assert f(a)*f(b) < 0, "f(a)、f(b) 必須異號(這正是 IVT 的前提)"
    while b - a > tol:
        m = (a + b)/2
        if f(a)*f(m) <= 0:
            b = m
        else:
            a = m
    return (a + b)/2

f = lambda x: x**3 - x - 1
print("f(1) =", f(1), " f(2) =", f(2), "-> 異號,IVT 保證有根")
print("近似根 x ~", bisect(f, 1, 2))
預期輸出f(1) = -1 f(2) = 5 -> 異號,IVT 保證有根 近似根 x ~ 1.3247179572

Lab 5｜漸近線視覺化

把「趨向無窮」畫出來:有理函數會貼近水平漸近線(x → ±∞)與鉛直漸近線(分母 = 0)。

# 水平漸近線:f(x)=(3x^2+2x-1)/(2x^2-x+5) -> y = 1.5
f = lambda x: (3*x**2 + 2*x - 1) / (2*x**2 - x + 5)
x = np.linspace(-20, 20, 2000)
plt.plot(x, f(x), label='f(x)')
plt.axhline(1.5, color='C1', ls='--', label='y = 1.5 (horizontal)')
plt.title('Horizontal asymptote: f -> 3/2')
plt.legend(); plt.ylim(-1, 4); plt.show()

# 鉛直漸近線:g(x)=x/(x-2) -> x=2 兩側衝 +-inf
g = lambda x: x/(x - 2)
xl = np.linspace(-3, 1.98, 800); xr = np.linspace(2.02, 7, 800)
plt.plot(xl, g(xl), 'C0'); plt.plot(xr, g(xr), 'C0', label='g(x)')
plt.axvline(2, color='C3', ls='--', label='x = 2 (vertical)')
plt.axhline(1, color='C2', ls=':', label='y = 1 (horizontal)')
plt.title('Vertical asymptote x=2')
plt.legend(); plt.ylim(-15, 15); plt.show()

會看到:第一張圖曲線壓平貼近 y=1.5;第二張圖在 x=2 兩側分別衝向 +∞、-∞。

Lab 6｜分段函數連不連續

待定係數在做的事,畫出來就懂:選對參數兩段接得起來(連續),選錯就斷一個縫。

# f(x)= a*x+3 (x<1) 接 x^2 (x>=1);連續需要 a=-2(接縫 x=1 兩邊相等)
def piece(a, title):
    xl = np.linspace(-1, 1, 400); xr = np.linspace(1, 3, 400)
    plt.plot(xl, a*xl + 3, label=f'a*x+3 (a={a})')
    plt.plot(xr, xr**2, label='x^2')
    plt.axvline(1, color='gray', ls=':'); plt.title(title); plt.legend(fontsize=8)

plt.subplot(1, 2, 1); piece(-2, 'a=-2: continuous')
plt.subplot(1, 2, 2); piece(0,  'a=0: jump')
plt.tight_layout(); plt.show()

會看到:左圖 a=-2 兩段在 x=1 平滑接上;右圖 a=0 出現一道明顯斷崖。
